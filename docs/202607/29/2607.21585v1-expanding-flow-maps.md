## 摘要
基于流的生成模型在连续和离散状态空间上实现了快速可控生成的显著进展，然而现有的参数化方法受限于固定维度或固定序列长度。本文引入扩展生成流（EFlows），它沿着一个扩展插值器定义递增维度的分布之间的流，该插值器通过添加条件噪声来增长状态。基于此构建，我们提出扩展流映射（EFMs），一类新的流映射，将扩展插值器蒸馏为高效的少步生成模型。每个EFM将任意两个时间步之间的映射分解为两个可学习操作：扩展算子，根据当前状态用新坐标或标记扩充状态空间；以及传输映射，将扩展后的状态沿插值器向前推进。组合这些算子产生一个联合扩展和去噪状态的单一映射，将现有的固定画布流和流映射作为扩展算子为单位算子的特例恢复。我们进一步将该框架扩展到离散单纯形，使得可变大小的图生成和可变长度的序列生成成为可能。在连续和离散两种模态中，我们确立了EFlows和EFMs作为一个原则性框架，适用于输出大小本身是学习得到的可控自由度的场景。

## Abstract
Flow-based generative models have enabled remarkable progress in fast and controllable generation across continuous and discrete state spaces, yet existing parameterizations are constrained to fixed dimensions or fixed sequence lengths. Here, we introduce Expanding Generative Flows (EFlows), which define flows between distributions of increasing dimensionality along an expanding interpolant that grows the state by augmenting it with conditional noise. Building on this construction, we propose Expanding Flow Maps (EFMs), a new class of flow maps that distill the expanding interpolant into efficient few-step generative models. Each EFM factors the map between any two timesteps into two learnable operations: an expand operator, which augments the state space with new coordinates or tokens conditioned on the current state, and a transport map, which pushes the expanded state forward along the interpolant. Composing these operators yields a single map that jointly expands and denoises the state, recovering existing fixed-canvas flows and flow maps as the special case in which the expand operator is the identity. We further extend the framework to the discrete simplex, enabling variable-size graph generation and variable-length sequence generation. Across both continuous and discrete modalities, we establish EFlows and EFMs as a principled framework for settings in which output size is itself a learned, controllable degree of freedom.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现有基于流的生成模型（包括扩散模型、流匹配、流映射等）都假设输出状态空间维度固定（连续空间固定d维，离散空间固定序列长度L）。然而，许多现实任务需要生成可变尺寸的输出，例如可变分辨率图像、任意长度音频/视频、未知长度的语言序列、可变节点数的分子图等。如何在推理过程中动态增长状态空间，同时在少步（few-step）采样下保持高质量生成，是一个未解决的挑战。
- **整体含义**：本文旨在开创一个原则性框架，将 **输出维度本身作为可学习的可控自由度**，统一处理连续和离散模态的可变规模生成，且支持从多步到一步的采样预算。这突破了传统流模型“固定画布”的约束，为更灵活的结构化生成提供新范式。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：将生成过程建模为 **沿着扩展插值器（expanding interpolant）** 在递增维度的分布之间流动。核心创新是分解每一步操作为两个可学习组件：
  - **扩展算子 (Expand Operator) \(E_{s,t}\)**：从当前较低维状态 \(x_s \in \mathbb{R}^{d(s)}\) 通过注入条件噪声 \(\epsilon\) 将其提升到目标维度 \(d(t)\)，生成增广状态 \(x_s^\epsilon = E_{s,t}(x_s, \epsilon) \in \mathbb{R}^{d(t)}\)。支持多种放置方案（拼接、位置插入、子节点扩展）。
  - **传输映射 (Transport Map) \(X_{s,t}\)**：在增广空间中沿插值器将 \(x_s^\epsilon\) 向前推送到目标时间 \(t\) 的状态，参数化为残差形式 \(X_{s,t}(y) = y + (t-s)v_{s,t}(y)\)（连续）或通过均值去噪器 \(\psi_{s,t}\)（离散）。
- **总体映射**：EFM 定义为 \(\Phi_{s,t} = X_{s,t} \circ E_{s,t}\)，联合完成维度扩展和去噪。当扩展算子为单位算子时退化为标准固定维流映射。
- **训练损失**：包括对角线损失（标准流匹配损失）和一致性损失（拉格朗日、欧拉、半群条件），允许通过蒸馏（从教师流）或自蒸馏训练。
- **离散扩展**：针对离散空间，扩展算子变为在序列/图的间隙中插入噪声标记（token）或节点，插入数量由可学习的插入头 \(I_{s,t}\) 预测（使用二项分布或泊松分布近似），传输映射使用均值去噪器 \(\psi_{s,t}\) 在单纯形上进行交叉熵优化。为每个插入位置分配局部时间坐标 \(t_i\)，使不同插入时间的维度按统一局部时间进行去噪。
- **理论基础**：将扩展流刻画为 **分段确定性马尔可夫过程 (PDMP)**，其生成器包含传输项和跳跃核，为密度变化公式和一致性推导提供严谨基础。

## 3. 实验设计：数据集/场景、基准与对比方法

- **实验场景与数据集**：
  1. **连续空间：粗到细分子构象生成**：GEOM-QM9（≤29个原子）和 GEOM-Drugs（≤181个原子），每个分子提供5个参考构象。评估指标：RMSD的覆盖率(COV)和平均最小RMSD(AMR)，分为召回率(R)和精确率(P)。
  2. **离散空间：可变大小分子图生成**：QM9数据集，10k生成分子，评估有效性(Validity)、唯一性(Uniqueness)和Fréchet ChemNet Distance (FCD)。
  3. **离散空间：可变长度语言建模**：One Billion Word Benchmark (LM1B)，评估生成困惑度(Gen. PPL)和熵(Entropy)。
- **基准与对比方法**：
  - 分子构象：与 GraphDG、CGCF、ConfVAE、GeoMol、ConfGF、GeoDiff、SubgDiff、MSGEN 等对比；少步基线包括 EFlow 自身以及加上精炼网络的变体 (+R)，以及 EFM 自身。
  - 分子图：与 DeFoG (多步扩散基线) 和 Categorical Flow Maps (CFM，少步基线) 对比。
  - 语言建模：多步与 FLM 对比；少步与 Duo+DCD、Duo+Di4C、MDLM+SDTT、MDLM+Di4C、CFM、FMLM 对比。
- **公平性**：在分子构象中，模型架构统一使用 GeoDiff 双编码器；分子图中使用 DeFoG 图 Transformer；语言建模中使用 DDiT 骨干网络（部分从 FLM 热启动）。对比基线多数采用公开检查点或报告值，保证公平。

## 6. 论文的主要结论与发现

- **EFlows 和 EFMs 是统一的可变尺寸生成框架**，在连续和离散模态上均能工作，且支持从多步到一步的采样预算。
- **在分子构象生成上**：EFlow 以 20-30 步（比基线少 16-50 倍）达到或超越多步扩散模型性能；EFM 在仅 4 步（+R 14 步）时在 GEOM-Drugs 上取得四项指标的最佳或次佳值，证明蒸馏高效。
- **在分子图生成上**：EFlow 在不同步数下有效性、唯一性、FCD 均优于或持平 DeFoG；EFM 在 2 步和 1 步上显著优于同类少步基线 CFM（尤其是 1 步时 FCD 0.44 对比 2.14）。
- **在语言建模上**：EFlow 虽求解可变长度问题，但在多步上生成困惑度始终低于固定长度基线 FLM；EFM 在 2 步和 4 步上效果接近 FMLM，且优于其他少步扩散基线；单步生成存在模式崩溃，但认为有改进空间。
- **核心发现**：将维度增长与去噪解耦为扩展和传输两个可学习操作，使得框架能灵活适应不同规模的生成，同时保留流映射的少步高效特性。

## 7. 优点

1. **新颖性**：首次提出在流映射框架中动态增长状态空间，将输出维度作为可学习自由度，突破定长限制。
2. **理论扎实**：将扩展流严格形式化为 PDMP，给出生成器、密度变化公式、一致性条件（拉格朗日、欧拉、半群）及其在离散空间的推广，为训练提供了数学保障。
3. **统一性**：同时覆盖连续和离散模态，且在同一框架内实现从多步到一步的采样预算控制，简化了模型设计。
4. **实验广泛**：在三个不同模态的任务上验证，综合性强，且与多个领域先进基线进行全面对比，显示竞争力。
5. **实用价值**：少步生成显著降低推理成本，对实际部署（如药物设计、快速文本生成）有直接意义。

## 8. 不足与局限

1. **可扩展性验证不足**：理论指出二项插入参数化有保障，但在更大维度（如千词序列、大分子）上的性能未充分实验。作者承认受限于计算资源未能完全探索。
2. **单步生成质量缺陷**：在语言建模上，1 步 EFM 出现模式坍塌，Gen. PPL 和熵均较低。论文仅提供了初步修补（使用 `t_denoise_min`），但缺乏系统分析或消融来证明该问题的根本原因及解决方案。
3. **插入头的建模依赖于固定最大长度**：虽比固定画布更灵活，但仍需预设最大长度 \(L\)，并未真正实现“无界”生成。

5. **与其他少步方法的公平比较需谨慎**：CFM、FMLM 等基线采用相同骨干，但作者未公开所有复现细节，可能存在细微实现差异影响结果。
