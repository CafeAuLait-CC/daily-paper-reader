## 摘要
平均场博弈为连续时间生成式建模提供了一个统一的视角：一个成本元组将十二个著名模型——连续归一化流、最优传输流、基于分数的模型、薛定谔桥等——作为同一个变分问题的特例加以恢复。然而，这一空间的两个维度仍完全未被探索：在许多现有模型中，交互项 $\mathcal{I}$ 被设为零，且丰富的平均场博弈求解器家族从未被应用于生成式建模。我们通过 MFGLab（一个开源 PyTorch 库）填补了这两个空白，其主要 API 是成本元组：所有十二个模型由四个可组合的成本函数指定，训练循环、对数雅可比矩阵和逆常微分方程采样器自动共享。此外，我们提出了 DI-Flow，一种新颖的成本设计，使用可微分熵函数来鼓励模式覆盖，并提供了基于学习的平均场博弈求解器，在随机动力学行上显著优于神经训练。在两个二维基准上的实验证实，统一的 API 相对于手写实现是无损的。

## Abstract
Mean-field games (MFGs) offer a unifying lens on continuous-time generative modeling: a cost tuple recovering twelve prominent models---Continuous Normalizing Flows, OT-Flow, Score-based Models, Schrödinger Bridges, and more---as special cases of one variational problem. Yet two dimensions of this space remain entirely unexplored: the interaction term $\mathcal{I}$ is set to zero in many existing models, and the rich family of MFG solvers has never been applied to generative modeling. We address both gaps with MFGLab an open-source PyTorch library whose primary API is the cost tuple: all twelve models are specified by four composable cost functions, and the training loop, log-Jacobian, and reverse-ODE sampler are shared automatically. We additionally propose DI-Flow, a novel cost design that uses a differentiable entropy functional to encourage mode coverage, and provide learning-based MFG solvers that substantially outperform neural training on stochastic-dynamics rows. Experiments on two 2-D benchmarks confirm that the unified API is lossless relative to hand-coded implementations.

## 2. 方法论

### 2.1 核心思想：代价元组统一建模
- 所有模型被视为同一个MFG变分问题（式1）的特例：
  $\inf_{v,\rho} \mathcal{M}(\rho_T) + \int_0^T \mathcal{I}(\rho_t) dt + \int_0^T \int L(x, v(x,t)) \rho(x,t) dx dt$
- 通过改变 **M**（终端代价）、**I**（交互项）、**L**（运行代价）和 **σ**（噪声标准差）四个组件，即可恢复表1中12种模型（如CNF对应 M=KL, I=0, L=0, σ=0；OT-Flow对应 L=½‖v‖²等）。

### 2.2 MFGLab框架
- **用户接口**：仅需指定 (M, I, L, σ) 四个可组合代价函数对象，训练循环、log-Jacobian计算、反向ODE采样器自动共享。
- **粒子仿真管线**：速度场 $v_\theta$ 用两层MLP + 正弦时间嵌入参数化；当L=½‖v‖²时，最优控制满足 $v^* = -\nabla U$，故参数化为 $\nabla U_\theta$。
- **训练**：前向ODE/SDE积分（Euler-Maruyama），累计 log-Jacobian $\Delta_{\log}$，优化粒子形式损失（式4）。
- **生成**：反向ODE（或概率流ODE），从标准高斯采样并积分。

### 2.3 DI-Flow：新颖的交互项设计
- 在 **I=0** 的OT-Flow基础上引入可微KDE熵交互项（式6）：
  $\mathcal{I}(\rho_t)(x) = \gamma \log \hat{\rho}_t(x)$，其中 $\hat{\rho}_t$ 为基于当前mini-batch的核密度估计。
- 梯度（式7）产生排斥力，使粒子分散到各个模式，鼓励模式覆盖。
- 代价元组：M=KL($\rho_T$∥$\mathcal{N}$), I=$\gamma\log\hat{\rho}_t$, L=½‖v‖², σ=0。

### 2.4 学习型MFG求解器
- 将MFG均衡条件转化为前向-后向不动点问题，通过迭代求解FPK方程（式2）和HJB方程（式3）得到 $v_\theta$ 和 $U_\phi$。
- **算法1（通用骨架）**：在每个迭代中，先通过当前策略模拟正向外推生成粒子轨迹；然后计算每步奖励 $r_t$，利用Bellman残差更新值函数 $U_\phi$；最后从最优性条件提取策略 $v_\theta$，并可选地进行虚拟博弈平均以稳定收敛。
- 具体实现有两种：
  - **VI（网格值迭代）**（算法3）：在离散网格上解HJB，无神经网络训练，求解时间<1秒。
  - **MFG-AC（双时间尺度Actor-Critic）**（算法4）：用两个神经网络分别参数化Actor和Critic，通过滚动展开和TD误差更新。

## 6. 主要结论与发现

1. **统一API无损性**：Lab列（统一API）与Individual列（专用实现）在所有指标上数值接近（如OT-Flow Cov 0.998 vs 1.000），证实代价元组抽象不会引入性能损失。
2. **DI-Flow改善模式覆盖**：在Ring GMM上，DI-Flow（Lab）达到Cov=0.997，KDE-LL=-3.42，为所有σ=0模型中最优，优于OT-Flow的-3.81。在Two-Moons上优势不明显（KDE-LL -2.27 vs OT-Flow -1.75），说明交互效应依赖于目标几何。
3. **MFG求解器（VI）在随机动力学行上显著超越神经训练**：对于Schrödinger Bridge、Gen. SB等σ>0模型，神经训练（Lab/Individual）的Coverage仅0.23–0.37，而VI达到≥0.986。VI还解决了无动力学正则化（λ=0）时的竞拍现象问题（除CNF外）。
4. **求解效率**：VI在2D上耗时<1s，远快于神经网络训练（数十秒至数百秒），但可扩展性受限。
5. **交互项设计空间被首次打开**：DI-Flow示范了如何通过代价元组中的I项编码诱导偏好（如熵最大化），为未来设计新型生成模型提供了普适框架。

## 8. 不足与局限
