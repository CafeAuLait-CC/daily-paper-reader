## 摘要
基于流的生成模型在连续和离散状态空间上实现了快速且可控生成的显著进展，然而现有参数化方法受限于固定维度或固定序列长度。本文引入扩展生成流（EFlows），其通过沿扩展插值项定义维度递增分布之间的流，该插值项通过添加条件噪声来增长状态。基于此构造，我们提出扩展流映射（EFMs），这是一类将扩展插值项蒸馏为高效几步生成模型的新型流映射。每个EFM将任意两个时间步之间的映射分解为两个可学习操作：扩展算子（基于当前状态用新坐标或标记增强状态空间）和传输映射（沿插值项推动扩展状态前进）。组合这些算子产生一个联合扩展和去噪状态的单一映射，当扩展算子为单位算子时，恢复现有的固定画布流和流映射作为特例。我们进一步将该框架扩展到离散单纯形，实现可变大小图生成和可变长度序列生成。在连续和离散模态中，我们将EFlows和EFMs确立为输出大小本身是学习到的、可控自由度的场景的规范框架。

## Abstract
Flow-based generative models have enabled remarkable progress in fast and controllable generation across continuous and discrete state spaces, yet existing parameterizations are constrained to fixed dimensions or fixed sequence lengths. Here, we introduce Expanding Generative Flows (EFlows), which define flows between distributions of increasing dimensionality along an expanding interpolant that grows the state by augmenting it with conditional noise. Building on this construction, we propose Expanding Flow Maps (EFMs), a new class of flow maps that distill the expanding interpolant into efficient few-step generative models. Each EFM factors the map between any two timesteps into two learnable operations: an expand operator, which augments the state space with new coordinates or tokens conditioned on the current state, and a transport map, which pushes the expanded state forward along the interpolant. Composing these operators yields a single map that jointly expands and denoises the state, recovering existing fixed-canvas flows and flow maps as the special case in which the expand operator is the identity. We further extend the framework to the discrete simplex, enabling variable-size graph generation and variable-length sequence generation. Across both continuous and discrete modalities, we establish EFlows and EFMs as a principled framework for settings in which output size is itself a learned, controllable degree of freedom.

## 1. 论文的核心问题与整体含义

**研究动机**：现有基于流的生成模型（包括扩散模型、流匹配、流映射）在连续和离散空间上均取得了显著成果，但其生成过程均假定一个固定的输出尺寸：连续空间中的固定维度 \(d\)，或离散空间中的固定序列长度 \(L\)。然而，许多真实生成任务要求输出大小本身是可变的（如可变分辨率图像、可变长度音频/视频、任意长度文本、大小可变的分子图等）。这种“固定画布”限制严重制约了流模型在更广泛场景中的应用。

**核心问题**：如何设计一个**可在推理过程中自适应增长状态空间**的生成框架，实现连续和离散数据上的**少步可变尺寸生成**？

**整体含义**：提出 **扩展生成流（EFlows）** 与 **扩展流映射（EFMs）**，将静态流模型泛化为维度可变的动态过程，为输出大小作为可学习自由度的场景提供了统一原则性框架。

## 2. 提出的方法论

**核心思想**：将生成过程建模为沿一个**维度逐步增加的插值项**的传输：源分布位于低维空间，目标分布位于高维空间。在每个时间步，先通过**扩展算子（Expand Operator）** 用条件噪声增广状态空间到目标维度，再通过**传输映射（Transport Map）** 在增广空间中沿时间推进去噪。

**关键技术细节**：
- **扩展插值项（Expanding Interpolant）**：维度 \(d(t)\) 随时间 \(t \in [0,1]\) 非递减。状态 \(\mathbf{x}_t \in \mathbb{R}^{d(t)}\)。对于 \(s < t\)，先通过扩展算子 \(\mathcal{E}_{s,t}(\mathbf{x}_s, \epsilon)\) 将 \(\mathbf{x}_s\) 提升至 \(\mathbb{R}^{d(t)}\)，然后由标准流 ODE 在增广空间内从 \(s\) 积分到 \(t\)。
- **扩展算子**：将源状态与从条件噪声分布 \(p_{\epsilon|s,t}\) 采样的新坐标结合，实现方式包括**拼接**、**位置插入**、**子节点扩展**（用于粗到细生成）。对于离散序列/图，还涉及**插入头**预测每个间隙应插入的标记/节点数。
- **传输映射**：在增广空间内使用平均速度 \(\mathbf{v}_{s,t}\)（连续）或平均去噪器 \(\psi_{s,t}\)（离散）实现从 \(s\) 到 \(t\) 的少步跳转。EFM 定义为 \(\Phi_{s,t} = X_{s,t} \circ \mathcal{E}_{s,t}\)。
- **一致性条件**：扩展流映射满足拉格朗日条件、欧拉条件、半群条件，对应蒸馏损失。
- **离散扩展流映射**：状态位于单纯形 \(\Delta^{V-1}\)，使用交叉熵损失训练平均去噪器；插入头采用二项式分布模拟插入计数（对少步和大步均稳定）。
- **分段确定性马尔可夫过程（PDMP）解释**：扩展过程可视为由确定性传输和随机跳转（插入）组成的 PDMP，其生成元由速度和跳转核给出。

**算法流程**（文字说明）：
- **训练 EFlow**：采样全局时间 \(t\) 和每个位置的插入时间 \(t_{\text{ins}}^i\)，构造扩展插值状态 \(\mathbf{x}_t\)，训练去噪网络和插入头（对角损失 + 插入损失）。
- **训练 EFM**：从教师流（或数据）蒸馏，使用一致性目标（如半群目标）联合训练扩展算子和平均去噪器。
- **采样**：按时间网格逐步执行“扩展 + 传输”操作，最后取 argmax 生成离散输出。

## 3. 实验设计

**数据集与场景**：
1. **连续空间：分子构象生成**  
   - 数据集：GEOM-QM9（最多29个重原子）、GEOM-Drugs（最多181个原子）  
   - 指标：覆盖率（COV-R/P）、平均最小RMSD（AMR-R/P）  
   - 对比模型：GraphDG、CGCF、ConfVAE、GeoMol、ConfGF、GeoDiff、SubgDiff、MSGEN（多步扩散基线）以及 EFlow（教师）和 EFM（学生）。

2. **离散空间：分子图生成**  
   - 数据集：QM9（小分子，最多9个重原子）  
   - 指标：有效性、唯一性、Fréchet ChemNet Distance（FCD）  
   - 对比模型：DeFoG（多步流匹配）、CFM（分类流映射，少步）

3. **离散空间：可变长度语言建模**  
   - 数据集：One Billion Word Benchmark (LM1B)  
   - 指标：生成困惑度（Gen. PPL，在 GPT-2 Large 上评估）、熵  
   - 对比模型：FLM（固定长度流语言模型）、Duo + DCD/Di4C、MDLM + SDTT/Di4C、CFM、FMLM

**Benchmark 与公平性**：在分子构象生成中采用 GeoDiff 的骨干网络（双编码器）以保证公平比较；图生成采用 DeFoG 的图 Transformer；语言建模采用 DDiT 架构并热启动 FLM 权重。消融实验较少，主要通过不同步数（1/2/4/64/128/256/512/1024 等）测试多步与少步性能。

## 6. 论文的主要结论与发现

1. **EFlows/EFMs 是统一的可变尺寸生成框架**，在连续和离散空间上均有效，且可蒸馏到少步（1~4步）生成。
2. **扩展算子与传输映射的组合**能够自然实现维度增长，且标准固定维度流映射是其特例。
3. **离散扩展流映射**通过插入头和二项式采样，在可变长度序列/图生成中取得与固定长度方法相当甚至更优的性能，尤其在小预算下优势明显。
4. **少步语言建模首次实现可变长度生成**，在2步和4步下生成困惑度优于大多数蒸馏扩散/流基线，与固定长度FMLM竞争。
5. **分子构象生成**在GEOM-Drugs上所有指标取得最佳或次佳，验证了框架在连续空间的有效性。
