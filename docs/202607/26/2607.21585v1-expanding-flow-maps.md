## 摘要
基于流的生成模型在快速可控生成方面取得了显著进展，涵盖连续和离散状态空间，然而现有参数化被限制在固定维度或固定序列长度。在此，我们引入了扩展生成流（EFlows），它通过沿着一个扩展插值器（该插值器通过添加条件噪声来增长状态）在递增维度的分布之间定义流。基于这种构造，我们提出了扩展流映射（EFMs），这是一种新的流映射类别，将扩展插值器蒸馏为高效的少步生成模型。每个EFM将任意两个时间步之间的映射分解为两个可学习操作：一个扩展算子（根据当前状态用新坐标或标记扩充状态空间）和一个传输映射（沿插值器向前推动扩展状态）。组合这些算子产生一个单一映射，该映射同时扩展和去噪状态，将现有的固定画布流和流映射作为扩展算子为恒等映射的特例。我们进一步将该框架扩展到离散单纯形，实现了可变大小图生成和可变长度序列生成。在连续和离散模态中，我们将EFlows和EFMs确立为一个原则性的框架，适用于输出大小本身是一个可学习的、可控的自由度的场景。

## Abstract
Flow-based generative models have enabled remarkable progress in fast and controllable generation across continuous and discrete state spaces, yet existing parameterizations are constrained to fixed dimensions or fixed sequence lengths. Here, we introduce Expanding Generative Flows (EFlows), which define flows between distributions of increasing dimensionality along an expanding interpolant that grows the state by augmenting it with conditional noise. Building on this construction, we propose Expanding Flow Maps (EFMs), a new class of flow maps that distill the expanding interpolant into efficient few-step generative models. Each EFM factors the map between any two timesteps into two learnable operations: an expand operator, which augments the state space with new coordinates or tokens conditioned on the current state, and a transport map, which pushes the expanded state forward along the interpolant. Composing these operators yields a single map that jointly expands and denoises the state, recovering existing fixed-canvas flows and flow maps as the special case in which the expand operator is the identity. We further extend the framework to the discrete simplex, enabling variable-size graph generation and variable-length sequence generation. Across both continuous and discrete modalities, we establish EFlows and EFMs as a principled framework for settings in which output size is itself a learned, controllable degree of freedom.

- **问题**：现有的基于流的生成模型（如流匹配、分数模型）在连续和离散状态空间取得了显著进展，但它们**受限于固定的画布**——连续状态空间必须固定维度d，离散状态空间必须固定序列长度L。这无法适应许多实际生成任务，例如变分辨率图像、任意时长音频/视频、未知长度文本以及多模态数据，这些任务的**输出大小本身是待建模的变量**。
- **核心挑战**：如何在推理过程中让状态空间动态增长，而不是在初始化时固定维度，从而实现可变大小输出的少步生成。
- **整体意义**：本文提出**扩展生成流（EFlows）**和**扩展流映射（EFMs）**，首次将流模型扩展到可变维度和可变序列长度，将输出大小作为可学习的可控自由度，统一了连续和离散模态下的可变大小生成。

## 2. 论文提出的方法论

### 2.1 核心思想
- **EFlows**：在标准流插值器基础上，允许维度随时间非递减增长。定义维度调度函数 \(d(t):[0,1]\to \mathbb{N}\)，使得 \(x_t \in \mathbb{R}^{d(t)}\)，并构造一个**扩展插值器**，通过增广条件噪声将低维状态提升到高维。
- **EFMs**：将EFlows蒸馏为少步模型。每个EFM将任意两点间的映射分解为两个可学习操作的复合：
  - **扩展算子 \(E_{s,t}\)**：根据当前状态 \(x_s\) 和条件噪声 \(\epsilon\) 将状态从维度 \(d(s)\) 提升到 \(d(t)\)，支持拼接、位置插入、子节点扩展等实例化方式。
  - **传输映射 \(X_{s,t}\)**：在扩展后的高维空间中，沿插值器推动状态从时刻 \(s\) 到 \(t\)，由平均速度 \(v_{s,t}\)（连续）或平均去噪器 \(\psi_{s,t}\)（离散）参数化。
- **复合**：\(\Phi_{s,t} = X_{s,t} \circ E_{s,t}\)，同时完成维度扩展和去噪/传输。

### 2.2 关键技术细节
- **局部时间坐标**：每个新插入的维度 \(i\) 有局部时间 \(t_i = (t - t_{\text{ins},i})/(1 - t_{\text{ins},i})\)，使得所有维度在共同局部时钟上被去噪。
- **分段确定型马尔可夫过程（PDMP）**：EFlow被形式化为一个PDMP，其生成器由传输项和跳跃项（由扩展算子定义）组成，统一了连续运输和离散维度跳跃。
- **连续EFM的恒等式**：拉格朗日条件、欧拉条件、半群条件均被推广到扩展流映射，并用于构建一致性损失。
- **离散EFM**：扩展到离散单纯形空间 \(\Delta^{V-1}\)，将扩展算子具体化为**基于插入预期的令牌插入**，传输映射由平均去噪器 \(\psi_{s,t}\) 定义，并推导了离散版本的拉格朗日、欧拉、半群恒等式。

### 2.3 算法流程（文字说明）
- **训练EFlow（算法1）**：
  1. 从数据中采样 \(x_1\)，从先验中采样 \(x_0\)；采样全局时间 \(t\)；为每个位置独立采样插入时间 \(t_{\text{ins},i}\)。
  2. 计算局部时间 \(t_i\)，构造扩展插值状态 \(x_{t_i}\)。
  3. 用插值状态训练去噪器 \(\hat{D}_t\)（交叉熵损失）和插入头 \(\hat{I}_t\)（泊松负对数似然损失）。
- **训练EFM（算法2）**：
  1. 同EFlow采样 \(s, u, t\) 三时间点，构造扩展状态 \(x_s^\epsilon\)。
  2. 使用半群目标计算教师目标 \(\bar{\psi}_{s,t}\)。
  3. 训练平均去噪器 \(\hat{\psi}_{s,t}\) 和插入头 \(\hat{I}_{s,t}\)，损失包括对角线损失（交叉熵）和一致性损失（交叉熵）+插入损失。
  4. 使用stop-gradient和梯度手术。
- **采样EFM（算法4）**：给定时间网格，先通过扩展算子从最小时间插入，再通过平均去噪器逐步传输，最终对最后一个时刻取argmax得到离散令牌。

## 6. 论文的主要结论与发现

1. **EFlows和EFMs是有效的可变大小生成框架**：在连续和离散模态中均能实现从多步到少步的可变大小生成，且不牺牲质量。
2. **连续分子构象生成**：EFlow以16-50倍更少的步数（20-30步）超越或持平多步扩散基线（500步）；EFM+R（14步）在GEOM-Drugs上取得所有指标最优。
3. **离散分子图生成**：EFlow在不蒸馏的情况下优于DeFoG；EFM在1步时FCD为0.44，是CFM（2.14）的近5倍，且有效性/唯一性极高。
4. **语言建模**：EFlow在64-1024步下始终优于固定长度FLM；EFM在2步和4步时生成困惑度优于所有蒸馏扩散基线和CFM，与FMLM相当；1步存在模式崩塌。
5. **框架统一性**：通过扩展算子-传输映射分解，将标准固定画布流映射作为特例；PDMP视角为理论基础。
6. **输出大小为可学习自由度**：插入头能预测间隙插入数，使得序列或图的长度成为模型控制的变量。

## 7. 优点

- **理论新颖性**：首次将流模型扩展到可变维度，并给出严格的PDMP形式化，推导了连续和离散的扩展流映射恒等式。

- **实验覆盖全面**：三个不同模态的任务验证了泛化能力，且步数从1到1000均有测试。
