## 摘要
离散流匹配为离散结构上的生成建模提供了灵活框架。然而，标准因子化训练目标使模型面临难度不一的目标，混合了条件良好、可预测的标记与模糊、高熵的标记。我们实证表明，每个标记值的不确定性与其邻域中可用上下文的密度密切相关。基于这一观察，我们提出对底层连续时间马尔可夫链（CTMC）进行简单修改，融入局部上下文信息。我们的上下文加权采样器在计算开销可忽略的情况下提升了生成质量，而我们的缩放交叉熵损失函数重新加权来自不同标记的训练信号，在OpenWebText上将生成困惑度降低了多达63%。此外，我们的方法在质量上匹配了强半自回归块扩散基线，同时保留了以任意顺序进行生成的能力。这些结果凸显了局部上下文作为离散生成建模中重要因素的作用，并表明简单的上下文感知修改可以显著提升采样和训练效率。

## Abstract
Discrete flow matching provides a flexible framework for generative modeling on discrete structures. However, the standard factorized training objective exposes the model to targets of varying difficulty, mixing well-conditioned, predictable tokens with ambiguous, high-entropy ones. We empirically demonstrate that the uncertainty over the value of each token is closely related to the density of available context in its neighborhood. Motivated by this observation, we propose a simple modification to the underlying continuous-time Markov chain (CTMC) that incorporates local context information. Our context-weighted sampler improves generation quality with negligible computational overhead, while our scaled cross-entropy loss function reweights the training signal from different tokens and reduces generative perplexity by up to 63% on OpenWebText. Moreover, our approach matches a strong semi-autoregressive block diffusion baseline in quality while retaining the ability to perform generation in any order. These results highlight the role of local context as an important factor in discrete generative modeling and show that simple context-aware modifications can significantly improve both sampling and training efficiency.

## 1. 核心问题与整体含义

**研究动机：** 离散流匹配（DFM）等离散生成模型在训练时使用因式化的交叉熵损失，对每个 token 的预测损失进行等权求和。然而，不同 token 因所处的上下文状态不同，其预测难度（不确定性）差异极大：有些 token 高度可预测（低熵），有些则非常模糊（高熵）。标准等权目标使得模型在高熵 token 上浪费大量训练信号，低熵 token 的尖锐监督也被弱化。

**整体含义：** 本文通过实证发现，token 的预测不确定性与局部邻域内已揭露 token 的数量（即局部上下文密度）密切相关。基于此，作者提出在连续时间马尔可夫链（CTMC）中引入局部上下文权重，从而在采样时偏好条件更好的 token，在训练时重新加权每个 token 的损失。该工作表明，简单的上下文感知修改即可显著提升离散生成模型的训练与采样效率，无需复杂的架构改动。

## 2. 方法论

### 核心思想
在 DFM 的 CTMC 转移速率上乘一个上下文权重函数 \(\alpha_i(z)\)（仅依赖当前状态 \(z\)，不依赖目标值 \(x\)），使得局部上下文更丰富的 token 获得更高的转移速率（更容易被更新）。同时，通过归一化条件 \(\sum_i \alpha_i(z) \mathbb{1}[z_i = x_i^0] = \sum_i \mathbb{1}[z_i = x_i^0]\) 保证每个 token 的边际揭露概率保持不变，进而保持路径的端点约束（噪声→数据）。

### 关键技术细节
- **上下文权重定义**：两种实用形式：
  - **Neighbor-weighted**：\(\alpha_i \propto \sum_{j=i-r}^{i+r} \mathbb{1}[x_j = x_j^1]\)（局部窗口内未遮盖 token 数）。
  - **Entropy-weighted**：\(\alpha_i \propto 1 / H(p_{\theta,i|t}(\cdot | x))\)（模型预测熵的倒数）。
  使用 softmax 归一化（含逆温度 \(s\)）以满足平均归一化条件。
- **采样器**：在推理时直接修改 Euler 更新步长，权重 \(\alpha_i\) 改变了每个 token 被翻转为预测值的概率。无需微调。
- **缩放交叉熵损失（SCE）**：训练时在标准交叉熵前乘上 \(\alpha_i(X_t)\)，即 \(L_{\alpha}(\theta) = -\mathbb{E}_{t,X_1,X_0,X_t} \left[ \sum_i \alpha_i(X_t) \log p_{\theta,i|t}(X_i^1 | X_t) \right]\)。该损失强调了低熵、条件良好的 token，抑制了高熵 token 的噪声信号。
- **训练路径采样（Algorithm 1）**：从 Binomial(\(N, \kappa_t\)) 采样总揭露 token 数，然后按权重 \(\alpha_i\) 逐步选择揭露的 token，避免了模拟整个连续轨迹，复杂度 \(O(N)\)。

### 理论保证
**Theorem 1**：若权重函数满足归一化条件，则上下文加权的 CTMC 与标准凸混合路径具有相同的揭露 token 数量分布和相同的边际概率，从而保持端点条件。
