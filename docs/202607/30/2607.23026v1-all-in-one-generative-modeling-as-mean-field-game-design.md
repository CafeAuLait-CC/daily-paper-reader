## 摘要
平均场博弈（MFGs）为连续时间生成建模提供了一个统一的视角：一个代价元组将十二个著名模型——连续归一化流、OT流、基于分数的模型、薛定谔桥等——作为同一个变分问题的特例恢复出来。然而，该空间的这两个维度仍完全未被探索：在许多现有模型中，相互作用项I被设为零，而且丰富的平均场博弈求解器家族从未被应用于生成建模。我们通过MFGLab（一个开源PyTorch库）来解决这两个空白，其主要API是代价元组：所有十二个模型都由四个可组合代价函数指定，并且训练循环、对数雅可比和反向ODE采样器自动共享。我们还提出了DI-Flow，一种新颖的代价设计，它使用可微熵泛函来鼓励模态覆盖，并提供了基于学习的平均场博弈求解器，在随机动力学行上显著优于神经网络训练。在两个二维基准上的实验证实，统一API相对于手工编码实现是无损的。

## Abstract
Mean-field games (MFGs) offer a unifying lens on continuous-time generative modeling: a cost tuple recovering twelve prominent models---Continuous Normalizing Flows, OT-Flow, Score-based Models, Schrödinger Bridges, and more---as special cases of one variational problem. Yet two dimensions of this space remain entirely unexplored: the interaction term $\mathcal{I}$ is set to zero in many existing models, and the rich family of MFG solvers has never been applied to generative modeling. We address both gaps with MFGLab an open-source PyTorch library whose primary API is the cost tuple: all twelve models are specified by four composable cost functions, and the training loop, log-Jacobian, and reverse-ODE sampler are shared automatically. We additionally propose DI-Flow, a novel cost design that uses a differentiable entropy functional to encourage mode coverage, and provide learning-based MFG solvers that substantially outperform neural training on stochastic-dynamics rows. Experiments on two 2-D benchmarks confirm that the unified API is lossless relative to hand-coded implementations.

### 2. 论文提出的方法论：核心思想、关键技术细节

论文的核心方法论包含三个层面的贡献：

- **框架设计：作为执行引擎的代价元组（Cost Tuple）**
    - **核心思想**：所有连续时间生成模型都可以被视为一个**平均场博弈**变分问题的特例，该问题由一个**代价元组** $(M, I, L, \sigma)$ 完全参数化。
        - $M(\rho_T)$：终端代价，衡量最终分布与目标分布的差异。
        - $I(\rho_t)$：交互项，编码群体级别的目标（如熵、拥堵）。
        - $L(x, v)$：运行代价，塑造传输路径（如动能惩罚）。
        - $\sigma$：噪声强度，控制路径的随机性。
    - **关键技术细节**：
        - 论文开发了 **MFGLab** 开源库，其主API就是这个四元组。用户只需指定这四个代价函数，库会自动共享训练循环、对数雅可比行列式计算、反向ODE/SDE采样器等所有底层逻辑。
        - 论文通过一个查找表（论文中表1），展示了12个模型（CNF、OT-Flow、SGM、SB等）如何通过选择不同的代价元组而一一对应。

- **代价设计：全新的交互项 $I(\rho_t)$**
    - **核心思想**：刻意设计一个非零的、可微的交互项 $I$，来编码只有群体层面才能体现的归纳偏好（如防止模式坍塌）。
    - **关键技术细节**：
        - 论文提出了 **DI-Flow** 作为具体实例。
        - **交互项定义**：$I(\rho_t) = \gamma \log \hat{\rho}_t(x)$，其中 $\hat{\rho}_t(x)$ 是一个可微分的核密度估计（KDE）。
        - **作用机制**：该代价惩罚高密度区域的“粒子”（即模式中心），而奖励低密度区域的粒子。它的梯度 $\partial (\gamma \log \hat{\rho}_t(x_i)) / \partial x_i$ 表现为一种排斥力，会将粒子从邻居的局部质心推开，从而实现**确定性（det**）的模式覆盖。其代价元组为 `(M=KL(ρ_T || N), I=γ log ρ̂_t, L=½||v||², σ=0)`。

- **求解器设计：基于学习的MFG求解器**
    - **核心思想**：将MFG领域的“前向-后向不动点”求解算法（如值迭代）直接应用于生成建模。传统的神经训练（梯度下降）优化的是单个粒子的损失；MFG求解器则迭代地寻找一个**纳什均衡**，在该均衡下，由策略 $v_\theta$ 诱导出的群体分布 $\rho$ 与价值函数 $U_\phi$ 是自洽的。
    - **关键技术细节**：
        - 算法框架（论文中算法1）是一个通用骨架，包含前向FPK传播、反向HJB求解（通过RL）、策略更新和可选的最优响应虚拟博弈（Fictitious Play）步骤。
        - 论文提供了两种具体实现：
            1.  **MFG Solver (VI)**：基于网格（Grid）的MFG值迭代。利用HJB方程和FPK方程的外层循环求解，算力消耗极低（<1s）。
            2.  **MFG-AC**：一种基于两时间尺度演员-评论家（Actor-Critic）的神经求解器，使用深度网络参数化策略和价值函数，通过Bellman残差最小化来更新。
