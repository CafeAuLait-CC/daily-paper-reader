## 摘要
在流匹配（FM）中，速度模型 $v_θ$ 通过一个连接数据与噪声样本的预定义路径 $g_t$ 来训练（例如，$g_t(x_0, x_1) = (1 - t) x_0 + t x_1$）。在这项工作中，我们从优化角度通过分析随机梯度的方差来研究该路径的选择。我们考虑路径类 $G(p_t,v^\star_t)$，这些路径诱导相同的边缘分布 $p_t$ 和边缘速度场 $v^\star_t$，因而具有相同的 FM 目标。我们的主要发现是，即使 FM 目标完全不变，路径 $g_t$ 的选择也能从根本上改变 SGD 的收敛速率。(i) 对于线性速度模型和一维高斯数据，我们推导出（至多对数因子意义下）SGD 迭代复杂度的紧界，并在诱导相同 FM 问题的线性路径中找到一个解析最优路径，使该界最小化。(ii) 随后，我们将方差分析推广到一般 FM 问题，并将固定 $θ$ 下的路径选择形式化为方差最小化问题 PathOpt$_θ$，其约束为 $g_t\in G(p_t,v^\star_t)$。我们表明这一约束至关重要：若没有该约束，降低方差可能导致更慢的收敛。(iii) 由于约束 $g_t \in G(p_t,v^\star_t)$ 通常无法直接验证，我们推导出一个等价的、其约束可从样本估计的表述，从而使路径能够通过数值方法找到。我们的理论结果得到了高斯数据、高斯混合模型和真实数据集实验的支持。

## Abstract
In flow matching (FM), a velocity model $v_θ$ is trained using a predefined path $g_t$ that connects data and noise samples (e.g., $g_t(x_0, x_1) = (1 - t) x_0 + t x_1$). In this work, we study the choice of this path from an optimization perspective by analyzing the variance of stochastic gradients. We consider the class $G(p_t,v^\star_t)$ of paths that induce the same marginal distributions $p_t$ and marginal velocity field $v^\star_t$, and therefore the same FM objective. Our main finding is that the choice of path $g_t$ can fundamentally change the convergence rate of SGD, even when the FM objective remains exactly the same. (i) For a linear velocity model and one-dimensional Gaussian data, we derive a tight bound on the SGD iteration complexity up to logarithmic factors and find an analytically optimal path that minimizes this bound among linear paths inducing the same FM problem. (ii) We then extend the variance analysis to general FM problems and formulate path selection at a fixed $θ$ as the variance-minimization problem PathOpt$_θ$, constrained to $g_t\in G(p_t,v^\star_t)$. We show that this constraint is essential: reducing variance without it can lead to slower convergence. (iii) Since the constraint $g_t \in G(p_t,v^\star_t)$ cannot generally be verified directly, we derive an equivalent formulation with constraints that can be estimated from samples, allowing paths to be found numerically. Our theoretical results are supported by experiments with Gaussian data, Gaussian mixture models, and real datasets.

## 1. 核心问题与整体含义

- **背景**：流匹配（Flow Matching, FM）通过预定义路径 $g_t$（如直线路径 $g_t(x_0,x_1)=(1-t)x_0+tx_1$）连接数据分布 $p_{\text{data}}$ 与噪声分布，训练速度模型 $v_\theta$ 拟合边缘速度场 $v^\star_t$，再用 ODE 采样生成样本。
- **关键观察**：对于固定的边缘分布 $p_t$ 与边缘速度场 $v^\star_t$，诱导它们的路径并不唯一，存在路径类 $G(p_t,v^\star_t)$。所有这些路径对应的 FM 目标 $L_{\text{FM}}$ 完全相同，因此从"学什么"的角度看无差别。
- **核心问题**：从优化角度看，路径选择决定了随机梯度 $\nabla L_{\text{CFM}}(\theta;\xi)$ 的方差，从而可能根本性地影响 SGD 的收敛速率，即使目标函数不变。
- **整体含义**：论文揭示了一个此前被忽视的设计自由度——在保持同一 FM 问题的前提下重参数化路径以降低梯度方差，为 FM 训练提供了新的优化视角。

## 2. 方法论

### 2.1 线性模型 + 一维高斯：精确分析
- **设定**：$v_\theta(x,t)=\theta x$，$p_{\text{data}}=\mathcal{N}(0,\sigma^2)$，线性路径 $g_t=a_t x_0+b_t x_1$。
- **可解性条件**（命题 2.1）：FM 问题可解（存在 $\theta^\star$ 使 $L_{\text{FM}}(\theta^\star)=0$）当且仅当
  $$q_t:=\sigma^2 a_t^2+b_t^2=\sigma^2(1-t),\quad \theta^\star=-\log\sigma.$$
- **收敛率定理**（定理 2.2）：SGD 达到 $\mathbb{E}|\theta_k-\theta^\star|^2\le\varepsilon$ 所需迭代数（上下界匹配至对数因子）
  $$T_{\text{SGD}}(a_t,b_t)=\frac{\mathbb{E}_t[q_t^2]}{(\mathbb{E}_t[q_t])^2}+\frac{\mathbb{E}_t[\sigma^2(a_t\dot b_t-b_t\dot a_t)^2]}{(\mathbb{E}_t[q_t])^2\,\varepsilon}.$$
- **解析最优路径**（命题 2.3）：用极坐标 $(r_t,\phi_t)$ 重写后，用 Euler–Lagrange 方程得 $\partial_t(\sigma^{-4t}\dot\phi_t)=0$，解得
  $$a^\star_t=\sigma^{-t}\cos\!\Big(\tfrac{\pi}{2}\tfrac{\sigma^{4t}-1}{\sigma^4-1}\Big),\quad b^\star_t=\sigma^{1-t}\sin\!\Big(\tfrac{\pi}{2}\tfrac{\sigma^{4t}-1}{\sigma^4-1}\Big).$$
  大 $\sigma$ 小 $\varepsilon$ 时复杂度为 $\tilde\Theta(1/(\sigma^4\varepsilon))$，而朴素路径（9）仅为 $\tilde\Theta(1/\varepsilon)$，不随 $\sigma$ 改善。
- 可推广至对角协方差多维高斯（逐坐标分离），并给出 GMM 的非线性扩展（附录 K）。

### 2.2 一般 FM 的方差分析
- 方差分解：$\mathrm{Var}(\theta;g_t)=\mathrm{Var}_1(\theta;p_t,v^\star_t)+\mathrm{Var}_2(\theta;g_t)$，其中 $\mathrm{Var}_1$ 与路径无关，$\mathrm{Var}_2$ 依赖路径的条件方差。
- 形式化两个优化问题：对参数集取最大值的 $\textsc{PathOpt}^{\max\Theta}$，以及固定 $\theta$ 的 $\textsc{PathOpt}_\theta$（等价于最小化 $\mathbb{E}\|J_\theta(x_t,t)^\top\dot g_t\|^2$），约束均为 $g_t\in G(p_t,v^\star_t)$。
- **约束的必要性**（例 3.1）：构造路径 $g^M_t=\exp(-Mt(1-t))(\cos(\pi t/2)x_0+\sin(\pi t/2)x_1)$，$M\to\infty$ 时方差 $\to 0$，但迭代复杂度 $\to\infty$，因为改变了 FM 任务（边缘方差趋于零）。说明无约束地压低方差会导致更慢收敛。

### 2.3 可行化：从不可验证约束到可估计约束
- 固定参考路径 $\bar g_t$ 间接固定 $(p_t,v^\star_t)$，将 $G(p_t,v^\star_t)$ 约束拆为两个可样本估计的条件：
  - **分布相等**：用能量距离 $D^2_{p,t}(g_t,\bar g_t)=0$（命题 4.1，Székely & Rizzo）。
  - **速度场相等**：用高斯核构造的 $D^2_{v,t}(g_t,\bar g_t)=0$（命题 4.2），前提是 $p_t=\bar p_t$。
- **定理 4.3**：上述两个期望约束 $\le 0$ 等价于 $g_t\in G(p_t,v^\star_t)$，得到可行的 $\textsc{Feasible PathOpt}_\theta$。
- **算法 1**：原始-对偶随机优化。对路径参数 $a$ 用 Adam 更新 $\hat L_k=\hat F_k+\lambda_{p,k}\hat D^2_{p,k}+\lambda_{v,k}\hat D^2_{v,k}$，对偶变量用投影梯度更新 $[\lambda+\eta\hat D^2]_+$。

### 2.4 与时间采样的关系
- 时间重要性采样（密度 $\rho$）的最优解为 $\rho^\star(t)\propto\sqrt{S_{\theta,g}(t)}$，与路径优化互补。
- 线性例子中证明：联合优化相对仅优化路径最多带来 $O(\log\sigma^2)$ 的方差改进，即时间采样不改变多项式依赖，路径优化是主要收益来源。

## 6. 主要结论与发现

- 路径 $g_t$ 的选择可在 FM 目标完全不变的情况下**根本改变 SGD 收敛速率**；一维高斯线性模型中给出了紧的迭代复杂度界与解析最优路径。
- 最优路径使复杂度在大 $\sigma$ 时达到 $\tilde\Theta(1/(\sigma^4\varepsilon))$，显著优于朴素路径的 $\tilde\Theta(1/\varepsilon)$。
- 方差最小化**必须**在 $G(p_t,v^\star_t)$ 约束内进行；去掉约束会使方差任意小但收敛任意慢（例 3.1）。
- 约束可转化为可用样本估计的能量距离与核化速度差异约束，从而支持数值路径搜索。
- 时间采样优化与路径优化互补，但在线性例子中前者只带来对数级收益。
- 实验中学习路径的方差与收敛接近解析最优，GMM 与真实数据上（尤其 SVHN、CIFAR-100）FID 有可测改进。

## 7. 优点

- **视角新颖**：首次系统利用 CFM 表示的非唯一性，把路径选择当作方差缩减的自由度，且严格保持原 FM 问题不变。
- **理论扎实**：线性情形给出匹配的上下界（至多对数因子），最优路径有解析解；约束必要性有反例支撑。
- **可落地**：把不可验证的 $G(p_t,v^\star_t)$ 约束转化为可蒙特卡洛估计的能量距离/核差异，并给出原始-对偶算法。
- **多层次验证**：从解析线性模型 → GMM 非线性模型 → 真实图像数据集，理论预测与实验一致性较好；消融实验直接验证约束必要性。
- **实验规范**：真实数据使用 5 seeds、配对置信区间、统一训练与评估协议，结论相对可信。

## 8. 不足与局限

- **理论覆盖有限**：显式的收敛率改进仅针对一维高斯数据 + 线性模型；一般数据与非线性模型仅有代理目标，缺少端到端保证。
- **PathOpt 只是代理**：$\textsc{PathOpt}_\theta$ 是端到端复杂度中方差项的代理，未考虑目标精度、损失几何（光滑性、曲率）等非平凡依赖。
- **优化困难**：Feasible PathOpt 非凸，约束需近似满足；实验中的路径族很小（4 参数）且训练前固定，未与网络权重、训练迭代、优化器状态自适应，作者也指出这是未来方向。
- **真实数据收益有限**：Flowers-102 上学习路径退化为直线路径、结果完全相同；AFHQ-Cat 改进在置信区间内不显著；说明当前低维路径学习对大型 FM 模型的提升有限。
- **算力与可复现细节**：未报告总 GPU 时间、超参搜索成本；真实数据网格搜索与约束阈值 $\delta$ 的选取依赖人工设定，可能带来偏差。
- **应用限制**：需要预先固定参考路径并估计两个约束量，在高维、复杂数据上估计代价与方差可能较大，实际收益与成本尚需权衡。
