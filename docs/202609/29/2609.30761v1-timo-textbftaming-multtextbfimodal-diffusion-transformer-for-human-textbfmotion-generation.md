## 摘要
大多数现有的人体运动生成（HMG）方法使用交叉注意力模块来注入文本语义，但忽略了运动与文本 token 之间双向建模的重要性，这限制了文本理解。一个直接的想法是将多模态扩散 Transformer（MMDiT）引入 HMG，这类模型已在视觉生成中展现出有效的文本—视觉联合建模能力。然而，我们发现，关节式运动在时间上连贯，但不同关节之间相关性较弱；在这种情况下，直接将 MMDiT 与流匹配结合应用，会产生协调性差且抖动明显的运动。在这项工作中，我们提出了 Timo，一种专为 HMG 设计的新颖的运动学感知 MMDiT 框架。Timo 将用于文本—运动双向建模的完全共享多模态注意力与流匹配、比较实际旋转及其随时间变化的几何与旋转运动学监督，以及从广泛运动学习到细粒度描述对齐的两阶段课程学习相结合。此外，我们构建了一个包含来自六个公开数据集、涵盖多种动作的 $40{,}025$ 个留出片段的基准，并在统一评估器和评分协议下评估六个互补维度。我们的模型在定量和定性评估中均显著优于最先进方法。值得注意的是，Timo 在六个维度中的五个上超越了 Kimodo，在平均基准得分上实现了 $40.8$% 的相对提升。项目页面：https://kyfafyd.wang/projects/timo。演示页面：https://timo.kyfafyd.wang。

## Abstract
Most existing human motion generation (HMG) methods use cross-attention modules to inject text semantics, but ignore the importance of bidirectional modeling between motion and text tokens, which limits text comprehension. A straightforward idea is introducing multimodal diffusion transformers (MMDiT), which have shown effective joint text--visual modeling in vision generation, into HMG. However, we find that articulated motion is temporally coherent but weakly correlated across joints, in which directly applying an MMDiT with flow matching produces poorly coordinated and jerky motion. In this work, we propose Timo, a novel kinematics-aware MMDiT framework tailored for HMG. Timo combines fully shared multimodal attention for bidirectional text--motion modeling with flow matching, geometric and rotational-kinematics supervision that compares actual rotations and their changes over time, and a two-stage curriculum progressing from broad motion learning to detailed caption alignment. Further, we construct a benchmark of $40{,}025$ held-out clips from six public datasets spanning diverse actions, assessing six complementary dimensions under a common evaluator and scoring protocol. Our model substantially outperforms state-of-the-art methods in both quantitative and qualitative evaluations. Remarkably, Timo surpasses Kimodo on five of six dimensions, achieving a $40.8$% relative improvement in the average benchmark score. Project page: https://kyfafyd.wang/projects/timo. Demo page: https://timo.kyfafyd.wang.

## 1. 核心问题与研究背景

- **任务背景**：人体运动生成（HMG）要把一段文本描述转成语义恰当、时间上连贯的姿态序列。
- **现有方法的瓶颈**：主流做法用**交叉注意力**注入文本语义，或把语言特征池化成全局条件。交叉注意力中运动 query 读取固定的文本特征，但**同一交互不会反向更新文本状态**，这种单向条件限制了文本与运动 token 的联合精炼，也限制了文本理解。
- **自然想法与失败**：多模态扩散 Transformer（MMDiT）在视觉生成中已证明能有效做文本—视觉联合建模，因此将其迁移到 HMG 是顺理成章的下一步。
- **关键发现（本文动机）**：关节式运动与视觉数据不同——
  - 相邻关节角色不同、朝向不必相似；但每个关节必须随时间连贯演化。
  - 实测数据：**同一关节相邻帧相关性 0.96，同一帧相邻关节相关性仅 0.14**。
  - 直接迁移 MMDiT + 流匹配会**提升速度但破坏平滑性**（Smoothness 从 80.1 掉到 52.5），父子关节角速度相关性仅 0.25（真实动捕为 0.54），结果是单帧姿态看似准确、整体却**协调性差、抖动明显**。
- **整体含义**：Timo 提出一个**运动学感知（kinematics-aware）的 MMDiT 框架**，把双向语义交互与面向关节协调、时间连贯的监督结合起来，并配套构建统一的多数据集评测基准。

## 2. 方法论

### 2.1 核心思想
用**完全共享参数**的 MMDiT 做文本—运动双向建模 + 流匹配预测显式人体参数；再用**几何损失**约束解码后的身体形态、用**旋转运动学损失**约束关节旋转及其随时间的变化；最后用**两阶段课程**从广泛运动学习过渡到细粒度描述对齐（骨干与目标函数不变）。

### 2.2 运动表示
- 保留 **SMPL 参数**（无需学习式运动解码器即可获得身体几何），每帧 151 维、30 fps：
  - θₜ：21 个身体关节的**连续 6D 旋转**（126 维）；βₜ：形状系数（10 维）；rcₜ / rgvₜ：相机系与重力对齐系下的根朝向（各 6 维）；vₜ：体坐标系根速度（3 维，解码时积分得平移）。
- **用根速度而非根位置**，避免依赖窗口任意全局起点；重力对齐朝向为根损失提供竖直参考。
- 各通道标准化，标准差截断为 1，防止近常数通道被放大成噪声。
- **足部接触单独监督**：由去噪器特征上的辅助头预测 6 个接触 logit，而非作为二值通道采样，既塑造共享特征又不增加采样变量。

### 2.3 双向 token 交互
- 冻结的 **T5-3B** 编码文本，每条描述 ≤50 个 token 嵌入，训练时预计算。
- 文本与运动经**各自输入投影**映射到公共特征空间，拼接序列 `[h_mot ; h_txt]` 送入 **24 个宽度 1024、16 头的 Transformer 块**，共 **495M 参数**；输出头只读取运动 token。
- **每个块共享 QKV 投影、FFN 权重与 adaLN**：文本 query 可读取运动状态，运动 query 也可读取文本状态。这与双流联合注意力不同——差异在**参数共享**，而不只是双向性。
- 运动 token 用 **RoPE** 编码相对帧位置；文本保留编码器上下文信息，不把词索引映射到运动时间轴。
- 逐头对 Q/K 做 **RMS 归一化**，稳定 bf16 训练下的注意力尺度。
- **共享调制**：全局条件作为 token 级联合注意力的补充而非替代。写 c = emb(t) + pool(h_txt)，每块由 c 产生 6 个调制向量，按 adaLN-zero 形式应用 `h ← h + γ⊙Attn(mod(LN(h),μ,σ))`、`h ← h + γ⊙MLP(...)`，其中 `mod(h,μ,σ)=(1+σ)⊙h+μ`，门控 γ 零初始化；FFN 为隐藏宽度 2752 的 SwiGLU；输出投影同样零初始化，使干净运动输出从零开始。

### 2.4 运动学感知流匹配
- **流匹配**：数据分布与 N(0,I) 之间做 rectified flow，线性插值 `xₜ=(1−t)x₀+tε`；网络**直接预测干净样本 x̂₀**（而非速度场），对应速度 `v̂ₜ=(xₜ−x̂₀)/t`。直接预测使输出即干净估计，可转换为旋转并经前向运动学评估。
- **重建项**：`L_rec = E[w(t)‖x̂₀−x₀‖²_M]`，权重 `w(t)=min(SNR(t),γ)/Z`，γ=5，Z 为按 batch 归一化，范数掩码到有效帧。截断是为避免 t→0 端主导梯度、把容量耗在近乎平凡的去噪问题上。
- **时间结构监督**：逐帧重建不直接约束姿态间的变化（缓慢漂移与交替抖动可获同等惩罚）。因此在 SO(3) 上比较**实际相对旋转**及其时间变化：
  - 体坐标系角增量 `ωₜ = Log(Rₜᵀ Rₜ₊₁)`，其差分 `Δωₜ = ωₜ₊₁ − ωₜ`。
  - 相对旋转目标对任意常数参考旋转 G 不变：`(GRₜ)ᵀ(GRₜ₊₁)=RₜᵀRₜ₊₁`；绝对根项仍监督重力对齐朝向。
  - `L_kin` 用 Huber 损失（β=0.05），根为绝对朝向/速度/加速度，权重 (5,10,10)；每个身体关节为速度/加速度，权重 (1,1)。根权重更大，因为根误差影响全身。
  - 注意：这些目标描述的是**旋转运动学**，不是力或力矩。
- **几何监督 `L_geo`**：3D 关节与顶点重建、2D 重投影、平移、接触交叉熵，均在前向运动学后的 x̂₀ 上评估。
- **总目标** `L = L_rec + L_kin + L_geo`，两阶段训练目标不变；训练时以 0.1 概率丢弃描述以训练无条件下分支（用于引导）。
- **推理**：二阶 UniPC，**8 步**，分类器无关引导（CFG）**尺度 2.5**。

### 2.5 两阶段课程
- **Stage 1（粗粒度）**：从几何过滤后的数据学习广泛运动结构，包含异构描述与长时室内录制（StudioTake），按**窗口数量**采样，无细粒度层的每语料/动作频率上限。
- **Stage 2（细粒度）**：从 Stage 1 权重出发，在六个公开句子标注语料 + 短录制（StudioClip）上精炼对齐，设每语料 30k 上限、批内 15% 运动类上限、StudioClip 5× 上采样；无粗粒度层回放，优化器与调度重启。
- 两阶段仅改变**监督分布**，不改变任务或表示。
