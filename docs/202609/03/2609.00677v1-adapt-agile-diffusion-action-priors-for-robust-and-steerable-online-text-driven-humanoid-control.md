## 摘要
我们提出ADAPT，一个用于交互式、文本条件的人形全身控制的端到端框架。与主流的文本到运动流水线（为单独跟踪器生成运动学动作）不同，ADAPT通过端到端闭环控制框架解决语言控制问题，机器人必须在保持平衡、自然运动和平滑过渡的同时，持续响应不断变化的命令。ADAPT从文本标记的人形状态-动作轨迹中学习基于扩散的动作先验，使得多样化的运动技能能够直接从语言命令执行。为了提高长期鲁棒性和平滑的提示切换，我们在冻结的扩散控制器之上训练一个轻量级残差强化学习策略。我们进一步证明，同一个扩散策略可以复用为可操控的文本条件运动先验，用于下游任务适应。实验证明了鲁棒的语言基础技能执行、平滑的交互式过渡以及风格保持的下游控制。

## Abstract
We present ADAPT, an end-to-end framework for interactive, text-conditioned humanoid whole-body control. Unlike dominant text-to-motion pipelines that generate kinematic motions for a separate tracker, ADAPT solves language control with an end-to-end closed-loop control framework, where the robot must continuously respond to changing commands while maintaining balance, natural motion, and smooth transitions. ADAPT learns a diffusion-based action prior from text-labeled humanoid state-action trajectories, enabling diverse motion skills to be directly executed from language commands. To improve long-horizon robustness and smooth prompt switching, we train a lightweight residual reinforcement learning policy on top of the frozen diffusion controller. We further show that the same diffusion policy can be reused as a steerable text-conditioned motion prior for downstream task adaptation. Experiments demonstrate robust language-grounded skill execution, smooth interactive transitions, and style-preserving downstream control.

**研究背景与动机：**
- 当前文本到运动（text-to-motion）领域的主流范式为**两阶段流水线**：先生成运动学轨迹，再交给独立的跟踪控制器执行。
- 这种范式存在明显的结构性缺陷：生成和控制在两个阶段中松散耦合，运动学输出与机器人动力学之间缺乏因果反馈，导致机器人面对在线语言命令变化时，难以在**维持平衡、保持自然动作、平滑切换**的同时持续响应指令，也无法真正用于交互式全身控制。

**核心问题：**
> 如何实现真正的**端到端、闭环、文本条件的人形全身控制**——让机器人能持续接收语言指令，并鲁棒地执行多样化运动技能、平滑地切换任务？

**整体研究意义：**
- 将语言控制从"离线的运动生成"推进到"在线的闭环控制"，为人形机器人在真实/仿真环境中接受自然语言指令交互提供了新的端到端方案。
- 提出可复用的扩散动作先验，不仅直接用于语言执行，还可作为下游任务的运动先验被灵活复用，拓展了文本控制方法的应用边界。

## 2. 论文提出的方法论

**核心思想：**
ADAPT 放弃"先轨迹后跟踪"的流水线，改为**直接从文本标记的状态-动作轨迹中学习扩散动作先验**，让控制器本身具备语言条件生成动作的能力，并以"冻结扩散控制器 + 轻量残差强化学习"的组合方式实现长期鲁棒和指令平滑切换。

**关键设计层次：**

1. **扩散动作先验（Diffusion Action Prior）**
   - 从带文本标注的人形状态-动作交互数据中训练扩散模型。
   - 输入：当前机器人状态 + 语言指令（作为条件）；输出：直接的动作（而非运动学轨迹）。
   - 由于在动作空间上学习，无需依赖外部运动跟踪器，实现端到端的语言-动作映射。

2. **残差强化学习策略（Residual RL Policy）**
   - 扩散控制器作为先期冻结模块，不参与 RL 训练。
   - 在其输出动作之上叠加一个轻量残差策略，通过强化学习优化长期收益（如长期稳定、平衡保持、命令切换平滑性）。
   - 残差结构保证不破坏扩散先验学到的语言技能表达，仅补偿其长期闭合回路响应不足的问题。

3. **可操控运动先验复用（Steerable Motion Prior）**
   - 同一个扩散策略在任务适应阶段被复用为文本条件运动先验，供下游策略跟随。
   - 这种先验为下游任务（如导航、物体交互）提供**风格保持的自然运动引导**，使下游策略保持人体自然韵律的同时完成新任务。

**方法亮点总结：**
- 不追踪外部运动学轨迹，而直接以动作空间为输出空间；
- 扩散模型处理语言条件的多模态动作分布——同一指令可对应多种合理动作；
- 冻结先验 + 残差强化学习 → 保留多样性、提升鲁棒；
- 先验可复用 → 下游任务只需学习"任务目标"而无需重新学习"如何像人一样动"。
