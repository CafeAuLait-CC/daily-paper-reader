tldr: 流匹配模型在迭代预测速度时，通常不会利用产生该预测的中间表示进行自我修正。CorrFlow 通过轻量 refiner 复用同一次前向中的干净预测、条件、噪声水平和隐藏状态，学习残差修正并加到基础速度上，使后续采样从修正状态继续。理论上给出特征复用优于原始输入仿射预测器的条件，并在匹配训练算力下证明 refiner 训练比继续训练基模型更能降低残差风险。在类条件图像、文本到视频和图像到视频生成上，方法无需额外基模型评估，仅每步一次轻量修正，即取得视觉质量与物理一致性提升。

## 摘要
流匹配模型通过迭代速度预测生成样本，但通常不会利用产生这些预测的中间表示来重新审视这些预测。我们提出 CorrFlow，一种自校正流匹配框架，它通过轻量级精化器复用这些信息。在整流流插值下，单步干净预测的误差等于实际速度残差按噪声水平缩放。受此恒等式启发，精化器学习从基础模型的干净预测、条件、噪声水平以及同一前向传播中的隐藏状态预测残差校正。每次采样更新前，将校正加到基础速度上，因此后续预测基于校正后的状态进行。这不需要额外的基础模型评估，且每步仅需一次轻量级精化器评估。我们的理论分析建立了特征复用优于原始输入仿射预测器的条件，并表明在匹配的训练计算预算下，精化器训练比继续训练基础模型能实现更大的残差风险降低。在类别条件图像生成、文本到视频生成和图像到视频生成上的实验表明，相较于相应的基础模型具有一致的改进，包括视觉质量和物理一致性的提升。项目页面：https://fogradio.github.io/corrflow-project

## Abstract
Flow-matching models generate samples through iterative velocity predictions, but typically do not revisit these predictions using the intermediate representations that produced them. We introduce CorrFlow, a self-correcting flow-matching framework that reuses this information through a lightweight refiner. Under rectified-flow interpolation, the error of the one-step clean prediction equals the realized velocity residual scaled by the noise level. Motivated by this identity, the refiner learns to predict residual corrections from the base model's clean prediction, conditioning, noise level and hidden states from the same forward pass. The correction is added to the base velocity before each sampling update, so subsequent predictions are made from the corrected state. This requires no additional base-model evaluations and only one lightweight refiner evaluation per step. Our theoretical analyses establish conditions under which feature reuse outperforms raw-input affine predictors and refiner training achieves greater residual-risk reduction than continued base-model training under a matched training compute budget. Experiments on class-conditional image generation, text-to-video generation and image-to-video generation show consistent improvements over the corresponding base models, including gains in visual quality and physical consistency. ## 1. 核心问题与研究动机

- **背景**：流匹配（Flow Matching）模型通过迭代预测速度场，将噪声传输到数据分布，已在图像、视频、3D、机器人动作等生成任务上取得强结果。但生成内容仍存在结构错误、语义不匹配和物理不一致等问题。
- **关键痛点**：现有改进路线（扩大训练规模、表征对齐、自监督特征学习、奖励优化）大多只从"最终答案"学习。模型在每一步必须仅凭一次速度预测决定下一状态，**没有机会回看并修正自己的预测**，也没有利用产生该预测的中间表示（隐藏状态）。
- **核心洞察**：流匹配采样每一步其实已经具备类似 LLM 自精炼所需的三类信息——干净样本估计（"答案"）、生成条件（"问题"）、中间隐藏状态（"推理过程"）。问题在于如何定义一个**训练时可监督、生成时无需干净参考即可预测**的校正目标。
- **论文含义**：提出 CorrFlow，把"refine-in-loop"（在采样循环内逐步修正）思想引入流匹配，通过轻量精化器复用基模型同一次前向的信息来预测速度残差，从而在不增加基模型评估的前提下提升生成质量。

## 2. 方法论

### 2.1 核心理论依据：干净预测恒等式

- 整流流插值：\(x_\sigma=(1-\sigma)x_0+\sigma\varepsilon\)，目标速度 \(v=\varepsilon-x_0\)，实际速度残差 \(r=v-v_\theta(x_\sigma,\sigma,c)\)。
- 一步欧拉干净预测：\(\hat{x}_0=x_\sigma-\sigma v_\theta\)。
- 关键恒等式：\(\hat{x}_0-x_0=\sigma r\)，即 **干净预测误差 = 噪声水平 × 速度残差**。
- 意义：把"预测样本的错误"与"速度场的校正"直接联系起来，使 \(\hat{x}_0\) 成为精化器的主输入，且残差 \(r\) 可在训练时由采样得到的 \((x_0,\varepsilon)\) 构造为监督目标。

### 2.2 精化器输入（三类信息）

- **当前答案**：一步干净预测 \(\hat{x}_0\)，按样本结构（图像 patch、视频时空 patch）token 化为答案 token。
- **情境**：条件 token \(c\)（类别/文本）与基模型自身的噪声水平嵌入 \(e_\sigma\)。
- **内部状态**：从基模型若干 Transformer 层（跨深度均匀选取，如图像选第 3/11/19/27 层）读取的隐藏状态 \(\{h_\ell\}\)。

### 2.3 架构设计

- 精化器为轻量 Transformer，参数量约为基模型的 **10%**，输出投影零初始化（初始校正为零，训练稳定）。
- **跨层隐藏状态融合**：在每个 token 位置把选中层的隐藏状态拼接，经 GELU MLP 投影到精化器宽度。这样隐藏状态 token 数保持为 \(N\) 而非 \(|L|\cdot N\)，注意力成本不随读取层数增长，同时让网络自行学习"每个位置该信任哪一层"。
- **上下文 token**：条件 token 与融合后的隐藏状态 token 拼接，加可学习 segment embedding 与 LayerNorm。
- **交替注意力块（AAB）**：偶数块对答案 token 做自注意力（图像用 2D、视频用 3D RoPE）；奇数块对上下文 token 做交叉注意力；每块用 \(e_\sigma\) 经 AdaLN 调制 shift/scale/gate；末端调制线性头输出残差并还原样本形状。

### 2.4 训练与推理

- **联合训练**：基模型与精化器在同一 minibatch 上各用各的目标、单次反向传播。
- 精化器损失：\(\mathcal{L}_{ref}=\mathbb{E}\big[\|\hat r-\mathrm{sg}[r]\|^2+\lambda(1-\cos(\hat r,\mathrm{sg}[r]))\big]\)，均方项拟合幅值与方向，余弦项在方向不一致时显式奖励对齐；总损失 \(\mathcal{L}=\mathcal{L}_{base}+\lambda_{ref}\mathcal{L}_{ref}\)，残差目标与基模型输入均 stop-gradient。
- **推理**：每个去噪步，基模型前向一次，捕获 \(e_\sigma\)、\(\{h_\ell\}\)，组装 \(\hat{x}_0\)，精化器前向一次得 \(\hat r\)，修正速度 \(v_\kappa=v_\theta+\kappa\hat r\) 交给采样器积分。
- **开销**：无额外基模型评估，每步仅多一次轻量精化器前向；由于修正改变后续状态，校正会沿轨迹累积影响后续精化器输入。

### 2.5 理论分析（三条主线）

- **冻结特征优势**：在条件高斯 XOR 构造下，证明复用隐藏特征的单参数精化器可精确表示条件贝叶斯残差，而原始输入仿射预测器存在不可消除的间隙 \(\Delta_{aff}\)；当余弦正则与优化容差满足 \(2\lambda+\epsilon_{opt}<\Delta_{aff}\) 时，训练所得精化器严格优于任意原始输入仿射类。
- **匹配算力分离**：在有限账本、局部 Jacobian/稳定性条件下，比较"训练精化器"与"继续训练基模型"两种方案的残差风险下降，给出切线近似与有限步扰动误差界，证明前者可严格更优。
- **自身采样律下的改进**：耦合基模型与校正模型的轨迹，证明在增益 \(\kappa<\bar\kappa\) 且 \(\kappa<M/N\) 时，校正采样器在其**自身诱导的状态律**下速度误差严格低于基采样器；附录进一步给出端点位移的精确增益二次型与最优增益 \(\kappa^\star=A/B\)。
