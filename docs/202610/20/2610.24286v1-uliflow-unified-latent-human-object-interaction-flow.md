## 摘要
文本条件的三维人-物交互（HOI）生成仍具挑战性，因为单独看似合理的人体和物体运动未必能构成连贯的交互。我们认为一个关键局限在于传统的基于骨架的表示：它们紧凑地描述身体运动学，却使表面层面的交互几何在很大程度上保持隐式，往往需要额外的接触特定正则化项。我们提出 ULIFlow，一个在统一潜在空间中显式建模连续人-物关系的框架。为此，我们从稀疏的人体表面标记点中推导连续的标记点-物体关系，并将其与人体运动和物体动力学一起视为一种显式的交互模态。随后设计了一个混合 Transformer（Mixture-of-Transformers, MoT）自编码器，以联合建模这些异构流，同时保留其模态特定的结构。重要的是，我们让关系流直接参与人体和物体重建，促使共享潜在表示同时保留各自的动力学以及协调二者的交互几何。为进一步实现可变长度生成，我们引入了一种带全局序列进度条件的逐块 Flow Forcing 方案，使其能够从固定长度训练窗口渐进式延续，同时保持一致的长时程动力学。大量实验表明，ULIFlow 在整体生成质量和人-物协调方面持续优于先前工作，并能在超出训练时程的所需时长内保持连贯交互。

## Abstract
Text-conditioned 3D human--object interaction (HOI) generation remains challenging because individually plausible human and object motions do not necessarily form a coherent interaction. We argue that a key limitation lies in conventional skeleton-based representations, which compactly describe body kinematics while leaving surface-level interaction geometry largely implicit, often requiring additional contact-specific regularizers. We propose ULIFlow, a framework that explicitly models continuous human--object relations within a unified latent space. To this end, we derive continuous marker--object relations from sparse body-surface markers and treat them as an explicit interaction modality alongside human motion and object dynamics. A Mixture-of-Transformers (MoT) autoencoder is then designed to jointly model these heterogeneous streams while preserving their modality-specific structures. Importantly, we let the relation stream directly participate in human and object reconstruction, encouraging the shared latent representation to preserve both individual dynamics and the interaction geometry that coordinates them. To further achieve variable-length generation, we introduce a blockwise Flow Forcing scheme with global sequence-progress conditioning, enabling progressive continuation from fixed-length training windows while maintaining consistent long-horizon dynamics. Extensive experiments demonstrate that ULIFlow consistently outperforms prior work in overall generation quality and human--object coordination, while preserving coherent interactions over requested durations beyond the training horizon.

## 1. 核心问题与研究动机

- **任务背景**：文本条件的三维人–物交互（HOI）生成，即根据语言描述与目标时长，同时合成人体运动与刚体物体轨迹。已有工作多聚焦"生成交互的另一半"（如 OMOMO、DAViD 给定物体生成人体），而**人体与物体运动的联合生成**仍相对欠缺。
- **核心痛点**：单独看合理的人体运动与物体运动并不等于连贯交互——简单拼接两条轨迹常出现**空间错位**与**频繁穿模**，作者将这种现象定义为缺乏"协调性（coordination）"。
- **对现有做法的批评**：
  - 一类方法依赖**手工规则/运动学约束**（接触、可供性引导），需大量任务特定假设与人工设计；
  - 另一类方法尝试**联合建模**（交互 tokenization、模态感知融合），但仍会出现物理伪影，说明"把两条轨迹放在一起建模"本身不足以保证连贯交互。
- **作者的核心诊断（本文最关键的论点）**：问题根源在于长期沿用**纯骨架表示**。骨架紧凑地描述身体内部运动学，但**接触发生在体表**，表面级交互几何在潜空间中被弱编码，因此不得不额外引入接触正则化。
- **研究问题**：能否在共享潜空间中同时建模人体运动、物体动力学与二者**连续几何关系**，使复杂接触模式直接从数据中学到，而无需接触专用正则？
- **整体含义**：把"交互几何"提升为与人体、物体并列的**第三种显式模态**，从而在潜空间层面而非损失函数层面解决协调性问题。

## 2. 方法论

### 2.1 总体思路
- 三流建模：人体流 `H`（体表标记点轨迹）、物体流 `O`（平移 + 6D 连续旋转）、**关系流 `R`（由 H、O 解析推导）**。
- 两阶段范式：先训练**统一潜空间自编码器**（MoT 结构），再在潜空间上用 **Flow Matching + DiT** 做条件生成，并用**分块 Flow Forcing** 实现变长滚动生成。

### 2.2 连续关系表示（核心创新）
- **局部关系**：对每个体表标记点 `p^H_{t,j}` 找物体表面最近点 `s^O_{t,j}`，定义偏移 `δ_{t,j} = s^O_{t,j} − p^H_{t,j}`、距离 `d_{t,j} = ‖δ‖₂`，并加入一阶/二阶时间差分 `∇δ`、`∇²δ`，以及在**物体规范坐标系**下的最近点 `s̄^O_{t,j}`（记录"接触发生在物体何处"）。
- 单帧局部特征：`r_{t,j} = (δ, d, ∇δ, ∇²δ, s̄^O)`；并额外把同一构造用于**物体–地面**对（`q^gnd = Π_gnd(p^O)`），得到 `r^gnd_t`。
- **全局关系**：以人体根代理 `p^root = N⁻¹Σ p^H` 与物体中心的相对量 `γ_t = p^O − p^root`、`ρ_t = ‖γ‖` 及其时间变化构成 `r^global_t`。
- 合并得 `R = (R_local, R_global)`。**关键性质：R 完全由 H、O 推导，无需接触标注或伪标签**，因此可作为稠密几何监督。

### 2.3 Tokenization（结构化 token 流）
- 人体：8 个学习的**身体区域 query** 聚合 77 个标记点 + 独立 root token + 左右 foot token = **11 token/帧**。
- 物体：**1 个动态位姿 token/帧** + **4 个静态几何 token**（BPS 基点点集描述符）。
- 关系：8 个关系 query 聚合标记点级关系 + 物体–地面 + root–物体 = **10 token/帧**。
- 加入模态/实体/区域身份编码；仅动态 token 施加**时间 RoPE**。
- **时间压缩**：以 `K = min(32, ⌈T/4⌉)` 选时间锚点，混合准则按 0.5（均匀覆盖）/0.3（关系显著性）/0.2（运动能量）分配；锚点通过**门控注意力**吸收全时段上下文。128 帧窗口 → 708 个 token，再投影到 `d_z = 16`。

### 2.4 MoT 自编码器
- 编码：`Z = N_EMA(E_MoT(X_H, X_O, X_R))`；解码：`(Ĥ, Ô, R̂) = D_MoT(Z)`。
- 四条计算路径（人体动态、物体位姿、静态物体几何、关系动态），**共享注意力 + 路径私有 LayerNorm/FFN**；注意力以本路径为 query、全部路径拼接为 key/value。
- **关系耦合解码（重要设计）**：关系特征不只是一个辅助重建目标，而是被注入人体与物体 readout，先由关系 query 汇聚各流特征，再让标记点 query 与物体位姿 query 读取关系条目，最后经帧级耦合块统一更新三流。
- **潜空间稳定化**：通道级 EMA 归一化（动量 0.99）+ 协方差正则 → 自编码器训练后用训练潜变量估计 **ZCA 白化**变换 `W`，Flow 模型在 `z_white` 空间优化，解码前用固定逆变换还原。
- **噪声鲁棒解码器微调**：冻结 tokenizer 与编码器，仅微调解码器；在白化空间加高斯扰动（σ 从 0 线性增至 0.125，前 2000 步为 0，共 30k 步），25% 样本保持干净；并加入有限差分速度/加速度损失（系数 0.5 / 0.25）。

### 2.5 条件潜空间 Flow 与变长生成
- 速度场：`v_ψ(Z_τ, τ | c, G, p) = F_ψ(Z_τ; c, G, τ, p)`，DiT 参数化。
- **全局序列进度条件 `p ∈ [0,1]`**：表示当前窗口在目标时长中的归一化位置，训练与推理定义一致，解决"固定窗口在长序列中处于不同阶段导致上下文不一致"的问题。
- **分块 Flow Forcing（对 Diffusion Forcing 的改造）**：不同于 token 级噪声，本文以**时间块**为单位共享一个独立采样的 flow time `τ_b ~ U(0,1)`（每块 8 个锚点），使模型见到"部分已解、部分仍噪声"的因果历史；配合**块因果注意力掩码**（块内双向、块间单向）。
- 损失：
  - 自编码器 `L_AE = λ_H L_H + λ_O L_O + λ_R L_R + λ_world L_world + λ_cov L_cov`，各场用 masked Smooth L1（λ_H=λ_O=λ_world=1，λ_R=2，λ_cov=1e-2）。
  - Flow 匹配 `L_FM`：对每个有效潜 token 采样 `ε`，构造 `z(τ)=(1−τ)ε+τz`，目标速度 `u = z − ε`，回归 `‖v_ψ − u‖²` 在有效 token 集 Ω 上平均。
- **推理（交错滚动）**：窗口含 `w` 块、其中 `h` 块为已完成的历史；每块分配 `S` 步，块间错开 `Δ = ⌈S/(w−h)⌉`，`τ_b(k) = clip((k−(b−1)Δ)/S, 0, 1)`，Euler 更新；最早块到达数据端点后转为固定上下文、窗口前移；静态几何潜 token 只在首个块调度中积分后固定；解码时用重叠窗口解码、按时间拼接、裁剪到恰好 `T` 帧。

- **生成质量**：ULIFlow 在 InterAct 上 FID 达 **0.812**（优于 InterAct 1.768、LIGHT 8.054、CHOIS 6.914 等），MM-Dist 与多样性接近真值分布；BEHAVE（FID 3.396）与 OMOMO（FID 1.367）子集上保持同类趋势。
- **物理协调**：穿透率降至 **0.003**（与真值 0.003 持平，InterAct/LIGHT 为 0.006），均值/P95/最大穿透深度均更低；关系通路消融显示接触召回从 **51.1% → 69.7%**、手部召回 46.2% → 68.9%、接触距离 4.04 → 2.70 cm、无支撑位移 50.8% → 28.6%、关系速度差 0.144 → 0.030 cm/帧，说明

，说明关系流并非仅提升重建指标，而是**实质性改善接触质量**：接触更准、更近、更少"凭空悬停"式退化解，且接触点的相对运动更一致（速度差降低约 5 倍）。

- **长时程生成**：在 128 帧不重叠子序列与跨续接边界的 64 帧窗口上，ULIFlow 的 FID、Diversity、Peak Jerk 与 AUJ 均优于固定窗口基线；**分块 Flow Forcing + 全局进度条件**的组合是长序列不漂移、不突跳的关键——去掉任一组件，边界处 jerk 峰值与 FID 明显上升。消融还显示该机制在 128/256/384 三种目标时长上均带来一致增益，而非仅在训练长度上有效。
- **架构与表示消融**：MoT（共享注意力 + 路径私有归一化/FFN）优于"单流拼接"与"完全分离"两种极端；关系分支的引入在参数量小幅增加的前提下，同时降低人体、物体与关系的重建误差，并提升潜空间**有效秩**（表示更充分、更少坍缩），佐证"交互几何应作为独立模态"这一核心主张。潜空间正则（EMA 归一化 + 协方差 + ZCA 白化）主要贡献于生成阶段的稳定性与对采样噪声的容忍度。
- **解码鲁棒性**：随潜扰动 σ 从 0 增至 0.2，各场重建误差平缓上升而无崩溃，验证噪声鲁棒微调使解码器能在 Flow 采样产生的"非完美潜变量"上工作——这是两阶段范式常见的性能断崖点，本文显式处理了它。
- **效率**：运行时随请求长度近似线性增长，128 帧下达到可用帧率，显存峰值随长度温和上升；交错滚动 + 重叠窗口解码避免了整段序列一次性注意力的二次复杂度，使 512 帧级请求在单卡上可行。

## 7. 贡献总结与定位

- **概念层面**：提出把"人–物连续几何关系"作为与人体运动、物体动力学并列的**第三模态**显式建模，将协调性问题的求解位置从"损失函数/后处理约束"前移到"表示与潜空间"，是对"纯骨架表示不足"这一诊断的直接回应。
- **技术层面**：① 无需接触标注、可由 H/O 解析推导的稠密关系表示（含局部最近点偏移及其时间导数、物体规范系接触位置、物体–地面关系、全局相对位姿）；② 结构化 token 流 + 关系耦合解码的 MoT 自编码器；③ 带全局序列进度条件的分块 Flow Forcing，实现变长、边界平滑的滚动生成；④ 白化潜空间 + 噪声鲁棒解码器，缓解两阶段范式的训练–推理失配。
- **实证层面**：在 InterAct 主基准与 BEHAVE/OMOMO 子集上同时改善生成质量与物理协调指标，且消融链条完整、结论在多个数据源上一致。

## 8. 局限与可改进方向

- **物理正确性的评价仍以几何代理为主**：穿透与接触基于 SDF/最近点阈值，未涉及力、摩擦、质量等真实动力学，也未做物理仿真可行性验证；"接触召回提升"不等于"交互在物理上可实现"。
- **依赖体表标记点表示**：方法在 InterAct 的 77 标记布局上原生设计，向 SMPL-X 顶点级、手部细粒度（手指关节）或非人形灵巧操作扩展时，最近点查询与 token 聚合的开销与有效性需重新评估。
- **单物体、刚体假设**：未覆盖多物体、可变形物体、工具链式交互等更复杂场景。
- **缺少人类主观评价与下游任务验证**：无 user study、无"生成结果驱动虚拟角色/机器人"的闭环实验，感知层面的自然度结论仅由 FID 等分布指标间接支撑。
- **对比公平性的边界**：基线仅在各自支持的子集上评测、长时程基线本身为固定窗口方法，这两点作者已声明，但读者解读主表排名时应保留余地。
- **算力与可复现细节**：未报告墙钟训练时间与总 GPU 小时；关系表示的最近点查询在训练中的实际开销、数据预处理管线细节对复现成本影响较大。
- **可探索方向**：将关系流扩展为"接触图/多实体关系图"以支持多物体；把几何关系与轻量物理约束（如接触冲量一致性）结合；以关系表示为接口做跨具身迁移（人体 → 机械臂/灵巧手）。

## 9. 一句话评价

ULIFlow 的核心价值不在于某个模块的堆叠，而在于给出了一个**清晰的因果诊断（纯骨架丢失表面交互几何）→ 对应的表示层解法（把关系作为第三模态）→ 贯穿表示、架构、生成调度与解码的系统实现**，并用覆盖质量、物理、时序、效率的多维消融支撑了该论点的自洽性；其主要短板在于物理评价仍停留在几何代理层面、场景假设偏窄（单刚体、标记点表示），以及缺少主观与下游验证。
