## 摘要
由于需要保持时间连贯性和一致的风格，长时程协同语音动作生成仍然具有挑战性。现有方法通常逐段生成长时间动作：要么以近期若干帧构成的短种子为条件，这会逐渐漂移；要么保留越来越长的显式历史，这既难以维护，又难以从有限数据中学习。我们将这些局限归因于过去与当前之间的关键不对称性：过去动作携带缓慢变化的风格，应被紧凑地概括；而当前片段表现出快速变化的局部动态，需要细粒度建模。这种不对称性启发了长时程协同语音动作生成中的一条简单原则：过去作为状态，当前作为注意力。遵循该原则，我们提出 PASPA，它用块间持久状态概括过去历史，并用块内双向自注意力对当前片段建模。我们在分块流匹配框架中实例化 PASPA，采用多块监督以在变化历史上有效训练，采用预填充-解码状态缓存以实现高效推演，并采用混合无分类器引导以增强历史与语音条件。大量公开基准实验表明，PASPA 取得了最先进的 FGD 性能，并在长序列生成中保持动作风格。

## Abstract
Co-speech motion generation remains challenging over long horizons due to the need for temporal coherence and consistent style. Existing methods typically generate long motions segment by segment, either conditioning on a short seed of recent frames, which gradually drifts, or retaining ever-longer explicit histories, which are costly to maintain and hard to learn from limited data. We trace these limitations to a key asymmetry between past and present: past motion carries slowly varying style that should be compactly summarized, whereas the current segment exhibits fast-changing local dynamics that require fine-grained modeling. This asymmetry motivates a simple Past-As-State, Present-as-Attention principle for long-horizon co-speech motion generation. Following this principle, we propose PASPA, which summarizes past history with an inter-block persistent state and models the current segment with intra-block bidirectional self-attention. We instantiate PASPA within a blockwise flow matching framework, with multi-block supervision for effective training over variable histories, prefill-decode state caching for efficient rollout, and hybrid classifier-free guidance for enhanced history and speech conditioning. Extensive public-benchmark experiments show that PASPA achieves state-of-the-art FGD performance and preserves motion style across long-sequence generation.

- **任务背景**：协同语音动作生成（co-speech motion generation）旨在根据语音合成与语音在时间上对齐、在语义上一致的全身动作与面部表情，广泛应用于数字人、虚拟助手、动画角色等场景。
- **核心痛点：长时程生成**。逐段（block-by-block）生成是主流做法，但段间历史传播（inter-block history propagation）成为瓶颈：
  - **短种子截断（Short-Seed Truncation）**：仅以最近几帧为条件，时间连贯性与说话人风格会逐渐漂移（如手势高度单调下降）。

- **关键洞察（论文的核心动机）**：过去与当前存在**本质不对称性**——
  - 过去主要承载**缓慢变化的风格**（手势幅度、空间偏好等），应被紧凑概括；
  - 当前片段包含**快速变化的局部动态**（速度、细粒度关节），需要全分辨率、双向的细粒度建模。

### 2.1 核心思想
- 将协同语音动作生成形式化为半自回归的块因果分解：\(p(x|a,e)=\prod_{n=1}^{N} p(x_n \mid x_{<n}, a_n, e_n)\)。
- 段间用**块间持久状态**压缩历史（跨段递归、固定大小）；段内用**块内双向自注意力**做稠密交互。两者串接为 PASPA 层。

### 2.2 块间持久状态：Blockwise Gated DeltaNet (BGDN)
- 基于 **Gated DeltaNet (GDN)**，利用其门控（α）与 delta 规则（β）更新带来的**时间衰减归纳偏置**，抑制瞬时波动、累积风格趋势，适配数据有限场景。
- 状态更新沿用 GDN：
  \(S_i = S_{i-1}\big(\alpha_i (I-\beta_i k_i k_i^\top)\big) + \beta_i v_i k_i^\top\)。
- **块因果读机制（关键改动）**：块内所有 query 只读取**块起始状态** \(o_i = S^0_{[n]} q_i\)（即上一块最终状态 \(S^K_{[n-1]}\)），而非持续更新的 \(S_i\)，从数学上杜绝块内未来信息泄漏。
- 输入噪声当前块派生 query，编码后的干净历史派生 key/value/门控；去掉 GDN 的时间混合以防跨块泄漏。
- **高效实现**：固定计算 chunk 大小等于生成块大小 K，读取退化为稠密矩阵乘 \(O_{[n]} = Q_{[n]}(S^0_{[n]})^\top\)，便于 Tensor Core 加速；基于 FLA 实现自定义 Triton kernel。

### 2.3 块内双向注意力：BMHSA
- 采用**块对角掩码**：块内双向可见，跨块严格屏蔽（\(B^{blk}_{ij}=0\) 若同块，否则 \(-\infty\)）。
- 实现上把 \(X\in\mathbb{R}^{NK\times d}\) reshape 为 \(N\times K\times d\)、以块索引为 batch，复杂度由 \(O((NK)^2 d)\) 降为 \(O(NK^2 d)\)；使用 RoPE。

### 2.4 网络架构
- 沿用 DiT 设计，将自注意力子层替换为 **BGDN → BMHSA** 两个串接子层；用 **AdaRMSNorm** 替代 AdaLN，调制参数来自傅里叶时间步嵌入与说话人 ID 嵌入。
- 遵循 GlobalDiff：冻结的音频到表情网络（WavLM 特征 + 说话人 ID）预测表情；动作在全局旋转空间分为**躯干（含平移）与手部两支**；噪声流嵌入身体部位动作、音频、表情 token，历史流将干净过去编码进每个 BGDN。

### 2.5 分块流匹配（Blockwise Flow Matching）与训练
- 每个块独立插值 \(x^n_{t_n}=(1-t_n)x^n_0+t_n z_n\)，网络直接预测干净块 \(\hat{x}_0\)。
- **多块监督**：一次前向对全部 N 块并行去噪，得到 N 倍稠密监督；不同块用不同噪声水平，暴露模型于"变长历史 + 多样噪声"的组合。
- **稳定化设计**：强制弱单调时间步 \(t_1\le t_2\le\cdots\le t_N\) 以匹配推理噪声剖面；时间采样改用 **logit-normal** 分布（\(\mu=-1.0,\sigma=1.0\)）。
- **损失函数**：旋转 MSE + 前向运动学（FK）关节位置损失 + 骨骼结构损失，配以可学习 MLP \(u(\cdot)\) 的**自适应逐时间步权重**（对 FK 项施加 stop-gradient），并加**边界损失** \(L_{bd}\)（在 2W=8 帧过渡窗口上做旋转、速度、加速度匹配，且不参与自适应加权）。
- 优化：Muon + AdamW 混合优化器（BGDN 归 AdamW），学习率 \(10^{-3}\to10^{-4}\)，梯度裁剪 1.0。

### 2.6 长时程推理
- **Prefill-Decode 与状态缓存**：预填充只编码干净片段更新 BGDN 状态（跳过去噪子层）；解码阶段 S 为只读条件；S 是唯一持久缓存，每步查询复杂度 \(O(1)\)，与历史长度无关。
- **混合无分类器引导（Hybrid CFG）**：四个预测——无条件 \((S_\varnothing,\varnothing)\)、仅条件 \((S_\varnothing,c_n)\)、仅历史 \((S,\varnothing)\)、完整 \((S,c_n)\)——按**多线性组合（Interaction 模式，含二阶联合项）**融合；引导尺度随时间变化，仅在 \(t\in[0.1,0.6]\) 生效。
- 训练端：条件以 10% 概率丢弃；历史状态按 keep 70% / null 10% / 插值 \(\alpha S+(1-\alpha)S_\varnothing\) 20% 采样，支持推理时连续调节历史强度。
