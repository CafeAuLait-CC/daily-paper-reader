生成包含多个物体的人-物交互（HOI）具有挑战性，因为由此产生的运动源于不同的潜在原因。人体运动反映语义意图，被有意操作的物体必须与人保持协调，而周围物体主要作为接触和碰撞的物理结果而运动。我们提出 BUMP，一个基于简单原则的文本驱动多物体 HOI 生成框架：学习意图性运动并模拟物理结果。我们的方法首先根据文本和场景上下文生成全身人体运动，然后在人体运动的条件下预测少量被有意操作的驱动物体的轨迹。随后，我们通过物理模拟获得响应物体的运动，使框架能够处理不同数量和配置的周围物体，而无需扩展学习到的轨迹输出空间。为解决成对全身多物体 HOI 数据稀缺的问题，我们结合了来自纯人体运动、全身 HOI 以及以手为中心的操纵数据的异构监督，并用合理的人体运动进行增强。我们进一步引入结果条件化的交互编辑，它可从期望的响应物体行为推断因果驱动物体轨迹的局部修改，而无需显式的目标驱动物体轨迹。实验表明，该方法在单物体和多物体 HOI 基准上均具有强劲性能。定性结果展示了涉及物体间关系和编辑的多样场景，凸显了我们统一模型表述的优势。

## Abstract
Generating human-object interactions (HOIs) with multiple objects is challenging because the resulting motions arise from different underlying causes. Human motion reflects semantic intent, intentionally manipulated objects must remain coordinated with the human, while surrounding objects move primarily as physical consequences of contact and collision. We present BUMP, a text-driven framework for multi-object HOI generation based on a simple principle: learn intentional motion and simulate physical consequences. Our method first generates full-body human motion from text and scene context, then predicts trajectories for a small number of intentionally manipulated driver objects conditioned on the human motion. We then obtain responder object motions through physics simulation, allowing the framework to handle varying numbers and configurations of surrounding objects without expanding the learned trajectory output space. To address the scarcity of paired full-body multi-object HOI data, we combine heterogeneous supervision from human-only motion, full-body HOI, and hand-centric manipulation data augmented with plausible body motion. We further introduce outcome-conditioned interaction editing, which infers a local modification of the causal driver object trajectory from a desired responder object behavior without requiring an explicit target driver object trajectory. Experiments demonstrate strong performance on both single-object and multi-object HOI benchmarks. Qualitative results showcase diverse scenarios involving inter-object relationships and edits, highlighting the advantage of our unified model formulation.

## 1. 核心问题与研究动机

- **背景**：真实人类活动很少只涉及单个物体（如做饭、打球），通常是一边有意操作一两个物体，一边与周围多个物体发生接触。现有 HOI 生成工作（CHOIS、InterDiff、HOIDiff、InterDreamer 等）多聚焦**单个被操作物体**；近期多物体工作（HIMO、Dex2HOI、PAMotion）虽扩展了物体数量，但把**所有**交互物体的轨迹都作为生成模型的显式输出。
- **核心痛点**：
  - 多物体 HOI 中各类运动的**成因不同**：人体运动体现语义意图；被有意操作的物体须与人保持协调；周围物体主要是接触/碰撞的**物理后果**。将三者对称地塞进一个学习问题，会耦合人体运动、多物体轨迹、接触与物体间关系，导致输出空间随物体数量膨胀。
  - **配对的全身份多物体 HOI 数据稀缺**，难以支撑大规模监督学习。
- **核心主张（整体含义）**：不必对称建模这些复杂性，应遵循“**学习意图性运动、仿真物理后果**”的原则——用一个**因子化（factorized）**框架把交互分解为“人 + 少量驱动物体（driver）+ 物理诱发的响应物体（responder）”，从而让学习到的轨迹空间与周围物体数量**解耦**。

## 2. 方法论

### 2.1 总体形式化

- 输入：文本 ℓ、初始人体姿态 h₁、初始场景 O₀（物体几何与位姿）、响应物体初始化 S⁰_R。
- 输出：(H, D, R)，按因果顺序三阶段求解：
  - **阶段1**：H = G_H(ℓ, h₁, O₀)（扩散 Transformer 生成全身人体运动）
  - **阶段2**：C = P_C(Z_H, Q_D)（接触头预测手–驱动物体接触），D = G_D(H, C, ℓ, O₀)（扩散 Transformer 生成驱动物体轨迹）
  - **阶段3**：R = Sim(H, D, S⁰_R; ψ)（刚体物理仿真产生响应物体运动）

### 2.2 表示与场景设定

- **人体**：T 帧序列，每帧 = 根平移(3) + 22 个身体关节全局旋转(22×6，6D 旋转表示) + 30 个手指关节局部旋转(30×6)；世界坐标由初始帧根节点定义；人体生成器最终隐特征 z_H,t ∈ R¹⁰²⁴。
- **物体**：每个物体 = 1024 点 BPS 编码(256 维) + 初始平移(3) + 展平旋转矩阵(9)；共 N 个物体，**最多 2 个驱动物体**；模型使用 **4 个物体槽位**（保留全部 driver，其余填离人最近的物体），多余物体一律作为 responder 仿真，空槽被 mask。
- **接触查询**：每个被选 driver 一个 3088 维 query（1024×3 原始 BPS + 12 维初始位姿 + 4 维物理槽 one-hot）。

### 2.3 关键技术细节

- **阶段1（人体生成）**：以文本、初始姿态、场景为条件做去噪；每个物体作为独立 token（≤4 个场景 token）。可选地在反向扩散中施加接触/力闭合抓取引导与穿透、时序惩罚——**仅用于定性可视化，不用于定量评测**。
- **阶段2（接触预测 + 驱动物体生成）**：
  - 轻量接触头 P_C 以冻结的 G_H 隐特征与 driver query 为输入，对每只手每帧预测“无接触 / driver1 / driver2”的类别分布；损失 L_C = L_CE + 0.01·L_temp（时序一致性）。
  - 驱动物体采用**手相对表示**：每帧输出 30 维 = 左/右手锚点平移偏移(3+3) + 无约束旋转(9)；硬 one-hot 接触决定用哪只手的候选重建位置（双手同时接触则取平均，均不接触则用固定 fallback 手）；旋转投影回 SO(3)。
  - 训练：先以真值人体与接触标签做标准扩散目标，再用**三次 B 样条残差损失**微调；推理时以生成的 H 与预测 C 替代真值，H 在 driver 采样全程固定。可选物体引导同样只用于可视化。
- **阶段3（物理仿真）**：MuJoCo 搭建场景，物体网格用 CoACD 分解为凸碰撞体；responder 为动态刚体，采用**统一密度与统一 MJCF 接触参数**（无需逐物体质量/惯量测量）；人体由 capsule/sphere 碰撞代理驱动，**禁用人体–driver 碰撞**；仿真**不修改**给定的人与 driver 运动；30fps 轨迹经样条插值以 60fps 重放，每帧 36 个仿真子步。
- **结果条件化交互编辑（可选）**：
  - 目标 g_R 分为**运动目标**（方向 u、响应强度区间 [s_min, s_max]、允许偏角 α，可加旋转轴）与**关系目标**（如支撑保持、持续接触）。
  - 可行响应集 V(g_R) 约束响应物体接触后速度沿 u 的分量在区间内、且方向落在以 u 为轴、半角 α 的锥内；运动目标误差定义为仿真速度到该集合的欧氏距离。
  - **局部 driver 修正**：在事件附近短窗口内用 δ ∈ R^{5×(3+3)}（5 个时序控制点，各含平移与旋转修正）参数化编辑，基函数在窗口边界处函数值与一、二阶导均为零以保持窗口外轨迹不变。

  - **仿真引导选择**：对缩放后的候选修正做完整 MuJoCo 重放，只累积能改善目标的候选，迭代至达成、无改进或预算耗尽。
  - **人体重定向**：把 driver 的 SE(3) 改动传给手腕目标，优化三次 B 样条残差手臂旋转，必要时以更强正则粗调躯干；根平移、手指关节与非编辑关节保持固定。
- **异构数据构建**：
  - 数据源：纯人体运动（HumanML3D、Motion-X++、AIST++、BEAT2、OpenBiomechanicsProject、LAFAN1）；全身交互（OMOMO、HuMoTo、GRAB、InterAct）；精细手部操作（TACO、OakInk2）。
  - 统一到中性身体模型、重采样至 30fps、切为 120 帧窗口。
  - **物体角色自动标注**：运动物体表面采样点任一顿距手关节 ≤2cm 者为 driver 候选，最多保留 2 个；其余为 responder；接触标签用同一 2cm 判据。
  - **不完整观测的全身拟合**：TACO 保留手指关节、对腕轨迹拟合中性 SMPL-X 身体，未观测区域正则到中立站姿并鼓励时序平滑；OakInk2 重定向上半身与手、下半身补全为接地静止脚并限制对上半身的改动。
