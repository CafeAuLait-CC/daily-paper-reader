# Abstract 

3D point clouds generation requires capturing both part-level layout and surface detail while preserving permuta-tion equivariance. Existing latent generative models often encode an entire shape into a single vector, which limits their ability to retain part-level structure. We propose To-kenFlow, a hierarchical flow matching framework that rep-resents each shape as a set of latent tokens and couples a rectified flow over these tokens with a conditional flow over points. A bottleneck of M ≪ N learnable tokens ag-gregates global context through cross-attention at O(N M )

cost. On ShapeNet, TokenFlow achieves the best MMD and coverage across airplane, car, and chair, while obtaining 1-NNA comparable to the strongest baselines. On Model-Net, its learned latent set reaches the best reported linear-evaluation accuracy on ModelNet10. These results show that representing a shape as a set of latent tokens, aggre-gated at O(N M ) cost, provides an effective representation for 3D point cloud generation. 

# 1. Introduction 

A 3D shape is more than a collection of points. Although a point cloud is represented as an unordered set of coor-dinates, its identity is largely determined by how parts are organized and how their surfaces are formed. A chair, for example, requires the seat, back, and legs to occupy a co-herent spatial configuration, while each individual leg must still exhibit a well-defined local surface. These two re-quirements are fundamentally different: global structure 

determines where parts should be and how they relate to one another, whereas local geometry determines how those parts are realized at the point level. A useful genera-tive model must capture both while remaining permutation-equivariant. Point cloud generation has progressed substantially along several directions. Early GAN- and VAE-based ap-proaches [1, 15, 27, 30, 51] directly generate point sets and optimize set distances such as Chamfer Distance (CD) and Earth Mover’s Distance (EMD) [14]. Continuous normaliz-ing flows (CNFs), including PointFlow [60], SoftFlow [26], and DPF-Net [28], instead model point clouds through con-tinuous transformations of distributions. More recently, dif-fusion models [22, 35, 47, 67] have improved generation quality, while latent representations [29, 38, 47, 63] and flow matching [32, 33] have emerged as effective ways to improve the scalability and efficiency of generative model-ing. Despite these advances, most existing models still treat the generation process as a single prediction problem: one representation and one generative field are responsible for both global organization and local surface formation. This design creates a less obvious bottleneck. Consider a rectified transport path 

Yt = (1 − t)Y0 + tX. 

At an early time t, the current state contains little infor-mation about the target shape; later in the trajectory, the tar-get geometry becomes increasingly identifiable. Thus, the useful signal available for predicting the target is not uni-form throughout the transport process. Global structure and local geometry are also not equally informative at the same time, and the two types of information cannot be expected to share a single representation. The representation used by latent generative models makes this problem more pronounced. Recent approaches such as LION [47] and 3DShape2VecSet [63] avoid operat-ing directly on all points by first mapping a shape into a la-tent representation. However, compressing an entire shape into a single global vector makes part-level structure diffi-cult to preserve explicitly. A natural alternative is to retain a set of latent tokens, so that different tokens can encode different aspects of the shape while remaining permutation-invariant as a whole. The challenge is then to connect this latent representation back to N points without resorting to full point-to-point attention, whose O(N 2) complexity be-comes costly as the point resolution grows. These observations suggest a simple question: where arXiv:2610.27418v1 [cs.CV] 20 Oct 2026 should the boundary between global organization and lo-cal geometry lie? We answer this question with Token-Flow , a hierarchical flow matching framework that places the two roles at different levels while allowing them to inter-act throughout the transport process. TokenFlow represents a shape as a set of M ≪ N latent tokens rather than a single global code. These tokens provide a compact global state from which part-level organization can be modeled, while cross-attention connects the global representation back to individual points at O(N M ) cost. Collectively, these components yield a generative model that disentangles shape semantics from surface geometry across different levels, while maintaining their coupling via the flow. We additionally conduct controlled experiments to isolate the effect of the representation. Our contributions are summarized as follows: • We introduce TokenFlow , a latent-set rectified flow framework for 3D point cloud generation that separates global shape organization from point-level detail in its representation. • We propose context bottleneck aggregation . Placing it after point-wise feature extraction means cross-attention learns only a grouping rather than a metric, and us-ing asymmetric query/key versus value widths keeps the 

O(N M ) attention map low-dimensional while the carried information stays high-dimensional. • We evaluate TokenFlow on ShapeNet and ModelNet datasets, demonstrating superior performance compared with previous state-of-the-art methods. 

# 2. Related Work 

2.1. Point Cloud Generation 

Early point cloud generators directly model an N × 3 point matrix with GANs [1, 30, 51], VAEs [15, 27], and adver-sarial autoencoders [36, 62]. These methods typically use a fixed number of output points and rely on set distances such as Chamfer Distance and Earth Mover’s Distance [14]. FoldingNet [61] and AtlasNet [19] instead generate surfaces by deforming 2D patches. PointFlow [60] introduced a con-tinuous normalizing flow formulation that models both the shape distribution and the conditional point distribution, al-lowing density estimation and variable point counts. Soft-Flow [26], DPF-Net [28], and ShapeGF [4] further explored continuous distributional formulations. Diffusion models subsequently became a dominant paradigm for point cloud generation [35, 40, 67] and la-tent 3D generation [29, 34, 38, 47]. Recent work has ex-tended diffusion to unified point cloud processing [13], joint geometry-semantic generation [44], and state-space archi-tectures [64]. Autoregressive models have also shown com-petitive performance through coarse-to-fine next-scale pre-diction [37]. Beyond generation, diffusion features have been distilled for point cloud representation learning [9]. Our work instead separates the two at the level of repre-sentation: a set of latent tokens carries global shape orga-nization, while a conditional flow resolves local geometry. 

2.2. Continuous-Time Generative Modeling 

Continuous-time generative models provide a principled framework for transporting a simple reference distribution to the data distribution. Diffusion models [22] perform this transformation through a predefined noise schedule, but typically require many denoising steps at inference. Flow matching [32] directly learns a velocity field along a prescribed probability path, while rectified flow [33] uses straight interpolation paths that enable efficient Euler sam-pling. Optimal-transport couplings [46] further improve path straightness, and consistency models [43] reduce the number of required sampling steps. These formulations have recently been applied to 3D generation. TripoSG [31] uses a large-scale rectified-flow transformer for image-to-3D synthesis, while ShapeR [42] conditions rectified flow on sparse SLAM points, posed im-ages, and text. Related approaches target dynamic meshes [58] and 3D Gaussian objects [52]. Hierarchical Flow Matching [50] factorizes point cloud generation into a la-tent flow and a conditional point flow. Other recent stud-ies have revisited transport design and evaluation for point cloud generation [3, 23, 49]. TokenFlow is closest to hierarchical flow-based formu-lations, but differs in how the shape is represented and how the conditional field is conditioned. It aggregates context through a bottleneck of M ≪ N latent tokens, which con-dition a point-level rectified flow at O(N M ) cost. 

2.3. Latent Shape Representations 

The choice of representation strongly affects how well a generative model preserves 3D structure. Global latent vec-tors [35, 60] provide compact shape representations but compress part-level information into a single code. Voxel-and grid-based representations preserve spatial locality but incur rapidly increasing memory costs with resolution. Latent sets provide an alternative by representing a shape with multiple learned tokens. LION [47] models a la-tent point cloud obtained from a hierarchical VAE, while 3DShape2VecSet [63] represents shapes as sets of latent vectors and applies a diffusion transformer for uncon-ditional, category-, text-, and image-conditioned genera-tion. Part-aware representations have also been explored in SPAGHETTI [21] and SALAD [29]. Autoregressive ap-proaches instead discretize latent representations and gener-ate them sequentially [7, 10, 45]. 2.4. Context Aggregation and Scalability on Point Sets 

Global context is essential for point cloud modeling, but di-rect point-to-point interaction scales poorly with the num-ber of points. PointNet [39] uses symmetric pooling to ob-tain permutation invariance with negligible interaction cost, but the resulting global representation is not explicitly adap-tive to individual points. Transformer-based architectures, including PCT [20] and Point Transformer [56, 66], model point-to-point relations through attention, with full attention requiring O(N 2) time and memory. Local attention [66] reduces the interaction range but remains dependent on the point resolution. A different strategy is to introduce a smaller set of latent tokens as an information bottleneck. Perceiver [24] cross-attends from a small array of learned latents to a large in-put and then processes the latents with self-attention, avoid-ing any N × N map. Hierarchical masked autoencoders [65] and 3DShape2VecSet [63] adopt the same recipe for 3D shapes. TokenFlow follows this bottleneck design and aggregates N point features into M ≪ N context to-kens through cross-attention, reducing the interaction cost to O(N M ). Our contribution here is not the bottleneck it-self, which is established, but its placement and parametri-sation: we place it after point-wise feature extraction, where cross-attention has to learn only a grouping rather than a metric, and we make the query/key and value widths asym-metric so that the O(N M ) attention map is constructed in a low-dimensional space. Neither choice is analysed in the works above; we quantify the resulting cost against global, local and linear attention in Tab. 1.

4.1. Overview 

A point cloud is denoted as X = {xi}Ni=1 , where xi ∈ R3,and a shape is represented by a compact set of tokens 

Z = {zm}Mm=1 , where zm ∈ Rd and M ≪ N . The over-all training objective is described in Sec. 4.5.

Evaluation Metrics. We employ COV (coverage), MMD (minimum matching distance), JSD (Jensen-Shannon di-vergence), and 1-NNA (1-nearest neighbor accuracy) using Chamfer Distance (CD) and Earth Mover’s Distance (EMD) as base metrics, following prior works [28, 60]. COV de-tects mode collapse, MMD evaluates fidelity, JSD compares marginal distributions, and 1-NNA is a more robust measure for both diversity and quality [60]. 

Configuration. For the generation task, we follow previ-ous works [4, 26, 28, 60, 67] and select three classes from ShapeNet dataset [5]: airplane, chair, and car. Each class in ShapeNet contains 15,000 sampled points. We sample 2,048 points for training and testing for each shape and pre-process the point cloud data following the steps outlined in [60]. For the classification evaluation of our auto-encoders, we implement ModelNet40 and ModelNet10 datasets [57], which contain 3D models of 40 and 10 categories, respec-tively. 

Implementation Details. All experiments are conducted on 4 NVIDIA A800 80G GPUs. The point-wise embed-ding uses C = 128 channels, and the CBA bottleneck uses 

M = 64 learnable tokens of width d = 128 , Lb = 2 blocks and four attention heads. The conditional point field has a hidden width of 128, and the latent velocity field is a four-layer Transformer. We optimize with Adam at a learning rate of 2 × 10 −3, with β1 = 0 .9, β2 = 0 .999 and no weight decay, for 4000 epochs at a batch size of 128 . The learning rate stays constant over the first half of training and then de-cays linearly to zero. All four weights in Eq. (17) are set to 

1, and the minibatch optimal-transport coupling is enabled for the prior flow. Sampling uses Kp = Kc = 20 Euler steps.

5.4. Ablation Study 

We ablate the two core designs, the context module of the encoder and the number of latent tokens M .

Context Module. Tab. 5 replaces the context module while the rest of the encoder and both flows stay unchanged. CBA improves on all three alternatives. PointTransformer is the closest competitor and still trails by 4.89 points on 1-NNA-CD and 7.41 points on 1-NNA-EMD. Transformer self-attention trails by 5.78 and 8.36 points, and Performer trails by 9.58 and 15.05 points. The ranking follows from the way each module turns N

points into a shape code. Transformer self-attention mixes all point pairs and then has to pool the resulting N features into one vector, which discards the assignment of points to parts. The conditional flow then has to recover that structure from noise, which is the hardest part of the problem. CBA keeps the assignment because its softmax is taken with M

learned queries over all N points, so each token is a content-adaptive summary rather than a fixed average. PointTransformer does better than full attention because it retains local geometry, but its neighbourhood graph is built on Euclidean distance in the input coordinates. Parts are frequently not proximal, so the four legs of a chair are never placed in one group. Performer fails for a different reason. The kernel re-places the exponential, so attention mass spreads over many points and no cluster is selected. Its M tokens then sum-marise diffuse second-order statistics instead of distinct parts. The costs of the four modules are listed in Tab. 1. CBA replaces an N ×N attention map with an M ×N one, which is 32 times smaller at N = 2048 and M = 64 . Performer builds no such map and is therefore the only module with a smaller memory footprint, but it is also the least accurate here, so the saving is paid for in fidelity rather than obtained for free. Latent Tokens. Tab. 6 varies M . Accuracy improves from 

M = 1 to M = 64 and then degrades again at M = 128 .At M = 1 the token self-attention becomes an identity, so the encoder degenerates into the single vector code used by earlier two-level models. Small values of M in general under-resolve the shape, because too few tokens cannot cover all parts. At M = 128 

the opposite failure appears. Tokens beyond the number of parts are redundant, and the latent prior must model a higher dimensional token set from the same training data, so the aggregated posterior drifts further from the Gaussian prior and sampling quality drops. The KL term is summed over every token coordinate, so its magnitude grows with M as well. M = 64 balances the two effects and is the value used in the main results. 

# 6. Conclusion 

We proposed TokenFlow, a hierarchical rectified flow matching framework that represents a shape as a set of 

M ≪ N latent tokens and couples a rectified flow over these tokens with a conditional flow over points. We found that existing models compress a shape into a single global vector, leaving part-level structure implicit. To address this, we introduced a context bottleneck that aggregates global information at O(N M ) cost and conditions a point-level rectified flow. Experiments on ShapeNet demonstrate that our method achieves superior fidelity and diversity, with competitive transferable latent representations for ModelNet classification. Future work will extend the framework to large-scale scene-level point clouds and multimodal conditional generation.
