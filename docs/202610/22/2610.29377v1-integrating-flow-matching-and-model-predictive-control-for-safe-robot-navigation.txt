# Integrating Flow Matching and Model Predictive Control for Safe Robot Navigation 

Philipp Holzmann 1, Maik Pfefferkorn 1, Jo˜ ao Carvalho 2, Ali Younes 3, An T. Le 2,Georgia Chalvatzaki 3,5,6, Jan Peters 2,4,5,6, Rolf Findeisen 1

Abstract — Learning-based path planners based on diffusion and flow matching can generate diverse trajectories from demonstrations but typically lack mechanisms for constraint satisfaction and collision avoidance during deployment. This work proposes a framework that combines flow-matching-based path planning with model predictive path-following control to integrate data-driven path generation with real-time, constraint-aware execution. The flow-matching model captures multimodal path distributions, while the predictive controller adapts motion online to satisfy state and input constraints and avoid obstacles using updated local sensor information. An event-triggered re-planning scheme incorporates predictive control solutions into subsequent path generation, promoting collision-free navigation in environments with previously unseen obstacles. Simulation results for mobile robot navigation demonstrate robust perfor-mance across cluttered environments. The framework provides a systematic approach to combining flow matching with predictive control for adaptive, data-driven navigation. 

I. I NTRODUCTION 

Recent advances in robot control for complex tasks have been driven by increasingly capable machine learning algo-rithms and the availability of high-performance computing resources [1–3]. Machine learning enables expressive control policies that often outperform classical methods in high-dimensional and multimodal settings, particularly when trained via imitation or reinforcement learning. To handle multimodal data distributions, recent work has applied deep generative models based on diffusion [4] and flow matching [5, 6], originally developed for image synthesis, to robotics domains including imitation learning [7, 8], offline RL [9], grasping [10, 11], and motion planning [12–18]. These models are particularly attractive for their ability to represent complex, multimodal trajectory distributions and to generate diverse candidate motions from demonstration data, including different paths from the same initial point. In this article, we use a variant of flow matching the shortcut model [19], which offers fast sampling [20]. One central challenge in learning policies from demon-strations is the lack of guarantees for collision avoidance

For example, a generative model trained on human-demonstrated trajectories may produce paths that become unsafe when new obstacles are introduced or when dynamics or constraints (e.g., velocity limits) change. Nev-ertheless, the data remains valuable as a reference for a lower-level controller that can safely adapt to it. To this end, we combine the deep generative planner with a model predictive path-following controller (MPPFC) [21–23], which tracks and locally reshapes the generated path to ensure safety, cf. Fig. 1. Unlike tracking model predictive control (MPC) [24, 25], MPPFC treats path progression and velocity as optimization variables, enabling adaptive motion profiles and reactive behavior in dynamic environments. By enforcing input and state constraints, including collision avoidance and actuator limits, MPPFC ensures constraint satisfaction even if the reference path must be temporarily deviated from. Previous works have used simpler generative models, focused on unimodal settings and control-theoretic guaran-tees [26–30]. Since combining diffusion and flow matching generative models with predictive control offers a large potential [31], this has been explored by a series of works: [32] uses a diffusion model to learn multi-step predictions and warm-start MPC optimizations; [33] parameterizes MPC feedback using diffusion; [34] applies diffusion models to solve nonlinear MPC problems; and [35, 36] explore diffusion rollouts for model predictive path integral control (MPPIC). Relatedly, [31] uses diffusion to generate subgoals for long-horizon control with MPPIC. However, because of the underlying MPC methods used, these works do not guarantee safety or path-following. In contrast, our approach combines flow-matching for reference generation with MPPFC for local safety and reference tracking, overcoming the limitations of the current methods. By using MPPFC to track and refine paths generated via flow matching, we ensure constraint satisfaction — particularly collision avoidance — and enable real-time adaptation. In this sense, the MPPFC shows similar-ities to predictive safety filters [37–39]. However, in contrast to standard safety filters that modify unsafe inputs to ensure safety, we directly apply MPPFC as the main controller, using its structure to dynamically shape both path execution and progression. The main contributions of this work are: (1) a framework that combines a flow-matching-based path generator, learned from human demonstrations, with MPPFC to enable constraint satisfaction and collision avoidance during execution; (2) a bidirectional coupling in which flow-generated paths guide MPPFC and its predictions bias the flow planner during event-arXiv:2610.29377v1 [cs.RO] 21 Oct 2026 triggered re-planning; (3) a systematic evaluation demon-strating collision-free path-following in environments with multiple obstacle configurations not observed during training. Rather than relying on classical sampling-based planners (e.g., RRT [40]), we assume access to expert task demonstrations that encode nuanced human preferences for spatial navigation. To model and reproduce these demonstrations, we learn a flow-matching-based generative planner. Given start and goal configurations, candidate paths are generated by sampling from this learned flow-matching model. Formally, a path is defined as a geometric curve ρ : Cθ →Y, θ 7 → y = ρ(θ) in the system’s output space, parametrized by a scalar path parameter θ. We represent each path as a linear combination of a finite set of fixed-order B-splines, training the flow-matching model directly on the governing coefficients. While the generative planner provides a strong, obstacle-aware prior based on demonstrations, it is not strictly tasked with enforcing real-time constraints or active collision avoidance using all current local information. Instead, this responsibility is systematically delegated to a lower-level controller that incorporates this information. Specifically, the generated paths serve as reference priors for parallel instances of an MPPFC, each configured with a different prediction horizon. The predictive controller seamlessly enforces state and input constraints, adapting the trajectory online to navigate environmental changes and previously unseen obstacles. During closed-loop operation, the generative model is selectively resampled whenever predefined criteria are met (e.g., a significant spatial deviation from the reference path). Crucially, these newly generated paths are biased by the predictive controller’s solution trajectory. This bidirectional coupling steers the generative model toward inherently collision-free regions of the task space, ensuring tight consistency between global planning and local execution while minimizing the corrective effort demanded of the controller. In principle, one could adapt the generative model directly to new obstacles using an energy-based guidance term: an energy function Jg : Rnξ → R≥0 assigns higher values to unsafe regions, and its gradient ∇ξJg(ξ) biases the sampled path away from obstacles. This yields a modified vector field 

˜vζ (λ, ξ) = vζ (λ, ξ) − γg∇ξJg(ξ), where γg > 0 controls the guidance strength. However, evaluating the flow-matching model is computationally expensive, and real-time systems can typically only afford a small number of integration steps [14]. With a limited number integration steps, a large γg

risks pushing the generative process out of distribution, while a small γg has negligible effect (see Fig. 2). Furthermore, updating the entire global plan for purely local environmental changes is computationally inefficient. To overcome these limitations, we leverage the MPPFC to locally re-plan the system’s behavior, enforcing system dynamics and collision-avoidance constraints exclusively where needed (see Fig. 1). At the beginning of task execution, we generate a batch of candidate paths from the generative model and select a collision-free path with respect to known obstacles. Rather than strictly requiring the flow-matching planner to output directly executable trajectories, our framework systematically delegates dynamic feasibility and real-time safety to the predictive controller. The selected path is incorporated into the MPPFC formulation in two complementary ways: it acts as a reference objective within the stage cost and defines the terminal region constraint (5h). Specifically, the MPPFC constrains the system to return to and align with the reference path at the end of the prediction horizon. The exact realignment point is dynamically determined by the controller via the path dynamics and virtual input. This hierarchical integration explicitly accounts for previ-ously unknown static obstacles at runtime. 1 Assuming the system is equipped with sensors (e.g., LiDAR), newly detected obstacles are convexified and incorporated into the safe set 

Xsafe as state constraints. Once the system safely bypasses an obstacle and it exits the sensing range, the associated constraints are removed to minimize the computational burden. Due to the terminal alignment structure of the MPPFC, feasibility dictates that obstacle avoidance and path re-alignment must be achieved within a single prediction horizon. If an obstacle forces a significant deviation, strict terminal alignment may render the optimal control problem infeasible. To ensure robust collision-free operation, we conceptually decouple short-term collision avoidance from strict terminal alignment. While this can be achieved by softening the terminal constraint or employing a generative-guided terminal cost, we adopt a parallelized horizon-extension strategy. We solve multiple MPPFC instances simultaneously, each with an incrementally extended prediction horizon but a fixed number of collocation points. We then execute the solution from the instance with the shortest feasible horizon (see Fig. 1). Because a shorter horizon with fixed collocation points implies a smaller integration step size, it naturally yields higher control fidelity. The controller autonomously reverts to the shortest horizon once local feasibility is re-established. For substantial deviations, event-triggered re-planning using the expert model is employed to improve adherence to the demonstrated global behavior. Re-planning is triggered when the system exits a user-defined neighborhood around an evaded obstacle — after the MPPFC has successfully ensured local safety. This allows the global planner to realign the overall trajectory with the expert distribution. Crucially,

By combining the global geometric awareness of flow-matching with the strict local safety filtering of the MPPFC, the proposed strategy consistently produces collision-free behavior in practice, assuming the existence of a topologically viable alternative path, a standard and practical assumption for agile robotic platforms operating in task-oriented environments. 

C. Biasing the Planner Toward the MPPFC Solution 

A key component of the proposed method is re-planning the reference path during evasive maneuvers to improve adherence to demonstrated behaviors. We achieve this by using the predictive controller’s collision-free solution, which incorporates updated local sensor and constraint information, to bias the generative planner toward locally safe trajectories, ensuring candidate paths remain consistent with the current system state. Introducing this sampling bias in classical generative mod-els, such as VAEs [48], is not straightforward. In denoising-diffusion-like methods, such as flow matching, this is easily integrated by applying noise steps to the previous MPC solution, followed by denoising steps. This approach ensures the generated trajectories remain closer to the MPC prediction than sampling from standard Gaussian noise followed by multiple denoising steps. A similar approach has been used in diffusion models for autonomous racing [49]. Specifically, instead of starting the generative process from pure noise ξ0 ∼ N (0 , I), we propose initializing it from an intermediate step λ = ¯λ, with 0 < ¯λ < 1. This requires a partially noisy sample ξ¯λ = (1 − ¯λ)ξ0 + ¯λξ1, which depends on a clean sample ξ1. Since the true ξ1 is generally unavailable, we use the MPC’s latest prediction to obtain a local approximation ˆξ1. This estimate is obtained by fitting a B-spline using (3), providing a fast-to-compute, biased initialization. The generative process is then started with 

(ξ¯λ, ¯λ) based on ˆξ1, producing candidate paths that are locally aligned with the controller’s current plan and likely maintain its collision-avoidance guarantees locally. In addition to aligning the generative process with the MPC plan, the biasing provides notable computational advantages. By initializing the flow-matching model from an intermediate state informed by the MPC prediction, sampling typically re-quires fewer refinement steps and can therefore be performed more efficiently. Furthermore, by increasing the likelihood of obtaining a collision-free alternative reference path, the bias often reduces the magnitude of corrective actions required by the MPC. This, in turn, generally decreases the computational effort associated with solving the MPC problem. (C1) (C2) (C3) (C4)

V. S IMULATION EXPERIMENTS 

In this section, we evaluate our framework in simulated tasks. The experiments are constructed to answer the follow-ing questions: 1) What is the system’s behavior in a navigation task with unknown obstacles? 2) How do the MPC horizon expansion and re-planning strategies influence the success rate? 

A. Environment, Data Collection, and Shortcut Model 

To train the shortcut model effectively, we require a diverse and informative dataset of collision-free paths. Such a dataset is constructed in a physically realistic MuJoCo simulation [50], where a human operator navigates a mobile robot through a cluttered environment populated with various static obstacles (see Fig. 4). The operator guides the robot between multiple random start and goal positions, producing paths that, due to the non-deterministic nature of human behavior, exhibit a multimodal distribution. The resulting dataset consists of approximately 1800 demonstrations. Our shortcut model is based on a diffusion transformer architecture as in [51]. The model is trained on an NVIDIA A100 GPU, and evaluated on an NVIDIA GeForce RTX 3090 GPU.

We employ K = 15 parallel controller instances with a base horizon length T = 1 .0 s , an increment δt = 0 .2,and 20 equidistant collocation points along each horizon. This results in a maximum horizon length of 3.8 s . We employ the re-planning strategy P3, as proposed earlier.

We sample a batch of paths from the shortcut model, conditioned on a given start and desired goal position (Fig. 4a). All sampled paths are collision-free with respect to the obstacles encountered during demonstrations. From this batch, a path is randomly selected, and the parallel MPC instances compute the corresponding optimal inputs. The solution from the instance with the shortest horizon that returns a feasible solution is then executed. After some time, a previously unknown obstacle appears within the system’s sensing range, causing the current reference path to be in collision (4b). To initiate an evasive maneuver, we include collision avoidance with the detected obstacle as a hard constraint in the MPC. However, adding this constraints can make the optimal control problem infeasible. Specifically, the MPPFC must re-align with the path at the end of each prediction horizon, and depending on the horizon length, input limits, and other state constraints, this may no longer be achievable for any controller instance. In such cases, the controller with the shortest horizon among the feasible instances is still selected and executed. Moreover, whenever a new obstacle is added as a collision-avoidance constraint, we initialize the path parameter for the next horizon with θ(T ) = 1 , corresponding to the end of the reference path. This has been found beneficial, as it biases the optimizer toward solutions that prioritize significant path progress, increasing the likelihood that one controller instance remains feasible while planning to return to the reference path at the horizon’s end (Fig. 4c). If necessary, the prediction horizons of each controller instance can be iteratively extended until feasibility is recovered, depending on the available computation budget. When the robot exits a user-defined neighborhood around an evaded obstacle (illustrated as a circle in Fig. 4d, gray dashed), re-planning is triggered and a new batch of paths (light green) is sampled from the current position to the desired goal. As described in Section IV-C, we bias the planner by initializing it with a noisy version of the MPPFC output at ¯λ = 0 .75 , rather than from standard Gaussian noise. As a result, the planner generates high-quality, locally collision-free candidate paths with only two integration steps. From the newly generated paths, we select one that is collision-free with respect to both the obstacles in the current sensing range and those encountered during demonstration (yellow line in Fig. 4d) and deploy it in all controller instances. If no such path exists, the framework continues without interruption, relying on the parallel MPC instances to handle local feasibility. This procedure is repeated whenever a new, previously unknown obstacle appears (Fig. 4e,f), until the mobile robot reaches its destination.

VI. C ONCLUSIONS 

We proposed a framework that combines flow-matching-based generative planning, trained on expert demonstrations, with model predictive path-following control for adaptive navigation in cluttered environments. The generative planner provides diverse candidate paths, while the predictive con-troller incorporates onboard sensor information to adapt these paths online and ensure constraint satisfaction and collision-free execution, including in the presence of previously unseen obstacles. Event-triggered re-planning further couples path generation and control throughout task execution. Future work will focus on incorporating richer contextual information, such as perception data, into path generation and extending the framework to dynamic environments through motion prediction.
