# Rectified Language Flow 

Baiyu Su *, Runlong Liao *, Lizhang Chen †, Qiang Liu 

The University of Texas at Austin 

Continuous-state flow and diffusion models offer a promising approach to fast, parallel language gener-ation, but matching the generation quality of autoregressive models remains challenging. We present Rectified Language Flow (ReLF), a language model that generates text by transporting noise to token embeddings using rectified flow. ReLF combines several complementary design choices: fixed token embeddings constructed with Hellinger–SVD, self-conditioning guidance trained with cross-entropy, and regularized reflow for few-step generation. We further introduce singular logits, which combine an analytically computed term that drives commitment to a valid token embedding as noise vanishes with a bounded neural residual that learns contextual token preferences. With 64 function evaluations on OpenWebText, ReLF achieves lower generative perplexity than autoregressive baselines at matched diversity across all three model sizes tested, while also outperforming prior continuous flow methods in this setting. ## 1. Introduction 

Parallel text generation can reduce the sequential cost of autoregressive (AR) decoding. Flow and dif-fusion models take two approaches: discrete-state models update token identities, whereas continuous-state models evolve real-valued representations decoded into tokens. Discrete approaches have attracted substantial attention through large-scale diffusion language modeling [2–4]. Building on early continuous text diffusion [5, 6], continuous-state approaches are also gaining momentum, with recent developments in embedding-space modeling and few-step generation [1, 7]. Continuous formulations are attractive for two reasons. First, they are flexible: all positions evolve jointly before committing to tokens, so a model transforming noise across the whole sequence can, in principle, capture inter-token dependencies in a single evaluation, the basis for one-step generation [7]. Second, they inherit image, audio, and video generation tools, namely ODE/SDE samplers, guidance, and trajectory straightening, for controlling generation and accelerating sampling [8, 9]. However, turning these advantages into effective language models raises three design challenges: learning continuous dynamics from categorical supervision; reliably recovering tokens at the flow’s end; and designing token embeddings whose geometry supports corruption and denoising. Prior work explored auxiliary objectives [5, 6], encoder–decoder networks [10], and vocabulary-sized simplex representations [7, 11]. We seek a simple continuous-flow formulation that addresses them while generating high-quality, diverse text with few function evaluations. 

Results. We present Re ctified Language Flow (ReLF), a rectified-flow language model that generates token sequences along continuous embedding trajectories from noise. ReLF predicts a token posterior at each position and is trained only with cross-entropy. The velocity field is computed from the posterior-weighted mean of the token embeddings. Our OpenWebText experiments show: • Generation quality at 64 function evaluations. ReLF outperforms same-size AR baselines and Embed-ded Language Flows (ELF) [1] across all evaluated model sizes. ReLF-Small achieves a generative perplexity of 24 .1 at an entropy of 5 .45 nats, compared with 27 .7 at 5 .43 for AR-Small. ReLF-Large reaches 17 .3 at 5 .51, matching the generative perplexity of real OpenWebText text (17 .3 at 5 .49). • Faster generation through reflow. We further apply reflow [8] to reduce the number of function evaluations. After two rounds, ReLF still outperforms same-size AR models with just 16 function evaluations. It then generates 1,024-token sequences 15–19 × faster than these AR baselines at batch size 1 (Figure 1(b)). • Generation quality at 8 function evaluations. With only 8 function evaluations, ReLF-Medium achieves a generative perplexity of 42 .7, compared with 66 .4 for ELF+PD, a progressively distilled ELF model, both at entropy 5 .42. 

Methods. ReLF learns continuous dynamics from categorical supervision by training token posteriors with cross-entropy (Section 2). Four components then address reliable token recovery, embedding geometry, and high-quality generation with few function evaluations: • Singular logits. As noise vanishes, token posteriors approach point masses, requiring unbounded logit differences. Our singular logits capture this divergence analytically through a reference posterior, so the network learns only a bounded residual of contextual token preferences. This guarantees that the modeled posterior converges to a one-hot distribution and the trajectory to a token embedding (Section 3.1). • Embedding geometry for language flows. Token embeddings define the geometry of corruption and denoising. Our fixed, frequency-weighted Hellinger–SVD embeddings place tokens with similar contexts nearby. Their dimension is a free hyperparameter, which we find important for generation quality (Section 3.2).

## 3. Commitment, Geometry, Guidance, and Straightening 

Section 2 fixes the training objective and sampler but leaves open how tokens commit as noise vanishes and in which embedding space the flow evolves. This section addresses both: Section 3.1 introduces singular logits, which guarantee convergence to token embeddings, and Section 3.2 constructs compact, context-informed flow embeddings. We further adapt two widely used flow techniques: Section 3.3 moves self-conditioning guidance to logit space, where it can be trained with CE, and Section 3.4 stabilizes reflow for few-step generation. 

3.1. Singular Logits Enable Endpoint Convergence Motivation. As noise vanishes, the posterior converges to a one-hot distribution. Under a fixed-temperature softmax, this requires diverging logit differences, which a network with bounded inputs and parameters cannot represent. The predicted posterior thus keeps probability on competing tokens even at the endpoint. Since the trajectory converges to the clean-state estimate b𝑋 1, it ends at a mixture of token embeddings rather than at a single token embedding (Figure 3(a,c)). Prior continuous models instead decode final states by rounding or a separate decoder [1, 5]. We observe that the exact posterior itself points to a solution: its logits decompose into a singular component that diverges as noise vanishes and a bounded component carrying contextual token preferences. The singular component has a closed form for a simple reference distribution 𝑟 1, leaving the network to learn a residual that is guaranteed to stay finite.

## 4. Experiments 

4.1. Experimental Setup Dataset and Evaluation. We evaluate unconditional text generation on OpenWebText (OWT) [21], following the benchmark used in prior diffusion and flow language models [1, 2, 7, 22]. We tokenize the corpus with the GPT-2 tokenizer [23] and pack sequences to length 𝐿 = 1024. For each ReLF and AR sampling configuration, we generate 1,024 sequences (ELF results use 1,000) and report generative perplexity (Gen. PPL) under GPT-2 Large and sample diversity as the mean per-sequence unigram entropy in nats. We evaluate the quality–diversity trade-off by sweeping the guidance strength. 

Model. Our default model is ReLF-Small, a bidirectional diffusion Transformer [24] with 138M trainable parameters, 12 layers, hidden width 768, and 12 attention heads. We use the fixed 32-dimensional Hellinger–SVD token embeddings constructed in Section 3.2. At each position, the noisy embedding is concatenated with a self-conditioning estimate of the clean embedding and projected to the Transformer width. The network predicts residual logits, which are added to the analytic singular logits with a unigram reference distribution. Appendix B gives the configurations of all sizes. 

Training and Inference. We train ReLF-Small, ReLF-Medium, and ReLF-Large for 80,000 steps each, with a global batch of 1 ,024 × 1,024 tokens (1,024 sequences of length 1,024), minimizing the CE loss in Eq. (3). We use Muon [25–27] for hidden matrices and AdamW for the input and output projections, normalization gains, and biases, with a base learning rate of 3 × 10 −4, 2,500 warmup steps, and a constant learning rate thereafter. Training uses standard Gaussian corruption, an embedding-dependent interpolation-time distribution, and self-conditioning with probability 0 .5. For distilled self-conditioning guidance, each sequence also draws a scale 𝜔 log-uniform on [1.5, 6],

> 8Rectified Language Flow

as in ELF [1]. We evaluate exponential-moving-average (EMA) checkpoints with decay 0 .9999. We report sampling cost in number of function evaluations (NFE) and wall-clock time; by default, we use the SDE sampler with 64 NFE. At sampling time, we sweep 𝜔 ; because 𝜔 is a network input, each guided step costs a single forward pass. 

4.2. Unconditional Generation on OpenWebText 

Figure 1(a) compares the quality–diversity trade-offs of ReLF, ELF [1], and autoregressive (AR) baselines trained on the same data and swept over sampling temperature. Each method has three sizes, Small, Medium, and Large, corresponding to the B, M, and L configurations of Hu et al. [1] (Table 2). With 64 NFE, ReLF outperforms both ELF and the AR baseline at every model size across the trade-off. At matched entropy, ReLF-Small, ReLF-Medium, and ReLF-Large reach Gen. PPL 24 .1, 18 .6, and 17 .3, compared with 27 .7, 22 .3, and 20 .2 for AR-Small, AR-Medium, and AR-Large. Appendix B.6 gives the evaluation details and the full Pareto frontiers. 

Observation 1. To the best of our knowledge, ReLF is the first continuous flow language model to achieve lower generative perplexity than autoregressive baselines of the same size on OpenWebText at matched entropy. 

ReLF-Large is close to real OpenWebText on the two reported metrics. It reaches Gen. PPL 17 .3 at entropy 5 .51, matching the Gen. PPL of real OpenWebText text (17 .3 at 5 .49). Unlike the Small and Medium models and despite the identical training pipeline, ReLF-Large no longer trades Gen. PPL against entropy effectively under guidance: across all guidance scales, both metrics stay nearly constant, with Gen. PPL between 17 .3 and 18 .0 (Table 5), so only two of its eight settings are non-dominated and appear in Figure 1(a). This does not mean that its samples fully match real text; the remaining differences in quality and diversity are small, semantic, and beyond what Gen. PPL and unigram entropy resolve (see the samples in Appendix C). Unconditional OpenWebText generation thus calls for richer benchmarks and metrics. 

Few-Step Generation. Figure 5 shows how regularized reflow (Section 3.4) improves few-step generation. Figure 10 in Appendix B.7 gives the complementary comparison across rounds at fixed NFE, with round 0 denoting the base model. Across rounds, Gen. PPL decreases at 8, 16, and 32 NFE for every model size while unigram entropy remains similar. Most of the gain arrives within two rounds: at 8 NFE, the first round lowers Gen. PPL by 29–36% (e.g., from 62 .5 to 44 .5 for Large), and the second by a further 8–12%. After two rounds, 16 NFE yields lower Gen. PPL than the base model at 32 NFE for every model size (Figure 7 in Appendix B.5). At matched entropy, the two-round models also attain lower Gen. PPL than ELF+PD at every NFE from 8 to 32, and than AR-Small (1,023 NFE) from 16 NFE onward (Table 6). 

Wall-Clock Efficiency. Figure 1(b) compares ReLF-Small, ReLF-Medium, and ReLF-Large (138M, 421M, and 784M parameters) with same-size AR models. ## 5. Related Work 

Discrete-State Models. Discrete-state models generate sequences by updating categorical vari-ables, often at multiple positions per step. Following masked-token pretraining [29] and iterative refinement [30], D3PM formalized structured categorical corruption [31], while continuous-time Markov formulations established corresponding denoising dynamics [32]. Subsequent work develops discrete score estimation, simplified masked-denoising objectives, and time-independent parameteri-zations [2, 22, 33, 34], alongside more general corruption kernels and probability paths [35–37]. The LLaDA family [3, 38, 39] advances masked diffusion through scaling and preference optimization, alongside work on language and code generation [4, 40, 41] and uniform-state diffusion [42–44]. Sampling research develops blockwise decoding [45], remasking [46], and adaptive token ordering and parallel updates [47–49]. Reinforcement learning supports reasoning [50], while masked gener-ation extends to images and multimodal modeling [51, 52]. These models retain categorical states even when time is continuous. 

Continuous-State Models. Continuous-state models generate categorical sequences through real-valued representations, with early examples including Argmax Flows [53]. Diffusion-LM [5] used token-embedding diffusion for controllable text generation, while Analog Bits [12] introduced self-conditioning for diffusion over continuous relaxations of binary encodings. Subsequent embedding-space models incorporate self-conditioning [54], continuous-time formulations [13], conditional generation and pretraining [55–57], and likelihood-based training [6]. Alternative representations include vocabulary-sized logit/simplex states [11, 58, 59] and statistical-manifold constructions [60– 62]. Latent diffusion denoises encoded text representations with a separate decoder [10, 63–66], with recent work jointly learning the latent space and generative dynamics [67, 68]. Rectified flow has also been applied to conditional text generation [69], while continuous flow-map language models pursue few-step decoding through distillation [7, 70, 71]. LangFlow [17] uses a Bregman formulation to train embedding-space flows with cross-entropy, whereas ELF [1] performs rectified flow in pretrained contextual embeddings and applies token-level supervision only at final decoding. Within this family, ReLF combines analytic singular logits for endpoint commitment with a compact, context-informed flow embedding space under a single cross-entropy objective, and reaches few-step generation through regularized reflow rather than distillation. 

## 6. Conclusion 

We introduced ReLF, a continuous rectified-flow language model trained with a cross-entropy loss. Its singular logits capture the divergent part of the token posteriors analytically, so trajectories converge to token embeddings, while the bounded learned residual decides which tokens are generated. Fixed Hellinger–SVD embeddings place tokens with similar contexts nearby, self-conditioning guidance in logit space is distilled through the same CE objective, and regularized reflow straightens the flow for few-step generation. On OpenWebText at 64 NFE, ReLF outperforms ELF and autoregressive baselines of the same size, and ReLF-Large matches real text in Gen. PPL at similar entropy. After two reflow

## B. Experimental Details 

B.1. Data Preparation and Fixed Embeddings Corpus Split and Sequence Packing. We use the OpenWebText training split, reserving the last 100,000 documents for validation and training on the rest. Each document is tokenized with the GPT-2 tokenizer and followed by an EOS token, and documents are concatenated within each preprocessing batch. We divide the stream into blocks of 1,022 tokens, discard the incomplete remainder, and add BOS and EOS to obtain sequences of length 1,024; GPT-2 uses the same token ID for both. Token distributions are defined over the 50,257-token GPT-2 vocabulary, excluding padding entries. 

Offline Statistics and Smoothing Selection. Embedding construction uses packed training windows sampled from contiguous chunks spread across the corpus, with a quarter of the chunks held out from count estimation for offline embedding evaluation. Numerical Precision. The Transformer residual stream and vocabulary projection run in bfloat16, while the flow state, analytic singular logits, and posterior embedding expectations stay in FP32. Network logits are promoted to FP32 before the analytic term is added, and the softmax and probability-weighted embedding sum are computed in FP32. This limits rounding of token-logit differences as the singular term grows near the endpoint and avoids storing small integration increments in bfloat16. Sampling updates, the self-conditioning carry, and the momentum-guidance velocity average also remain in FP32. Grid nodes and interval coefficients are computed in FP64.

Memory-Efficient Vocabulary Operations. We limit the memory of vocabulary-sized tensors by processing token positions in chunks. During training, each chunk of hidden features is projected to vocabulary logits, augmented with the analytic term, and passed to a fused cross-entropy kernel. A custom autograd operation computes each chunk’s hidden-feature and output-head gradients immediately and saves them for the outer backward pass, so training never materializes the full logit tensor. The self-conditioning pass likewise computes embedding expectations chunk by chunk. During sampling, the network produces the full bfloat16 logit tensor, but singular-logit addition, softmax, and the embedding expectation are performed in FP32 chunks, and final decoding applies a chunkwise argmax.
