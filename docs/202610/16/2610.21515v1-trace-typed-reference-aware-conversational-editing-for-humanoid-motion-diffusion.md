## 摘要
语言条件的人形运动生成使用户能够通过自然语言创建和优化机器人动作。核心挑战在于将描述不充分的请求与具体运动结构关联起来，使其后续能够相对于已接受的参考进行修改。我们提出 TRACE，一个面向 Unitree G1 人形机器人、围绕类型化且可度量的运动学量构建的生成与编辑框架。我们的洞见是：将生成条件锚定在成对的训练运动上，并将编辑目标锚定在当前运动上。一个语言模型学习从运动导出的监督信号中预测支撑、根和手部事件；这些事件的时间对齐编码在扩散生成器中补充原始文本。重力参考状态与轨迹—接触目标提升运动学一致性。对于编辑，类型化请求定义身体—时间范围以及相对于源的目标。一个单独的参考条件扩散编辑器利用这些目标和修订后的事件来实现变化，同时在采样时进行投影以保留受保护的状态坐标。定量评估和人工评估表明，与所比较的方法相比，语义对齐和运动质量有所提升。受控消融实验支持了运动锚定条件与运动学一致性的价值，而多轮编辑评估表明，在共享保留约束下，能够更可靠地执行连续的相对请求。总之，这些结果支持将类型化运动学结构作为运动生成与参考感知修订的共同基础。

## Abstract
Language-conditioned humanoid motion generation enables users to create and refine robot movements through natural language. The central challenge is to connect an underspecified request to concrete motion structure that can subsequently be revised relative to an accepted reference. We present TRACE, a generation and editing framework for the Unitree G1 humanoid robot built around typed, measurable kinematic quantities. Our insight is to ground generation conditions in paired training motions and editing goals in the current motion. A language model learns to predict support, root, and hand events from motion-derived supervision; their time-aligned encodings complement the original text in a diffusion generator. Gravity-referenced states and trajectory--contact objectives improve kinematic consistency. For editing, typed requests define body--time scopes and source-relative goals. A separate reference-conditioned diffusion editor uses these goals and revised events to realize changes, while sampling-time projection preserves protected state coordinates. Quantitative evaluation and human assessment show improved semantic alignment and motion quality over the compared methods. Controlled ablations support the value of motion-grounded conditioning and kinematic consistency, while multi-turn editing evaluations demonstrate more reliable execution of successive relative requests under shared preservation constraints. Together, these results support typed kinematic structure as a common basis for motion generation and reference-aware revision.

- **编辑侧的对称问题**：源条件编辑方法（MotionFix/TMED、SimMotionEdit、CIME）需要把"把手抬高"这类**相对请求**对照当前姿态与轨迹解释，同时保留其余动作；系统既要显式描述"改什么"，又要限制改动只作用于选定的身体部位与时间区间。
- **核心洞见**：把**类型化、可度量的运动学量**（支撑、根、手事件；高度、倾斜、接触）作为生成与编辑的**共同基础**——配对示范决定生成时的事件目标，当前参考决定编辑的基线与受保护坐标。
- **整体含义**：论文主张"类型化运动学结构"可同时支撑运动生成与参考感知的连续修订，从而把欠指定的语言连接到可被选择性修改的具体运动参考。

## 2. 方法论

### 2.1 核心思想
- 用 **typed（类型化）** 的事件词汇表（支撑 / 根 / 手）+ **reference-aware（参考感知）** 的编辑目标，统一生成与编辑两个阶段；生成器与编辑器**权重分离**、共享运动表示与运动学词汇。
- 生成条件锚定在**配对训练运动**上（motion-grounded），编辑目标锚定在**当前运动**上（source-relative）。

### 2.2 运动锚定的稀疏事件规划与条件注入
- **事件目标构造**：对干净训练动作做确定性正向运动学（FK）与根重建，得到脚底高度/速度、根垂直运动与高度、相对骨盆的手掌高度；固定阈值转成类型化事件。每个 4 帧 patch 携带 16 维条件 `c_ℓ ∈ [0,1]^16`：2 个左右脚支撑概率（独立 sigmoid）、3 个根垂直速度类别（下降/水平/上升，阈值 ∓0.08 m/s）、3 个根高度类别（0.60/0.85 m 切分）、左右手各 4 个高度类别（0/0.25/0.45 相对骨盆切分）。类别组内用 softmax，和为 1。
- **不确定性与置信度**：支撑用滞回阈值（进入 ≤0.035 m 且 ≤0.20 m/s，离开 >0.055 m 或 >0.30 m/s），<3 帧接触段被置信度屏蔽；根/手类别先做 5 帧滑动平均，接近阈值（0.025 m / 0.02 m/s）的帧标为不确定。每 patch 聚合为直方图目标 `Y`，置信度 `W` = 可信帧比例。
- **LLM 规划器**：冻结的 LLM（Qwen3-4B-Instruct 适配器）从文本联合预测时长与事件区间，确定性栅格化为 `P = (N, C) = Rasterize(LLM_φ(u))`，`C ∈ [0,1]^{L×16}`，`L = ⌈N/4⌉`。
- **训练条件混合**（关键设计）：`C_mix = W⊙Y + (1−W)⊙h(u,N)`（以 1/2 概率），否则直接用预测事件 `h(u,N)`；分组整体选择，降低对完美标注的依赖。测试时只用 caption 预测的时长与事件。
- **时间对齐条件**：原始 caption 编码一次，事件投影分支与原始文本残差分支用 patch 进度特征对齐；残差条件按 `α(k)=min(1, k/[0.25(K−1)])` 在接近干净运动时衰减。匹配对照通过"置零事件输入但保留全部可训练参数"来隔离事件内容与容量的影响。

### 2.3 重力锚定与接触一致的扩散
- **重力参考状态**（40 维）：`x_t = [Δp^x_t, Δp^y_t, h_t, sinΔψ_t, cosΔψ_t, r^tilt_t, j_t]`。即只积分平面位移与偏航，**直接预测绝对高度 h_t 与重力相对倾斜 r^tilt**（根旋转去掉水平朝向后的 6 维残差，正交化后与积分偏航复合恢复旋转），加 29 个关节角。这样把"需要绝对参考的量"与"描述位移的量"分离。
- **分组目标**：`L_gen = L_motion + L_geometry + L_contact`
  - 运动组：状态重建 + 速度 + 加速度。
  - 几何组：积分位置、累积偏航（周期 cos 惩罚）、body-up 重力方向、偏航单位范数；权重 `(λ_p, λ_ψ, λ_g, λ_u) = (0.25, 0.10, 0.25, 0.02)`。
  - 接触组：用可微 FK 惩罚支撑脚滑动（相邻帧）、漂移（lag 2/4/8）、高度误差、以及全帧穿透；前三项权重各 0.05，穿透权重 1。地面用干净动作最低脚底高度的第 5 百分位估计；支撑掩码来自干净运动，**Plan 概率只作条件、不作掩码替代**。

### 2.4 自动掩码与参考感知编辑
- **类型化请求解析**：编辑适配器输入后续指令 + 时长 + 仅源运动的运动学摘要（FK 腕高相对骨盆），输出 `A_t = (attribute, effector, signed change, interval)`。
- **确定性编译器**：把 effector 扩展到运动链 `K(e)`，解析时间区间 `[a,b)`，生成身体—时间掩码 `S_t(f,j) = 1[j ∈ K(e_t)]·1[a_t ≤ f < b_t]`；手高编辑时运动链含 7 个手臂坐标，其余（含区间外的手臂）受保护；非法请求则掩码关闭、源不变。
- **源相对目标**：`D_f,h = 1[h = e*]·d·sin²(π(f−a)/(b−a−1))`，即带正弦平方时间包络的带符号腕高偏移（0<|d|≤0.10 m）。
- **参考保持的采样**：编辑器为条件扩散 `M_{t+1} ~ p_η(· | f(u_t), M_t, S_t, D_t)`（马尔可夫状态 `X_t=(M_t,u_t)`）；每个 DDIM 步后做**参考投影**：`x_{k−1} = S⊙x̃_{k−1} + (1−S)⊙q_{k−1}(Enc(M_t))`，最后一步对受保护坐标**精确复制**，因此受保护坐标误差为 0。多轮编辑中每次输出成为下一轮参考。
