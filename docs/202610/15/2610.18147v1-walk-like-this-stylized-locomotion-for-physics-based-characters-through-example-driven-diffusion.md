## 摘要
我们提出了一个用于富有表现力的腿式运动的实时框架，可独立控制速度与风格。与通常需要显式风格标签进行训练的现有数据驱动控制器不同，我们的方法高效利用大规模非结构化运动数据，并能泛化到未见过的风格。我们通过一种定制的采样策略将风格与功能性运动解耦，该策略用于训练一个风格编码器，其输出对自回归扩散模型进行条件化。在推理时，用户提供一段风格参考片段和一个摇杆速度命令。随后，扩散模型生成一个运动学参考，并由强化学习控制器进行跟踪。为提高用户可控性和风格化强度，我们提出了一种注意力偏置机制和一种速度命令校正策略。我们在仿真中的基于物理的人形角色和实体机器人上展示了我们的方法，展现了鲁棒的实时控制和连续风格调制。结果最好参见我们的补充视频（https://www.youtube.com/watch?v=roFnS6N7nJ4）。

## Abstract
We present a real-time framework for expressive legged locomotion that enables independent control over velocity and style. Unlike existing data-driven controllers, which typically require explicit style labels for training, our method efficiently leverages large-scale unstructured motion data and generalizes to unseen styles. We disentangle style from functional locomotion through a tailored sampling strategy used to train a style encoder whose output conditions an autoregressive diffusion model. During inference, the user provides a style reference clip and a joystick velocity command. The diffusion model then generates a kinematic reference tracked by a reinforcement learning controller. To improve user controllability and stylization strength, we propose an attention biasing mechanism and a velocity command correction strategy. We demonstrate our method on a physics-based humanoid character in simulation and on a physical robot, showcasing robust real-time control and continuous style modulation. The results can be best seen in our supplemental video (https://www.youtube.com/watch?v=roFnS6N7nJ4).

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：基于物理的人形角色控制长期停留在"功能性运动"层面（如稳定行走、跟随速度指令），而如何让角色以**富有表现力的风格**（expressive gait style）运动，同时保持实时性与物理可行性，仍是开放难题。
- **现有方法的缺口**：
  - 风格化运动控制器通常围绕**固定目标**设计，或只能模仿训练时见过的**狭窄运动分布**，训练后缺乏风格变化与泛化能力。
  - CAMDM 虽实现实时风格化控制，但依赖**显式离散风格标签**，无法泛化到训练集之外的风格。
  - 风格迁移方法（如 SMooDi、MoST）质量高，但**速度慢**，不适合实时机器人跟踪与交互控制。
  - 物理基础的运动生成器（如 PhysDiff、PARC）虽能保证物理性，但**缺乏对风格的表达性控制**。
- **整体含义**：论文提出一个统一的实时框架，让用户通过**摇杆速度指令**控制"做什么"、通过**一段风格参考片段**控制"怎么做"，且风格参考可来自任意来源（MoCap、视频）与任意时长，并能泛化到训练时未见过的风格。这是首次在物理人形机器人上实现"速度—风格独立控制 + 未见风格泛化"的系统。

## 2. 方法论

### 2.1 核心思想
- 采用**两阶段架构**：
  1. **运动学自回归扩散模型**：根据速度指令与风格条件生成运动学参考。
  2. **RL 跟踪控制器**：将生成的参考运动落地到物理角色/机器人上。
- 关键创新在于**用风格编码器替代离散标签**，使模型能利用大规模无标注运动数据，并泛化到未见风格。

### 2.2 关键技术与算法流程

- **自回归扩散模型 M**：
  - 条件化为：`M0_fut = M(Md_fut, d; Mpst, Dpst, Cfut, csyl)`
  - 其中 `Mpst` 为过去 P 帧运动，`Dpst` 为过去运动的差分（增强自回归连贯性），`Cfut` 为未来根轨迹（含 x-y 坐标与 yaw 角），`csyl` 为风格嵌入。
  - 与 CAMDM 不同，未来根状态只给 yaw 角而非完整旋转，roll/pitch 完全由风格决定。
  - 运动表示：根位置/朝向、关节朝向、连杆位置/朝向，旋转用 6D 表示，除关节朝向外均变换到角色 heading 坐标系。

- **风格编码器 E**：
  - 用 transformer-encoder 将风格片段压缩为潜在向量 `csyl = E(Msyl)`。
  - 强制 `‖csyl‖ = 1`（L2 归一化），便于泛化并支持**球面线性插值（slerp）**混合风格。
  - 引入**register token** 作为工作空间，取最后一层输出作为风格嵌入。

- **定制双采样训练策略（解耦风格与内容）**：
  - 从同一运动序列中采样 `P+F` 连续帧得到 `Mpst`、`Mfut`。
  - 另从同一序列中采样长度 `S ∈ [Smin, Smax]` 的窗口作为风格片段 `Msyl`。
  - 关键点：**风格窗口与内容窗口不同**，迫使编码器提取风格而非内容。论文定义"内容"为地面投影根轨迹，"风格"为其余运动动力学。
  - 损失 = 重建损失 + 速度/关节一致性/脚滑损失（沿用 CAMDM）。

- **推理时注意力偏置（Attention Bias）**：
  - 注意力公式：`attention(Q,K,V;B) = softmax(QK^T/√D + B) V`
  - 对风格 token 的注意力加正偏置 `wsyl ≥ 0`，对过去运动 token 加负偏置 `wpst ≤ 0`，迫使模型尊重风格条件。
  - 相比 CFG，偏置修改的是 softmax 前的权重，注意力仍是归一化分布，更接近训练分布，且只需一次前向。

- **速度指令校正（Velocity Correction）**：
  - 追踪当前位置/朝向 `pcur, ψcur` 与期望位置/朝向 `pdes, ψdes`。
  - 校正公式：
    - `ṽx,y = vx,y + kp Rψ(ψcur)^T (pdes_x,y − pcur_x,y)`
    - `ṽψ = vψ + kψ (ψdes − ψcur)`
  - 将期望状态投影到当前状态的邻域（位置 ≤0.5 m、yaw ≤0.5 rad），防止过度校正。

- **RL 跟踪控制器**：
  - 用 PPO 训练，策略输出 PD 控制器关节设定点。
  - 观测含关节位置/速度、根角速度、投影重力、历史动作；目标含参考运动特征、目标根线/角速度及校正后的速度指令。
  - 奖励分三类：跟踪奖励、正则化奖励、任务奖励（joystick 奖励可缓解扩散模型脚滑等非物理目标）。
  - **离线生成训练数据**：用扩散模型自回归 rollout 生成大规模数据集，避免 RL 在线查询扩散模型的开销。
  - **开环部署**：扩散模型条件于自身过去预测而非真实状态，提升风格质量，且可预计算缓存。

## 8. 不足与局限

- **方法局限**：
  - RL 策略虽能修正脚滑等伪影，但运动学与速度指令不匹配时会出现**额外中间步**，自然步态仍不完美，作者建议引入隐式奖励（如 AMP/ASE）改善。
  - 仅适用于**与运动方向无关的风格**；对方向强耦合的风格（如月球漫步、侧手翻）需要匹配的速度指令。
  - 若风格本身由根轨迹定义（如边走边旋转），会与摇杆指令产生**接口冲突**，论文选择优先用户指令。
  - 风格为**隐式学习**，无法对上下半身分别风格化或部分风格化。
- **实验覆盖局限**：
  - 扰动实验仅测试单一 600 N 力，未覆盖多方向、多强度、多地形组合。
  - 未在真实机器人上做长时间极端扰动测试，鲁棒性验证仍以仿真为主。
  - 风格泛化主要用 100STYLE 未见风格与少量视频，视频风格数量有限。
  - 训练与部署均针对特定角色（人形 + G1），跨形态泛化未验证。
- **潜在偏差风险**：
  - FID 与风格准确率依赖自训练的风格分类器，评估结果可能受分类器质量影响。
  - 未见风格评估中，作者自述"细节处理较差、FID 较高"，说明泛化并非无代价。
  - 算力信息未说明 GPU 数量，复现成本评估受限。
