## Abstract 

Classifier-Free Guidance (CFG) with guidance scale γ is commonly motivated by the ω-powered conditional distribution obtained by setting ω = γ, but CFG does not, in general, sample from this distribution exactly. We study whether the powered target can instead be learned explicitly. We introduce Importance-Weighted Conditional Flow Matching (IW-CFM), which reweights conditional flow-matching examples using density ratios obtained from frozen conditional and unconditional flow models. With exact normalized weights, the resulting objective has the same gradient as flow matching on the powered target; in practice, we use self-normalized estimation and a regularized empirical approximation for high-dimensional data. On synthetic distributions, IW-CFM recovers analytical powered targets for which numerically matched CFG, γ = ω, exhibits a visible mismatch. On ImageNet, an amortized lightweight corrector achieves better alignment than fixed- and matched-guidance CFG with the corresponding weighted and filtered reference distributions. We additionally present an exploratory CLIP analysis of powered-density rankings on real ImageNet data. Aggregate shifts across selected prompt-specific contrasts coexist with heterogeneous classwise responses, including nonmonotonic trajectories. These results provide a practical route for studying and approximating model-defined powered conditional distributions. 1

## 1 Introduction 

Diffusion models (Sohl-Dickstein et al., 2015; Ho et al., 2020; Song et al., 2021), flow matching (FM) (Lipman et al., 2023; Liu et al., 2023), and stochastic interpolants (Albergo et al., 2025) are widely used for continuous data such as images and audio. These methods learn a process between a simple prior, such as a Gaussian, and the data distribution. We work in the Gaussian flow-matching setting. Conditional models commonly use Classifier-Free Guidance (CFG) (Ho & Salimans, 2021; Zheng et al., 2023; Dao et al., 2023), which steers generation toward a condition y by combining conditional and unconditional vector-field estimates. ## 2 Modeling the ω-Powered Distribution 

We adopt the Flow Matching (FM) framework (Lipman et al., 2023), which defines a probability path pt(x)for t ∈ [0 , 1] interpolating between a prior p0(x) = N (x; 0 , I ) and data p1(x). The flow is governed by a time-dependent vector field v(·, t ) via the ODE dx t = v(xt, t )dt .

2.1 Background on Conditional Flow Matching 

In Conditional Flow Matching, for each data point x1, we define a conditional probability path pt(x|x1) that interpolates between a prior sample x0 ∼ p0 and the data point x1. The path is constructed by defining the interpolated sample xt and its corresponding target velocity vector ut as:

2.5 Amortized ω-Powering via Lightweight Correctors 

To avoid training a separate model for each powering parameter, we treat ω as a conditioning variable for a single corrector network. We implement this corrector, vϕ, using lightweight, parameter-efficient designs. For 4synthetic experiments, vϕ is an MLP that predicts an affine correction to the baseline conditional vector field. For real-world image data (ImageNet), we build upon the Scalable Interpolant Transformer (SiT) backbone (Ma et al., 2024), introducing a parameter-efficient adapter into its Transformer blocks, similar to Jensen & Sadat (2025). This way, we learn a single model to target the entire family of powered distributions, adding only about 5% of the parameters compared to the baseline SiT. A key challenge in this amortized setting is normalizing the importance weights. Normalizing globally across a batch with different conditions and powering parameters changes the effective distribution over ( y, ω ): each pair is weighted in proportion to its partition function Z(y, ω ) rather than according to the intended outer distribution p(y)p(ω) (see Section A.2). We instead use hierarchical batches and nested normalization. At each training step, we sample M condition–parameter pairs ( yj , ω j ) and a subbatch of K data points for each pair. We normalize weights only within samples that share ( yj , ω j ), preserving the intended outer distribution. Algorithm 1 gives the procedure. 

2.6 Scaling to High-Dimensional Data 

Algorithm 1 provides an asymptotically unbiased estimator for streaming data, which we apply directly in our synthetic experiments. However, this approach is computationally prohibitive for high-dimensional data. We therefore adopt two practical techniques that enable an efficient application of IW-CFM to ImageNet. 

Amortized Training with Precomputed Weights. Sampling from the weighted empirical distribution at an arbitrary continuous ω would require computing the weight of every ImageNet training instance for every sampled ω. We instead precompute normalized weights over the full dataset at integer powering parameters. Given a continuous ω, we sample training instances with replacement using the weights at the nearest integer ¯m(ω). For those instances only, we linearly interpolate the self-normalized weights at ω and multiply the flow-matching loss by rreg  

> ω

(i|y)/r reg ¯m(ω)(i|y). This proposal is more efficient than uniform sampling followed by SNIS: at large ω, most stored weights are zero, so most uniformly sampled instances would provide no weighted training signal. Section C.5.1 specifies the zero-weight fallback and numerical threshold. 

Operational ImageNet Weights. The population formulation assumes access to exact conditional and unconditional densities. On ImageNet, we instead use densities induced by frozen pretrained SiT vector fields, which are learned approximations to the data distributions, and evaluate them numerically through augmented ODE integration. Powering amplifies errors in these density estimates. In particular, if the estimated log-density ratio ̂

d(x, y ) = log ̂p(x|y) − log ̂p(x)differs from its ideal value by an additive error ϵ(x, y ), then the corresponding unnormalized weight is distorted by the multiplicative factor exp(( ω − 1) ϵ(x, y )). At large ω, even moderate errors can therefore cause a few training instances to dominate the normalized empirical distribution. Given any fixed set of endpoint weights, importance-weighted flow matching trains toward the distribution encoded by those weights. It does not, however, correct errors in the weights themselves. If exact and reliable densities were available, we could use the unregularized density ratios directly. With the available ImageNet estimates, their extreme concentration produces a brittle empirical target: most normalized weights become numerically zero, while a small number of potentially misestimated instances receive nearly all of the mass. We therefore regularize the weights before training. Following the standard temperature-scaling transformation (Guo et al., 2017), we first contract all log-density-ratio differences by a temperature T > 1. ## 3 Related Work 

The closest methodological predecessor is Energy-Weighted Flow Matching (Zhang et al., 2025). At the population level, the IW-CFM objective is a specialization of their conditional energy-weighted flow-matching formulation. For a fixed condition y, setting the base distribution to p(x|y), the energy to Ey (x) = log p(x) − log p(x|y), and β = ω − 1 gives 

p(x|y) exp[ −βE y (x)] ∝ p(x|y)ω p(x)1−ω .

Thus, the endpoint importance-weighting principle and the resulting population equivalence to flow matching on the reweighted target follow from Zhang et al. (2025). Our contribution concerns the conditional, amortized, and high-dimensional realization of this principle. While Zhang et al. (2025) primarily develop energy-weighted generative models for offline reinforcement learning and additionally show, in a low-dimensional synthetic bandit ablation, that a single energy-weighted diffusion score model can be conditioned on β, IW-CFM uses a lightweight flow-matching corrector to approximate model-defined powered conditional distributions across ImageNet classes and a continuous range of ω. Our parameter-efficient corrector conditioned on ω is inspired by guidance-distillation architectures (Meng et al., 2023; Jensen & Sadat, 2025), but is trained to approximate a family of powered vector fields rather than to reproduce standard CFG. This setting requires normalization across heterogeneous ( y, ω ) pairs: our hierarchical estimator normalizes within each pair, preserving the intended outer distribution p(y)p(ω) rather than reweighting pairs according to their partition functions. We further develop a regularized ImageNet construction based on precomputed conditional and unconditional densities, per-class weight regularization, nearest-integer proposal sampling, and interpolation between precomputed powering parameters. Our experiments evaluate recovery across a family of analytical synthetic targets and alignment with regularized ImageNet references. Analyses by Bradley & Nakkiran (2024) and Chidambaram et al. (2024) provide evidence that CFG does not generally sample from the powered distribution suggested by the numerical identification γ = ω and can shift probability mass away from the data manifold. These works diagnose the discrepancy; IW-CFM instead learns a vector field conditioned directly on the powering parameter ω under the idealized formulation and its regularized empirical counterpart on ImageNet. Feynman–Kac Correctors (FKC) (Skreta et al., 2025b) use particle-based Sequential Monte Carlo to target modified distributions at inference time. Rectified Gradient Guidance (REG) (Gao et al., 2025a) formulates 6powered-distribution sampling as reward optimization over the sampling trajectory, while Kit et al. (2025) study a related debiasing problem for discrete diffusion. IW-CFM instead shifts the main computation to density precomputation and corrector training, after which sampling uses a single learned vector field. CFG++ (Chung et al., 2025) modifies guidance to reduce off-manifold behavior, while Galashov et al. (2025) learn a guidance network that better matches the original conditional distribution p(x|y). Their target differs from ours: IW-CFM studies powered conditional distributions and a regularized empirical implementation on ImageNet. Finally, Karczewski et al. (2025) investigate extreme high-density regions of diffusion models and find that samples with substantially higher likelihood than those produced by standard samplers can be blank, blurry, or cartoon-like. Their results reinforce the distinction between model likelihood and perceptual quality. Our target differs from maximizing either the marginal or conditional likelihood in isolation: pω (x|y) increasingly emphasizes features discriminative of the condition. Their observations nevertheless motivate regularizing the concentrated importance weights in our ImageNet implementation. 

## 4 Experiments 

Our primary experiments address two questions. First, when the analytical ω-powered density is available, does IW-CFM recover that target more faithfully than CFG with the numerically matched guidance scale 

γ = ω and the other evaluated alternatives? Second, on ImageNet, how closely do samples from the learned corrector align with weighted and filtered references derived from rreg  

> ω

? We study the first question on two-dimensional synthetic distributions and the second with a lightweight corrector for a pretrained SiT model. The exploratory analysis of powered-density rankings on real ImageNet data follows in Section 5. 

4.1 Synthetic Target Recovery 

We first test IW-CFM against the target density on two-dimensional synthetic datasets: a three-mode Gaussian mixture and a distribution inspired by fractal-like geometries (for details see Section C.1). For these tasks, we compute importance weights during training using the minibatch SNIS estimator in Algorithm 1. As shown in Figures 1a and 1b, CFG with matched guidance γ = ω departs from the analytical target contours, whereas IW-CFM closely follows them. This controlled setting tests the motivating identification in Equation (5) before the density-estimation and regularization choices needed for ImageNet are introduced. Sections C.1 and D.3.1 provide hyperparameters and additional density visualizations. We additionally evaluate REG and FKC on the exact conditional and unconditional vector fields of the three-Gaussian problem. Under the tested configurations, neither method closely matches the analytical powered contours. We therefore do not conduct an image-scale comparison, and our ImageNet results make no claim of superiority over REG or FKC. Section D.3.2 provides implementation details and results. 

4.2 ImageNet Generation 

We scale our method to ImageNet at 256 × 256 resolution. The IW-CFM corrector operates in the latent space of the Stable Diffusion VAE used by the pretrained SiT model (Rombach et al., 2022). Log-probability computation, loss reweighting, and sampling all use this latent space; we decode to pixels only for visualization and image-based metrics (CLIP, FID, and DINOv2). The corrector is a parameter-efficient adapter in the frozen Transformer blocks of a pretrained SiT-XL/2 (Ma & Ryoo, 2024), following Jensen & Sadat (2025). We train it with ω ∼ U [4 , 128]; the real-data CLIP analysis in Figure 6 evaluates a wider range of ω values. On ImageNet, IW-CFM samples training data from the precomputed nearest-integer weights and corrects each loss with its interpolated continuous-ω weight, as described in Section 2.6. At inference, we optionally apply CFG with scale γ to vϕ(x, t, y, ω ). To support this option, we replace the class token with a null token during 10% of training iterations. This additional guidance is a sampling heuristic and need not preserve target fidelity. We use unguided inference ( γ = 1) to assess the learned distributional shift, γ = 1 .5 for FID, FD-DINOv2, and PRDC, and γ = 4 for qualitative visualizations. We independently ablate two components of the ImageNet implementation: the numerical accuracy of log-density estimation and the regularization applied to the resulting importance weights. In each experiment, all other settings are held fixed. 

Number of log-density integration steps. We conduct this ablation on a fixed subset of 100 ImageNet categories, described in Section C.6.1, while keeping the target-regularization parameters at their default values. For each evaluated step count, we recompute the log-densities and importance weights and train a new corrector from scratch. All models are evaluated against the common weighted and filtered references constructed from the 250-step log-density estimates, using 50 generated samples per category. As shown in Figure 3, the results remain relatively close at ω ∈ { 4, 8}, begin to separate at ω = 16, and diverge substantially for ω ≥ 32. This behavior is consistent with the error-amplification effect discussed in Section 2.6: an additive error in the estimated log-density ratio is multiplied by ω − 1 before exponentiation. Consequently, the numerical precision used for density estimation should be selected according to the largest powering parameter of interest; a step count adequate at small ω need not remain adequate under stronger powering.

## 5 Exploratory Analysis of Powered-Density Rankings on Real Data 

The preceding experiments provide the primary validation of target recovery and alignment with the regularized ImageNet references. Here, we present a complementary, exploratory characterization of how powering reorganizes real ImageNet examples. For this analysis, we evaluate the conditional log-density log p(x|y) and unconditional log-density log p(x) of every ImageNet instance (Deng et al., 2009) using the same pretrained SiT model (Ma et al., 2024) that underlies standard CFG.

Within each category, we rank ImageNet instances by the powered-density score defined in Equation (1); the class-dependent normalizing constant does not affect the ordering. All rankings in this section are computed from the unregularized, model-defined powered log-density score, prior to the temperature scaling and log-weight clipping introduced in Section 2.6. Those transformations are used only to construct the operational ImageNet training and reference weights. Varying ω changes which images occupy the extremes of the ranking. Figure 5 provides one qualitative example, and Section B.2 presents additional selected categories. 

Illustrative ranking changes. ## 6 Discussion 

IW-CFM has several limitations. First, it depends on the quality and support coverage of the base density models. The ImageNet implementation also depends on regularized precomputed weights, nearest-integer sampling, and interpolation. Computing these weights requires a correction dataset. We use that dataset to correct a pretrained model rather than train one from scratch, but performance may change when the correction data are smaller than or shifted from the original training set. Second, density precomputation requires solving two augmented ODEs, one conditional and one unconditional, for each training instance. This one-time cost enables sampling with a single learned corrector. The ImageNet weight construction has a separate regularization trade-off : log-weight clipping and temperature scaling limit concentration on a few training modes, but their settings are chosen manually. Automated regularization schedules remain future work. Our CLIP analysis is descriptive and prompt-dependent; consequently, neither the class-averaged trajectories nor individual examples establish statistically significant or universal attribute effects. Finally, our current nested estimator and ImageNet implementation are tailored to categorical conditioning because self-normalization groups samples by a shared class label. The population formulation itself does not require categorical conditions. Applying the practical estimator to high-cardinality or continuous conditions, such as text prompts, will require a different normalization strategy. 12 7 Conclusions 

In this work, we introduced Importance-Weighted Conditional Flow Matching (IW-CFM) to learn model-defined ω-powered conditional distributions. With exact densities and normalization, its population objective targets the powered vector field. The practical finite-sample estimator uses self-normalized weights, and the ImageNet implementation uses regularized precomputed integer weights with interpolated per-sample corrections. The synthetic experiments test the analytical target directly and show that IW-CFM recovers it more faithfully than the evaluated alternatives, including CFG at the numerically matched scale γ = ω. On ImageNet, the learned corrector aligns more closely than CFG with the weighted and filtered regularized references. Unguided evaluation provides evidence of a learned distributional shift, while the guided practical results include an additional inference-time CFG heuristic and therefore do not isolate the distributional shift learned by the corrector. The complementary real-image analysis shows that powered-density rankings and their selected CLIP contrasts vary with ω. The across-class averages exhibit several baseline-relative shifts, while the underlying classwise trajectories are heterogeneous and can be decreasing or nonmonotonic. IW-CFM learns multiple powered targets with one corrector. Although our implementation uses a SiT backbone, the population formulation applies to other continuous domains. Applying it to video or 3D synthesis would require testing the available density estimates, normalization schemes, and operational targets in those settings. 

Broader Impact Statement 

This work studies generative modeling of images, with the technical goal of producing realistic and diverse samples. That goal is not socially neutral: greater realism makes synthetic images harder to distinguish from photographic evidence, while greater diversity broadens the range of content that can be generated at scale. These capabilities may support valuable scientific and creative applications, but they may also facilitate deception, impersonation, non-consensual imagery, and other forms of abuse. Improvements in generative modeling should therefore be accompanied by careful evaluation of misuse risks and appropriate safeguards in any deployed system.

C.1 Synthetic 

The synthetic tasks test whether IW-CFM recovers pω (x|y) when the ground-truth density and vector field are available analytically. We use a three-mode Gaussian mixture and a distribution with a tree-like branching structure. 

Analytical quantities. The synthetic implementations provide • conditional and unconditional log-densities, log p(x|y) and log p(x); • conditional and unconditional ground-truth vector fields, v(xt, t, y ) and v(xt, t ); and • exact conditional and unconditional sampling procedures. 

Distribution Parameters. 

• Three-Gaussian mixture: three components with means μ ∈ { [−1, −0.866] , [0 , 0.866] , [1 , −0.866] } and identity covariance. • Fractal distribution: a reimplementation of the tree-like structure in Karras et al. (2024). Each category is a mixture of 1,016 Gaussian components arranged along the branching structure. We use slightly modified parameters. 

Corrector Architecture. We train a lightweight affine correction to the analytical conditional vector field: 

vϕ(x, t, y, ω ) = v(xt, t, y ) ⊙ scale( xt, t, y, ω ) + shift( xt, t, y, ω ) (16) where a multilayer perceptron maps ( xt, t, y, ω ) to scale and shift. 

Training and Hyperparameters. We train the corrector for 8,192 iterations with a total batch size of 8,192, partitioned into M = 256 ( y, ω ) pairs and K = 32 samples per pair for nested normalization. For both tasks, p(ω) is uniform on [1 , 8].

C.5 SiT Corrector: Implementation and Training Details 

To scale our method to ImageNet, we implement the IW-CFM corrector as a parameter-efficient adapter integrated into a frozen SiT-XL/2 backbone. The architecture and parameter-efficient conditioning follow the design of Jensen & Sadat (2025). 

Training Strategy and Efficiency. We precompute the normalized importance weights on an integer grid. For each continuous ω ∼ U [4 , 128], the ImageNet data loader rounds to the nearest grid point ¯ m(ω)and samples examples with replacement according to the stored sampling weights at that point. For each sampled instance i, we interpolate the unmodified weights at the adjacent grid points to obtain rreg  

> ω

(i|y). The flow-matching loss is multiplied by rreg  

> ω

(i|y)/r reg ¯m(ω)(i|y) when the denominator exceeds 10 −9, and by one otherwise. The unit fallback gives re-injected training examples an unweighted flow-matching loss; these examples would otherwise receive zero weight. It also avoids division by a numerically zero stored weight. We therefore interpolate weights only for sampled instances. This avoids the nested normalization in Algorithm 1 during corrector training and is more efficient than uniform sampling followed by self-normalized weighting, for which most sampled examples would have zero loss weight. • We train with a global batch size of 256 distributed across 8 GPUs. • Normalizing independently on each GPU’s local subbatch would reduce the normalization-group size, lowering the effective sample size (ESS) and increasing variance. • The precomputed proposal and correction weights are shared across workers. 

Optimizer and Schedule. We use Adam with β1 = 0 .5, β2 = 0 .9, and a base learning rate of 1 .0 × 10 −3.We train for 45,000 iterations with a 2,000-iteration linear warmup followed by cosine decay. 

Evaluation Setup. We sample with a Heun solver using 250 function evaluations (125 steps). At each ω,we generate 50,000 instances (50 per ImageNet class). We use T = 1 .2, a per-class clipping fraction τ = 0 .01 (1%), a zero-weight re-injection fraction ρ = 0 .05, and a loss-correction threshold of 10 −9. D.5 Memorization Analysis 

To assess whether IW-CFM retrieves high-likelihood training instances rather than generating novel variations, we conduct a nearest-neighbor analysis. This test asks whether training-data retrieval could explain the observed distribution-alignment and paired-CLIP score differences. 

Methodology. We follow the framework of Gu et al. (2025). After deduplicating the training set as described below, we flatten the VAE latent tensors and compute Euclidean distances from each generated sample to every remaining training instance. We apply no additional distance filter before sorting these distances. Let 

d1 ≤ d2 be the two smallest distances. We flag a generated sample as a potential retrieval when 1.82 d1 < d 2. (19) For d1 > 0, this is equivalent to d2/d 1 > 1.82; the multiplicative form also covers an exact match with d1 = 0. The reported memorization ratio is the fraction of generated samples satisfying this condition. We use the VAE latent representation on which the generative model operates; this choice does not guarantee that the distances measure semantic similarity. 

Deduplication. ImageNet contains duplicate and near-duplicate training instances. A generated sample may therefore have similar distances to two copies of the same image ( d1 ≈ d2), causing the ratio test to miss a possible retrieval. Before the nearest-neighbor search, we deduplicate the training set by removing instances within an ℓ2-distance threshold of dduplicate = 35.
