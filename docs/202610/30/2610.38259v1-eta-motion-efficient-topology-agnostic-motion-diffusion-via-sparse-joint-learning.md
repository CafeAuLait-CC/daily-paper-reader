## 摘要
拓扑无关的运动生成旨在为具有任意骨架的多样角色合成运动。与传统假设固定骨架模板的运动生成不同，该设定必须处理不同角色间多样的关节配置和不一致的关节语义。现有方法通过稠密的全关节建模来应对这一挑战，但这会带来巨大的计算开销，并阻碍跨多样骨架拓扑学习可迁移的运动模式。我们提出 ETA-Motion，一个基于稀疏关节学习的拓扑无关运动生成框架。我们的方法并非从所有关节学习运动，而是使用紧凑的关节子集来减少冗余，并在所得的稀疏骨架上训练运动生成器。为促进不同拓扑之间的对应关系，我们引入结合文本和视觉线索的语义关节嵌入，并采用拓扑感知的训练目标以保留骨架结构。尽管 ETA-Motion 仅在稀疏骨架观测上训练，但在推理时支持全骨架运动生成。实验结果表明，ETA-Motion 优于现有的拓扑无关基线，同时显著提升了效率，并增强了对未见运动和未见拓扑的泛化能力。

## Abstract
Topology-agnostic motion generation aims to synthesize motions for diverse characters with arbitrary skeletons. Unlike conventional motion generation, which assumes a fixed skeletal template, this setting must handle diverse joint configurations and inconsistent joint semantics across characters. Existing methods address this challenge through dense full-joint modeling, which incurs substantial computational cost and hinders learning transferable motion patterns across diverse skeletal topologies. We present ETA-Motion, a topology-agnostic motion generation framework based on sparse joint learning. Instead of learning motion from all joints, our method uses a compact subset of joints to reduce redundancy and trains the motion generator on the resulting sparse skeleton. To facilitate correspondence across diverse topologies, we introduce semantic joint embeddings that combine textual and visual cues, together with topology-aware training objectives for preserving skeletal structure. Although ETA-Motion is trained only on sparse skeletal observations, it supports full-skeleton motion generation during inference. Experimental results demonstrate that ETA-Motion outperforms existing topology-agnostic baselines while significantly improving efficiency and generalization to unseen motions and unseen topologies.

## 1. 核心问题与研究背景

- **任务设定**：拓扑无关（topology-agnostic）文本驱动运动生成——给定文本描述与任意骨架（关节数量、层级、语义均可不同），合成对应角色的运动。
- **与传统设定的差异**：传统运动生成（如 HumanML3D 体系）假设所有样本共享固定骨架模板，关节索引天然对齐；而拓扑无关设定下关节索引不再具有一致语义，articulation 结构差异巨大。
- **现有方法的瓶颈**：AnyTop、How to Move Your Dragon 等采用**稠密全关节建模**，带来两方面问题：
  - 计算开销随关节数快速增长（空间注意力为 O(FJ²)）；
  - 迫使模型学习拓扑特定细节，妨碍跨骨架的可迁移运动模式学习，进而影响生成质量与泛化。
- **整体含义**：论文主张拓扑无关运动学习的核心矛盾不只是效率，而是"冗余表示—建模复杂度—泛化能力"的耦合；因此提出以**稀疏关节子集训练、全骨架推理**作为新范式。

## 2. 方法论

### 2.1 核心思想
- 训练阶段只在**紧凑关节子集（预算 K）**构成的稀疏骨架上学习运动动力学；推理阶段借助干净 rest pose 提供的结构信号，直接为任意目标全骨架生成运动。

### 2.2 运动表示
- 放弃关节旋转、父节点相对偏移等与运动链强绑定的表示，直接建模 **3D 关节位置** X ∈ R^{F×J×3}。
- root 关节用全局坐标，非 root 关节表示为相对 root 的坐标，从而避免骨架特定的运动学参数化。

### 2.3 网络架构
- 条件扩散模型，骨干为 **DiT + AdaLN-Zero**，输入含噪运动 X_t，预测干净运动 X_0。
- 参照 AnyTop，将干净 rest pose P ∈ R^{J×3} **前置拼接**到含噪序列，作为显式结构参考；输入 token 数为 (F+1)×J。
- 训练时 J = J_max，不足者 padding 并用 validity mask 屏蔽（空间注意力中屏蔽、时间注意力中排除监督）；推理时 J = J_target，无需 padding。
- 骨干由**空间注意力（帧内关节交互）、时间注意力（关节跨帧动态）、FFN** 交替组成；空间注意力复杂度 O(FJ²)，时间注意力 O(JF²)。

### 2.4 稀疏关节学习
- 在关节预算 K ≪ J_max 下训练，空间注意力复杂度由 O(FJ_max²) 降至 O(FK²)，同时减少 batch 内 padding。
- 关节选择：以 root 为起点做**最远点采样（FPS）**，确定性启发式。
- 稀疏骨架重构：每个保留关节连接到原运动学层级中**最近的保留祖先**，得到稀疏但拓扑一致的骨架。
- 训练只见稀疏骨架，推理可迁移到全骨架；rest pose 是迁移的关键结构信号。

### 2.5 语义关节嵌入
- 动机：同一关节索引在不同骨架上语义不同，且资产自带关节名常含噪声/缺失/不一致。
- 形式：E = E_text + E_vis，沿关节维广播到时间维后与运动 token 相加，H′ = H + E。
- **文本嵌入**：关节名经预训练 **T5** 编码，线性投影到运动隐空间。
- **视觉嵌入**：多视角渲染网格，按可见性掩码加权聚合 **DINOv2** 特征到顶点（式 1），再用 **skinning weights** 聚合为关节级特征（式 2），最后线性投影。
- 文本单独不足（如 "arm" 可能对应四足前肢或鸟翼），视觉线索提供互补语义。

### 2.6 拓扑感知训练目标
- 重建损失：L_rec = ‖X̂_0 − X_0‖²₂，仅作用于选中关节。
- 骨长损失：在稀疏骨架边集 E_K 上约束预测骨长与真值骨长一致（逐帧独立计算）。
- 总损失：L = L_rec + λ_bone · L_bone。

## 8. 局限与潜在问题

- **对 rest pose 的依赖较强**：推理阶段的结构迁移依赖干净、语义一致的 rest pose；若目标资产 rest pose 含噪声、姿态非标准或缺失，稀疏关节上学到的动力学能否正确“铺开”到全骨架缺乏系统验证，论文仅给出有限定性案例。
- **稀疏化可能丢失细粒度运动线索**：FPS 选择与“最近保留祖先”重构会丢弃部分末端或细节关节，对于手指、面部、尾部末梢等高频小幅度运动，K=20 的预算是否足够未单独评估；论文的运动多为整体体态，细粒度动作的适用性仍待检验。
- **全骨架推理存在训练—推理分布偏移**：训练只见稀疏骨架的空间交互，推理时却需处理全骨架的关节间注意力；rest pose 作为提示能缓解但无法完全消除该偏移。Unseen Topology 覆盖率绝对值为 70.66，说明跨拓扑生成仍有明显失败空间。
- **语义嵌入的泛化收益不稳定**：视觉嵌入在 Seen / Unseen Motion 上有效，但在 Unseen Topology 上略低于去视觉嵌入的变体，表明其提供的主要是“已见语义—关节”的对应线索，对真正新拓扑的语义迁移帮助有限；且视觉嵌入依赖可渲染网格与可靠蒙皮权重，资产缺失时管线会退化。
- **表示与约束的匹配问题**：直接预测全局/相对 root 的关节位置虽避开骨架特定参数化，但骨长仅通过软损失约束，未显式保证运动学一致性；与基于旋转+FK 的方法在 BLV 等指标上的可比性有限，论文虽作解释，但评测口径仍需谨慎解读。
- **实验外部效度有限**：仅使用 Truebones Zoo 一个数据集，物种与动作类型集中；基线多为自行复现或改造，作者也承认未达原论文水平；缺少多次运行方差、置信区间与显著性检验，主表与消融表训练步数不同，跨表数值不宜直接比较。
- **评测与用户研究规模有限**：Coverage 依赖对训练运动的检索式覆盖，可能偏向训练分布内模式；用户研究 30 人、仅两个问题，统计效力有限；未报告推理时延与 100 步扩散的实际部署成本，也未评估动画师工作流中的可用性。
- **方法边界未充分讨论**：对柔性体、非刚性形变、多角色交互、含物理接触的运动等场景未作讨论；稀疏关节预算 K 为固定超参，未给出按骨架规模或任务复杂度自适应选择的原则。

## 9. 对领域的启示

- **“表示稀疏性”可作为归纳偏置**：论文的核心启示不是单纯降本，而是通过限制训练时的关节交互图，抑制模型对拓扑特定细节的过拟合，从而把学习重心放在跨骨架可迁移的运动动力学上。这一视角可迁移到其他结构化生成任务（如场景图、分子、多智能体轨迹）。
- **结构提示替代结构重训练**：以 rest pose 作为显式结构条件，使同一模型在训练与推理使用不同关节集，提供了一种“训练—推理解耦”的轻量适配思路，避免为每个新骨架微调。
- **语义关节嵌入的必要性与边界**：关节名文本与视觉外观互补，但论文结果显示其收益主要集中在语义可对应的场景；未来工作应明确何时需要视觉线索、何时干净标签已足够，并设计对噪声标签更稳健的融合方式。
- **评测应同时报告效率与结构合法性**：BLV、CR 等拓扑感知指标与显存/时长并列，有助于避免“质量提升以巨大算力换取”的误读；但位置表示与旋转表示在骨长指标上的口径差异，提示社区需要更统一的跨表示评测协议。

## 10. 总体评价

论文以“稀疏关节训练、全骨架推理”为主线，将拓扑无关运动生成中的效率与泛化问题统一到一个可操作的表示层设计上，方法简洁、消融较系统、效率收益明确，用户研究也支持其在语义合理性上的优势。其主要价值在于提出并验证了一种反直觉但有效的归纳偏置：减少训练时可见的关节交互，反而改善跨拓扑迁移。与此同时，结论的证据范围仍受单一数据集、基线复现质量、rest pose 依赖与有限统计检验的约束；对细粒度运动、噪声 rest pose、推理成本与自适应预算的讨论不足。总体而言，这是一项问题视角清晰、工程可行性较强、但外部效度仍需更多独立验证的工作，适合作为拓扑无关运动生成中“结构化稀疏表示”方向的参考基线。
