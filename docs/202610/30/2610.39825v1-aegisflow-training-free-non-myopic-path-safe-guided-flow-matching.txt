# Abstract 

Pretrained generative models, such as diffusion and flow matching models, have demonstrated exceptional capabilities in synthesizing high-quality data. How-ever, steering their generative trajectories to satisfy strict constraints—such as identity preservation in image editing or obstacle avoidance in robotics—remains fundamentally challenging. While recent training-free guidance methods enforce path-safety, they rely heavily on min-norm controllers that only account for im-mediate constraint satisfaction. These myopic approaches often yield suboptimal trajectories that hover dangerously close to the boundary, severely restricting the model’s ability to optimize toward its target. In this paper, we propose AegisFlow, a training-free, non-myopic path-safe guidance framework that recasts guided generation as a safety-critical optimal control problem with global scope. By integrating a time-varying barrier function directly into the global cost functional, AegisFlow naturally enforces constraints along the entire generative path. To com-pute the global optimal control, we derive a tractable, mathematically grounded approximation of the Hamilton-Jacobi-Bellman (HJB) equation. Comprehensive experiments demonstrate that AegisFlow outperforms state-of-the-art methods across text-guided image manipulation and robotic planning, establishing a signifi-cantly better trade-off between target alignment and constraint satisfaction. Code is available at https://github.com/LiuKunpeng03/AegisFlow .

# 1 Introduction 

Generative models such as diffusion [25, 53] and flow matching [34] have exhibited remarkable capabilities in synthesizing high-quality data across various domains, including images [45, 16] and planning [8, 14]. Guided generation, e.g., image editing [38, 24], takes advantage of the expressiveness of pretrained generative models and steers the generative trajectory towards a target. Reward-guided methods [52, 36, 56], which leverage a predefined reward function to optimize the trajectory at inference time, have attracted significant attention due to their training-free nature and flexibility in handling various objectives.

Besides objective guidance, constraint satisfaction is increasingly accounted for in guided generation. For example, fake or harmful content should be strictly prohibited from generation [51, 33], and generated trajectories for robotics should obey physical law and avoid obstacles [27, 8]. Previous methods deal with constraints by either soft guidance [60, 9] or projection [10, 54, 61]. The former admits no hard guarantees on constraint satisfaction, while the latter might hinder the generation quality. Recent works [57, 58, 20] extend the desired constraint on the output to the entire generative trajectory, and enforce path-safety by imposing control to the pretrained flow model. These methods are able to achieve better constraint satisfaction while maintaining generation quality. However, they apply a myopic min-norm controller, which only considers the immediate effect of the control input without accounting for the long-term effect on the trajectory. As a result, these methods often find suboptimal solutions that hover dangerously close to safety boundaries, severely limiting the aggressiveness with which a model can optimize toward its target. See Figure 1 for an illustration. To overcome the fundamental limitations of myopic controllers, we propose AegisFlow, a training-free, non-myopic path-safe guidance method for flow matching models. AegisFlow recasts guided generation as a safety-critical optimal control problem with a global scope. Instead of relying on per-step corrections, we integrate a time-varying barrier function directly into the global cost functional. This formulation penalizes the trajectory for approaching the boundary of the safe set, ensuring the entire generated path remains within a safe tube. AegisFlow seeks to find the global optimal control via estimating the solution to the Hamilton-Jacobi-Bellman (HJB) equation associated with the cost functional, which inherently accounts for the long-term effects of control inputs on both target alignment and safety constraints. Since the barrier function drives the cost to infinity near safety boundaries, any finite-cost solution natively guarantees constraint satisfaction, allowing us to bypass the ad-hoc projections or per-step barrier functions required by prior methods. We extensively evaluate AegisFlow across diverse and challenging domains, spanning from high-dimensional text-guided image manipulation (CelebA-HQ) to physical planning (Maze2D and D3IL 2robotic manipulation). In image editing, AegisFlow proactively maintains a larger safety margin for identity preservation, enabling stronger textual alignment (higher CLIP scores) and better identity retention than myopic baselines. In continuous control tasks, AegisFlow achieves higher success rates, smoother trajectories, and fewer safety violations compared to current state-of-the-art safe diffusion methods. In summary, our main contributions are as follows: • Overcoming of Myopic Limitations: We identify the suboptimality of min-norm controllers in guided flow matching and propose AegisFlow, a globally aware, training-free optimal control framework. • Tractable HJB Approximation: We formulate a barrier-inclusive cost functional and derive a tractable, mathematically grounded approximation for the optimal safe control using the Hamilton-Jacobi-Bellman (HJB) equation. • Comprehensive Empirical Validations: We demonstrate superior performance across both high-dimensional image manipulation and safety-critical continuous control tasks, establish-ing a significantly better trade-off between target alignment and constraint satisfaction. 

# 2 Related Works 

Training-free image manipulation. There are various training-free methods for image manipu-lation based on pretrained diffusion models. The mainstream approach starts with image-to-noise inversion and then applies certain guidance to the generative trajectory [36, 50, 7, 26, 5, 56]. Some works directly optimize over the original image [31, 41, 59]. Recently, Kulikov et al. [32] also explore inversion-free methods. In this paper, we will mainly focus on the first approach. However, we think there is no fundamental barrier to applying our method to the other approaches, and we leave it for future work. 

Flow matching under control theory. Prior works have formulated the training [15, 65, 66], sampling [63, 6, 55, 23], and test-time editing [36, 56, 48, 49, 21] of flow matching models as optimal control problems. Some of them use Pontryagin’s Maximum Principle (PMP) [15, 36, 56], while others adopt the Hamilton-Jacobi-Bellman (HJB) approach [65, 49, 21]. They aim to optimize a certain cost, while the behavior of the trajectory is controlled by a regularizer and admits no hard guarantees. Several recent works explore the use of per-step projection [10, 47, 61, 54, 37], control barrier functions (CBFs) with min-norm controller (MNC) [57, 62, 58, 20] to enforce hard constraints along the entire trajectory. However, the myopic nature of per-step projection and MNCs remains to be addressed. Mizuta and Leung [40] try to encode the CBF constraint into the reward function. But they do so by including the increment of the term inside the supremum in (19) (in Appendix A) between two timesteps as part of the reward, which is still essentially myopic and cannot find globally optimal solutions. Mishra and Manchester [39] explore the use of an emerging barrier function to enforce safety constraints in the diffusion process, but their method is mainly a heuristic one. In constrast, our method estimates the optimal control from the HJB equation with a cost functional that includes the barrier function, which attempts to find a globally optimal solution that minimizes the cost functional while ensuring the trajectory stays within a safe set.

Constraint satisfaction is also increasingly considered in guided generation. It requires the generated sample to satisfy certain constraints, i.e., x(tf ) ∈ C for some constraint set C. Traditional approaches utilize soft guidance or projection to enforce constraints, which offer no hard guarantees or suffer from performance degradation. For example, Gao et al. [21] set Ψ to be the distance to the admissible set and utilize HJB to estimate the optimal control. To alleviate performance deterioration caused by post hoc projection, recent works extend the constraints to the entire trajectory [57, 58, 20], i.e., they demand x(t) ∈ C t for all t ∈ [t0, t f ] where Ct is a time-varying safe set with Ctf ⊆ C . They enforce such path-safety by CBFs and MNCs. However, MNCs only consider the immediate effect of the control input and such myopic nature often leads to suboptimal solutions. 5.1 Text-Guided Image Manipulation with Identity Preservation Dataset and Evaluation. We conduct experiments on the celebrity face dataset CelebA-HQ [29] with text guidance {old, smile, sad, angry, curly hair} . Following the same setup as in [36], the alignment between the generated image and text prompt is evaluated by the CLIP model [43]. As in [30], we measure the perceptual similarity between the source and generated image by LPIPS [64] and identity similarity by ID, which is computed using ArcFace [12]. Implementation details are deferred to Appendix C.1. 

Main Results. We benchmark AegisFlow against state-of-the-art methods on CelebA-HQ (Figure 3). The results are summarized in Table 1 and Figure 4. Our method achieves the best CLIP and LPIPS score, indicating that it improves text alignment while preserving subject identity better than prior methods. We also compare against the myopic safety baseline, i.e. applying the plug-and-play MNC to OC-Flow. While MNC attains the highest ID, it underperforms AegisFlow on both CLIP and LPIPS. To better understand AegisFlow, we record the value of the function h(x, t ) at each timestep, as shown in Figure 4. It can be seen that AegisFlow acts the most proactively to maintain a large margin from the boundary of the safe set. Although MNC and AegisFlow both renders safety for the most part of the trajectory, AegisFlow achieves better performance by maintaining a larger safety margin and thus allowing more aggressive optimization towards the target prompt. # 6 Conclusion 

In this paper, we presented AegisFlow, a training-free guidance framework that addresses the limitations of myopic controllers in path-safe guided flow matching. By casting guided generation as a safety-critical optimal control problem, AegisFlow integrates constraints into the cost functional. A tractable HJB approximation is derived to obtain the optimal control. Comprehensive empirical evaluations across diverse domains demonstrate the effectiveness of AegisFlow. Future works may improve HJB approximation, enhance computational efficiency, and extend this control-theoretic framework to broader settings and more complex modalities.

A.1 Control Barrier Functions 

Control Barrier Functions (CBFs) [3, 4] are a powerful tool to enforce hard safety constraints in control theory. Specifically, given a control system 

˙x = f (x) + g(x)u, (17) we want to ensure that the state x(t) remains within a safe set 

C := {x ∈ Rn : h(x) ≥ 0} (18) for all t ∈ [t0, t f ]. If so, we say that the set C is forward invariant . We also allow C to be time-varying, i.e. Ct := {x ∈ Rn : h(x, t ) ≥ 0}, and in this case we say Ct is forward invariant if x(t) ∈ C t for all t ∈ [t0, t f ]. The intuition of CBFs is to ensure that when evaluated along the trajectories of the system, the gradient of h is nonnegative whenever h(x) = 0 , which prevents the system from leaving the safe set. We shall introduce the formal definition of CBFs as follows. 

Definition 1 (Extended Class K∞ Function) . A function α : R → R is an extended class K∞

function if it is strictly increasing and with α(0) = 0 .

Definition 2 (Control Barrier Function) . Let C ⊂ D ⊂ Rn be with the form of (18) and h : D → R

be a continuously differentiable function, then h is a control barrier function (CBF) if there exists an extended class K∞ function α such that for the control system (17) , we have 

sup 

> u∈U

[∇h(x) · (f (x) + g(x)u) + α(h(x))] ≥ 0 (19) 

for all x ∈ D . For a CBF h, define the set of safe controls at x as 

KCBF (x) := {u ∈ U : ∇h(x) · (f (x) + g(x)u) + α(h(x)) ≥ 0}.

Theorem 1 (Ames et al. [3]) . Let C ⊂ D ⊂ Rn be with the form of (18) and h : D → R

be a continuously differentiable function. If h is a CBF and ∇h(x)̸ = 0 , ∀x ∈ ∂C, then any Lipschitz continuous controller u(x) ∈ KCBF (x) renders the set C forward invariant. Moreover, C is asymptotically stable, i.e. if h(x(t)) < 0 for some t, then h(x(t)) → 0 as t → ∞ .

The result above can be easily generalized to time-varying safe sets by introducing an auxiliary state to represent time.

D.1 Computational Efficiency Comparisons 

We compare the computational efficiency of AegisFlow with the baselines. The results are shown in Table 5. For the image manipulation task, AegisFlow takes slightly more time than OC-Flow, and is more efficient than OC-Flow + MNC. For the maze navigation task, AegisFlow is slower than SafeDiffuser and SafeFlowmatcher, which is expected since AegisFlow attempts to estimate the solution to the forced HJB equation, while SafeDiffuser and SafeFlowmatcher only solve a simple quadratic program at each timestep in one go. Indeed, they mainly consider constraint satisfaction in a myopic manner, while AegisFlow seeks to find a globally optimal solution that balances constraint satisfaction and task performance.
