## 摘要
我们提出了 FlowHMR，一个用于从单目视频中恢复物理合理的全局三维人体运动的框架。此前的基于学习的方法通常直接从视频回归人体运动，并使用几何监督训练网络。然而，从单目视频中恢复人体运动在深度上本质上是模糊的，直接回归往往会坍缩到平均解。此外，恢复出的运动不能保证物理合理，因此基于物理的跟踪往往失败。为解决这些挑战，我们将视频动作捕捉建模为一个以视频为条件的运动生成问题，并首先针对该任务预训练一个流匹配模型。给定输入视频，预训练模型会生成多样的候选运动，但并非所有候选都忠实于视频或可被物理跟踪。因此，我们使用带两个奖励的组相对策略优化（GRPO）对模型进行后训练。保真度奖励鼓励与输入视频保持一致。跟踪奖励偏向于基于物理的控制器能够成功跟踪的运动。这些奖励共同改变模型的输出偏好，使后训练模型在保持对输入视频忠实的同时，生成物理上更合理的运动。我们进一步引入 Wild-4K，一个包含约 4K 个互联网视频的大型多样数据集，用于评估真实场景下的人体运动恢复。在 Wild-4K 上的定性和定量实验表明，我们的方法在整体运动保真度上优于最先进方法，并实现了 82.47% 的物理跟踪成功率，而最强基线 GVHMR 为 62.82%。

## Abstract
We present FlowHMR, a framework for recovering physically plausible global 3D human motion from monocular video. Previous learning-based methods typically regress human motion directly from video and train the network with geometric supervision. However, recovering human motion from monocular video is inherently ambiguous in depth, and direct regression tends to collapse toward an averaged solution. Moreover, the recovered motions are not guaranteed to be physically plausible, so physics-based tracking of them often fails. To address these challenges, we formulate video motion capture as a video-conditioned motion generation problem and first pretrain a flow matching model for this task. Given an input video, the pretrained model generates diverse motion candidates, but not all of them are faithful to the video or physically trackable. We therefore post-train the model using Group Relative Policy Optimization (GRPO) with two rewards. A fidelity reward encourages consistency with the input video. A tracking reward favors motions that a physics-based controller can track successfully. Together, these rewards shift the model's output preference, so the post-trained model stays faithful to the input video while producing more physically plausible motion. We further introduce Wild-4K, a large and diverse dataset of about 4K internet videos, for evaluating human motion recovery in the wild. Qualitative and quantitative experiments on Wild-4K show that our method outperforms state-of-the-art methods in overall motion fidelity and achieves a physical tracking success rate of 82.47%, compared with 62.82% for the strongest baseline, GVHMR.

## 2. 方法论

### 2.1 核心思想

- 两阶段框架：
  - **Stage 1 生成式预训练**：用流匹配（Flow Matching）学习"视频+相机条件 → 全局人体运动"的条件分布，天然表达深度歧义。
  - **Stage 2 物理后训练**：用 GRPO（具体采用 MixGRPO）以**保真奖励 + 物理跟踪奖励**微调生成器，使采样偏好转向既忠实又物理可行的运动。
- 关键设计：**仿真仅在训练阶段使用**；推理时生成器直接输出运动，不做基于仿真的选择或修正。

### 2.2 运动表示与条件

- **坐标系**：重力对齐的世界坐标系，朝向由首帧相机朝向定义，运动水平平移至原点起始。
- **每帧特征**（N 帧编码为 x ∈ R^{N×D}）：
  - root（时间平滑后的骨盆轨迹）的水平速度与绝对高度；
  - SMPL-H 关节位置（分解为相对 root 的水平偏移 + 绝对高度）；
  - 关节旋转的连续 6D 表示（骨盆在世界系，其余相对父关节）；
  - 体型参数与脚部接触标签。
  - 该表示**联合编码身体姿态、手部关节与全局轨迹**，并在训练集统计量上标准化。
- **条件 c**：逐帧的人体区域视觉特征（冻结的 SAM 3D Body 姿态感知图像编码器）+ 世界系相机旋转，分别投影到同一维度后相加。

### 2.3 网络架构

- 采用 **0.46B 参数的多模态扩散 Transformer（MM-DiT）**（HY-Motion 架构），将文本条件分支替换为视觉条件分支，token 与运动序列逐帧对齐。
- 结构：先**双流块**（运动/条件各自投影权重），再**单流块**（拼接后共享权重）；时间 t 经 adaLN 调制每个块；末层线性层直接预测干净运动 x̂₁ = fθ(x_t, c, t)。
- **局部时序注意力**：运动 token 关注窗口内运动与条件 token；条件 token 仅关注窗口内条件 token，从而保持条件特征独立于含噪运动。

### 2.4 流匹配预训练

- 线性插值构造含噪运动：x_t = (1−t)x₀ + t x₁，x₀ ~ N(0, I)，t 从 logit-normal 分布采样。
- 网络直接预测干净运动，再转换为速度：
  - v̂_θ = (fθ(x_t, c, t) − x_t) / d(t)，v* = (x₁ − x_t) / d(t)，其中 d(t) = max(1−t, ε) 用于数值稳定。
- **流匹配损失**：对 root 轨迹、关节旋转、体型、脚接触等特征组分别计算 Smooth-L1 并加权求和。
- **额外几何监督**：将 x̂₁ 与 x₁ 分别经 SMPL-H 前向运动学解码为全局关节旋转与位置，施加 **不做骨盆对齐或 Procrustes 对齐**的 Smooth-L1 损失（L_rot, L_pos），从而同时惩罚全局轨迹与关节衔接误差。
- 总预训练目标：L_pre = L_FM + λ_rot L_rot + λ_pos L_pos。
- 训练细节：500K 步，全局 batch 1024，AdamW，学习率 1e-4 余弦衰减至 1e-5；训练时**随机丢弃视觉条件但始终保留相机条件**，避免过拟合视频条件。
- 推理：20 步均匀 Euler 积分，**不使用 CFG**；root 速度积分得水平轨迹，结合骨盆水平偏移得水平位置，垂直位置由骨盆绝对高度给出；体型参数时间平均为单一形状。

### 2.5 基于物理的后训练（GRPO）

- **保真奖励**（逐帧关节位置的世界系误差，无对齐）：
  - r_fid = exp[ −(1/(τNJ)) Σ_n Σ_j ‖p_{n,j} − p^{gt}_{n,j}‖² ]，τ = 0.15 m。
- **物理跟踪奖励**：用冻结的 PHC+ 控制器在 Isaac Gym 中以采样运动本身为参考进行跟踪：
  - r_track = exp[ −(1/(τH)) Σ_n min( (1/M) Σ_m ‖b^{sim}_{n,m} − b^{ref}_{n,m}‖², d_max ) ]，d_max = 0.5 m。
  - 关闭控制器的失败恢复与动作循环，使失败反映在奖励中；转换或仿真失败的动作为零奖励。
  - 成功判据：任一步平均身体位置误差不超过 0.5 m。
- **组采样与优势估计**：
  - 每个视频采样 G = 8 个运动，仅在去噪窗口内使用 SDE 随机采样，其余用 ODE 确定性步；组内共享初始噪声。
  - **仅保留同时含成功与失败结果的组**（保证对比信号）。
  - 两个奖励各自标准化后等权相加并裁剪：A⁽ⁱ⁾ = clip( (r_fid−μ_fid)/σ_fid + (r_track−μ_track)/σ_track, −A_max, A_max )。
  - 仅更新生成器，视觉编码器与控制器保持冻结；策略梯度只作用于随机窗口内的转移。
