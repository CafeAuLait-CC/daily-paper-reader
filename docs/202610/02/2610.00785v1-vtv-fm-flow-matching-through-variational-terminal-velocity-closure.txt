Abstract
Flow matching (FM) learns generative transport by fitting continuous-time motion
from a simple source distribution to the data distribution. Most existing methods
use first-order bridges: once a source and a target sample are paired, the path is a
straight motion with constant velocity. FM with optimal transport (OT) improves
the pairing, but the bridge itself remains linear, limiting its ability to model curved
motion, acceleration, and changing directions. A natural remedy is to use second-
order phase-space dynamics; however, learning the bridge requires target-side
terminal-velocity information that static datasets do not provide. We propose
Variational Terminal-Velocity Flow Matching (VTV-FM), a second-order FM
framework that derives the missing velocity by minimizing acceleration energy,
yielding a closed-form closure for static data. The same minimum-acceleration
variational construction also defines the OT pairing cost and the acceleration
targets used for training. Experiments on low-dimensional datasets, PDE-governed
physical fields, and CIFAR-10 show that VTV-FM improves transport geometry
and generation quality over first-order and high-order FM baselines. Our code is
available at https://github.com/HaoyangJiang-WM/VTV-FM.

Introduction
Flow Matching (FM) has emerged as a flexible generative model by learning continuous-time vector
fields along prescribed probability paths [1, 2]. A common choice is the first-order linear bridge: given
a paired source sample and target sample, the model learns a straight path from x0 to x1, corresponding
to constant-velocity transport [1]. OT-based Flow Matching further improves this framework by
replacing independent source–target pairing with an optimal coupling, thereby reducing transport
cost and vector-field conflicts [3, 4]. However, even after the pairing is improved, the conditional
bridge itself remains a first-order linear interpolant. For data distributions with curvature, branching
structures, or separated modes, straight paths may pass through low-density regions and require
the model to learn vector fields in poorly supported intermediate regions. Meanwhile, trajectory
intersections can induce conflicting velocity supervision, forcing the learned vector field to average
incompatible directions [5]. This motivates a second-order phase-space formulation, where transport
can exhibit nonuniform speed and curved position paths with time-varying tangent directions, rather
than being restricted to constant-velocity linear interpolation.
Constructing a second-order bridge is fundamentally more challenging than constructing a first-order
path. A first-order bridge only requires endpoint positions, whereas a second-order phase-space
bridge also requires endpoint velocities, since these boundary velocities determine the intermediate
trajectory and the induced acceleration supervision. The initial velocity v0 can be sampled from a
source phase-space prior, but static datasets typically provide only the terminal position x1, leaving

VTV-FM instead formulates the static-data case by treating v1 as a latent boundary variable and
eliminating it variationally, tying the terminal-velocity completion to the bridge geometry and
pairing cost. This issue is critical because v1 controls the full phase-space bridge. Externally
specified terminal velocities can therefore introduce unnecessary curvature or acceleration, biasing
the regression targets. Figure 1 illustrates this sensitivity: under the same observable boundary
information (x0, v0, x1), different choices of v1 induce different position trajectories, velocity profiles,
and acceleration-energy costs. Since deterministic FM sampling relies on numerical integration of
the learned dynamics at inference time, such trajectory distortions can make discretization errors
accumulate more easily and increase sensitivity to solver choice and time discretization [5, 12].
To address these structural limitations, we propose Variational Terminal-Velocity Flow Matching
(VTV-FM). Its core is a minimum-acceleration variational principle: the same variational problem
simultaneously induces the second-order bridge, the terminal-velocity closure, and the OT pairing
cost. For a complete boundary state (x0, v0, x1, v1), the minimum-acceleration problem yields a cubic
Hermite bridge, together with the corresponding intermediate velocity and acceleration supervision.
The optimal action value of this trajectory further defines a full-boundary second-order transport cost.
In static-data regimes where the terminal velocity is missing, VTV-FM does not introduce an auxiliary
estimator or artificial constraint. Instead, it treats v1 as a latent boundary variable and directly
minimizes the same full-boundary cost with respect to v1. This optimization has a closed-form
solution, yielding the variational terminal-velocity closure v⋆
1. Substituting v⋆
1 back into the original
cost gives a projected OT cost that depends only on the observable boundary variables (x0, v0, x1). In
this way, the missing v1 in static data is determined intrinsically by the same minimum-acceleration
principle, rather than being specified by an external mechanism. When the terminal velocity is
observed or derivable, as in PDE data or temporal sequences, VTV-FM directly uses the full-boundary
bridge without applying the closure. Thus, the terminal-velocity closure, the OT pairing cost, and
the acceleration supervision induced by the second-order bridge are all determined by the same
minimum-acceleration variational principle, rather than being specified separately by external rules.
Our contributions include: (1) a phase-space formulation of FM that identifies missing terminal
velocity as the key obstacle for second-order bridges on static data; (2) together with the proposed
VTV-FM framework, a closed-form terminal-velocity closure derived from a minimum-acceleration
principle, which also defines the bridge and projected OT pairing cost; and (3) empirical validation
on low-dimensional transport, PDE-governed fields, and CIFAR-10, where VTV-FM improves over
first-order, OT-based, and high-order FM baselines.

3
Proposed Method: VTV-FM
We present VTV-FM, a second-order Flow Matching framework in phase space. Its central idea is to
derive the transport bridge, terminal-velocity closure, and OT pairing cost from a single minimum-
acceleration variational principle, rather than specifying them as separate design choices. This
unified construction allows VTV-FM to use the full-boundary bridge when terminal velocities are
available, and to close the missing terminal velocity variationally when they are not. We first derive
the closed-form full-boundary bridge and cost for (x0, v0, x1, v1) (Section 3.1). We then project this
cost onto (x0, v0, x1), obtaining a closed-form terminal-velocity closure and projected OT cost for
the latent-v1 regime (Section 3.2). Finally, we use these quantities for minibatch pairing, trajectory
supervision, acceleration matching, and sampling (Sections 3.3–3.4).

Experiments
We quantitatively evaluate VTV-FM on low-dimensional datasets, PDE-governed physical fields
[19], and CIFAR-10 [20], and additionally provide qualitative proof-of-concept temporal examples
on BAIR robot pushing [21] and KTH [22]. The low-dimensional datasets and CIFAR-10 evaluate
the missing-v1 regime, where terminal velocity is unobserved and must be inferred by the proposed
closure. The low-dimensional setting further enables direct visualization of sample quality and
transport trajectories. In contrast, the PDE and temporal examples evaluate the observed/derivable-v1
regime, where terminal derivative information is available from governing dynamics, simulators, or
adjacent frames. Additional qualitative temporal visualizations are provided in Appendix E.4.
4.1

can be directly visualized. This setting compares sample quality and transport geometry on complex

Results and findings. Table 1 reports the main results on seven low-dimensional datasets. VTV-
FM achieves the best average sample-based W2, reaching 0.1004 and outperforming all baselines.
Compared with CFM, OT-CFM, OAT-FM, HOFM, and CurveFlow, VTV-FM reduces the average
W2 by approximately 9.1%, 6.8%, 4.1%, 3.4%, and 2.4%, respectively. The radar relative score

At the dataset level, VTV-FM achieves the best result on 4/7 datasets: Checkerboard, Two Moons,
Parallel Lines, and Star. Compared with the strongest competing baseline on these datasets, VTV-
FM reduces W2 by approximately 3.0%, 6.2%, 0.6%, and 1.7%, respectively. Checkerboard, Two
Moons, and Star involve multimodality, separated modes, or sharp local direction changes, suggesting
that second-order phase-space dynamics are particularly beneficial for complex low-dimensional
structures. On another three datasets, VTV-FM is not the best method but remains competitive.
On Tree, it is only about 0.8% worse than the best HOFM result. This suggests that high-order
or OT-based path modeling can still be effective for certain geometries. However, in terms of
average performance, VTV-FM shows the most robust behavior across low-dimensional structures.

4.2

CIFAR-10, PDE data provide explicit temporal evolution, so the terminal derivative can be obtained

derived in Section 3. This experiment tests whether the proposed construction remains effective in
high-dimensional image generation.

Related Work
Flow Matching and OT-based coupling. Flow Matching learns generative transport by regressing
time-dependent vector fields along prescribed probability paths, with stochastic interpolants and
rectified flows providing related formulations [1, 2, 5]. Minibatch optimal transport improves
source–target coupling and simplifies transport paths and regression targets [3, 4]. In OT-CFM with
linear conditional bridges, optimal transport improves sample pairing, but each conditional trajectory
remains a straight line between the paired endpoints.
Higher-order dynamics and path design. Beyond improving sample coupling, existing methods
enrich generative dynamics through higher-order supervision and alternative dynamical construc-
9


tions. HOMO introduces acceleration and higher-order derivative supervision into one-step shortcut
models [6], and NRFlow jointly learns velocity and acceleration fields to improve noise robustness
and trajectory stability [7]. HOFM develops a unified framework incorporating arbitrary-order
trajectory derivatives, with conditional regression formulations, derivative consistency constraints,
and statistical convergence rates [8]. Related theory also studies estimation errors in higher-order
trajectory refinement [24]. In terms of dynamical structure and path geometry, HRF models velocity,
acceleration, and higher-order variables through hierarchically coupled rectified flows [25], and
CurveFlow explores curvature-guided path objectives [9]. For few-step generation, Terminal Velocity
Matching matches the derivative of a two-time displacement model with respect to its terminal
time [26]; this derivative target is distinct from the data-side endpoint velocity considered here.
Minimum-acceleration transport and boundary conditions. A closely related variational approach
uses squared-acceleration action to construct trajectories and transport costs. Classical spline theory
shows that minimizing this action with fixed endpoint positions and velocities yields a cubic Hermite
curve [14]. At the distribution level, second-order optimal transport studies acceleration-minimizing
paths and cubic Wasserstein splines [27]. OAT-FM applies optimal acceleration transport to flow
matching [11], and OTIKIN studies second-order discrepancies between distributions induced by
acceleration costs [28]. Endpoint information also plays an important role: boundary-constrained
flow matching imposes prescribed endpoint behavior on learned first-order velocity fields [10].
Our setting concerns second-order phase-space bridges whose terminal velocity is not provided by
static data. VTV-FM treats this unspecified velocity as an optimization variable in the minimum-
acceleration problem and eliminates it analytically, jointly determining the terminal-velocity closure,
bridge, corresponding OT pairing cost, and acceleration supervision.
6
Conclusion
We introduced VTV-FM, a second-order FM framework for generative transport in phase space. The
central challenge is that second-order bridges require a target-side terminal velocity, which is often
unavailable for static data. VTV-FM addresses this issue with a minimum-acceleration variational
principle: when the terminal velocity is missing, the principle yields an analytic terminal-velocity
closure and a projected OT cost; when the terminal velocity is observed or derivable, the same
full-boundary bridge directly incorporates it. This construction unifies terminal-velocity closure,
source–target pairing, and acceleration supervision under a single variational framework. Experiments
on low-dimensional datasets, PDE-governed fields, and CIFAR-10 show that VTV-FM improves
generation quality over first-order, OT-based, and higher-order FM baselines, while producing more
reliable second-order transport trajectories. Future work includes developing richer kinetic priors,
extending the framework to conditional and controlled generation, and scaling second-order transport
constructions to larger generative modeling tasks.

A
Limitations.
VTV-FM relies on a minimum-acceleration principle to close the missing terminal velocity in static-
data regimes. Although this gives an analytic and internally consistent bridge, richer kinetic structures
or multimodal terminal velocities may require more flexible closures. Our experiments include
low-dimensional datasets, PDE-governed fields, CIFAR-10, an ImageNet-256 scaling study, and
qualitative video examples. Broader evaluation on higher-resolution image generation, quantitative
video generation, and conditional generation remains future work.
B
Broader impacts.
This work is primarily methodological and may benefit scientific generation, physical simulation,
and data-driven modeling by improving transport geometry and derivative-aware generation. As
with other generative modeling methods, improved sample quality may also be misused for synthetic
image or video generation. The paper does not propose a deployed system or use private personal
data, and our experiments are limited to standard benchmarks and simulated physical fields.

Implementation Details
This appendix summarizes the implementation and evaluation settings for the low-dimensional,
PDE, and CIFAR-10 experiments. We report both method-specific and solver-controlled inference
protocols, with solver choices and sampling budgets specified for each experiment.
D.1
Low-Dimensional Experiments
For the low-dimensional datasets, all methods are evaluated with the same sampling budget of 100
steps and EMA weights. For each dataset, we use n = 2000 target samples and n = 2000 generated
samples to compute the sample-based W2 metric. CFM, OT-CFM, OAT-FM, and CurveFlow are
evaluated with Euler sampling, following their standard first-order sampling protocol. HOFM is
evaluated with the Taylor2 solver, following its original high-order setting. For VTV-FM, we evaluate
Heun, Taylor2, and Velocity Verlet, and report the best validation result in the main table. The
solver-specific results are reported separately in the ablation table.

D.3
PDE-Governed Field Experiments
For PDE-governed field generation, all methods are evaluated with 100 sampling steps. Unlike static
image data, PDE data provide terminal derivative information through the PDE right-hand side or
simulator outputs. Therefore, VTV-FM directly uses the observed or derivable terminal velocity and
does not apply terminal-velocity closure in this setting. This corresponds to the observed/derivable-v1
regime described in the main text.
The baseline solver choices follow the same principle as in the low-dimensional experiments. First-
order FM variants use their standard first-order samplers, HOFM uses the Taylor2 solver, and
VTV-FM is evaluated with phase-space solvers such as Heun, Taylor2, and Velocity Verlet. Other
evaluation settings, including sample size and metric computation, follow the low-dimensional
experiment protocol unless otherwise specified.
D.4
CIFAR-10 Experiments
CIFAR-10 represents the high-dimensional missing-v1 regime, where only terminal images are
observed and target-side terminal derivatives are unavailable. Therefore, VTV-FM uses the variational
terminal-velocity closure derived in Section 3 to instantiate the second-order bridge.
For the controlled cross-method comparison in Table 3, we evaluate FM, I-CFM, OT-CFM, OAT-
FM, CurveFlow, and VTV-FM under the applicable shared inference protocols. VTV-FM uses

shared adaptive-solver comparison with measured NFE.
Table 4 separately evaluates the effect of the auxiliary objectives within VTV-FM under Velocity
