## 摘要
文本驱动的人体运动编辑旨在实现所请求的更改，同时保留兼容的源内容。现有扩散编辑器主要依赖学习到的条件来保持未编辑部分，但其输出会随着去噪过程推进而丢失时间细节。我们提出源保持去噪框架（SuperMotion），它在每个反向步骤中显式复用源以实现源保持。我们首先将源运动与输出时间线对齐，并预测一个保持门控，以控制跨帧和特征维度的复用。随后，干净空间源锚点利用学习到的保持门控，将预测的干净运动与对齐后的源进行融合，并将校正后的估计直接传递给采样后验。由于对齐后的源是已实现的运动而非回归输出，该锚点注入了样本级时间细节，而经过重建训练的去噪器往往会将其平滑掉。为学习有效的源复用，我们用编辑目标监督锚定后的估计，并通过时间高频损失匹配其二阶时间差分。这些目标不需要显式的编辑掩码。大量实验表明，SuperMotion 提高了编辑准确率，在 MotionFix 上达到 33.20% 的 full-pool R@1，同时在实现所请求更改时减轻了时间细节衰减并保持了运动动态。消融实验证实，学习到的保持门控带来了该增益，并且其复用源以恰当保留未编辑内容。

## Abstract
Text-driven human motion editing aims to realize a requested change while preserving compatible source content. Existing diffusion editors rely largely on learned conditioning for preservation of the unedited part, yet their outputs can lose temporal detail as denoising proceeds. We propose the \textbf{Source-Preserving Denoising framework (SuperMotion)}, which explicitly reuses the source at each reverse step for source preservation. We first align the source motion to the output timeline and predict a preservation gate that controls reuse across frames and feature dimensions. A clean-space source anchor then utilizes the learned preservation gate to blend the predicted clean motion with the aligned source and passes the corrected estimate directly to the sampling posterior. Because the aligned source is a realized motion rather than a regression output, the anchor injects sample-level temporal detail that a reconstruction-trained denoiser tends to smooth away. To learn effective source reuse, we supervise the anchored estimate against the editing target and match its second temporal differences through a temporal high-frequency loss. These objectives require no explicit edit masks. Extensive experiments show that SuperMotion improves editing accuracy, reaching 33.20\% full-pool R@1 on MotionFix, while reducing temporal-detail attenuation and preserving motion dynamics as it realizes the requested changes. Ablations confirm that the learned preservation gate is responsible for the gain and that it reuses the source to retain the unedited content properly.

# SuperMotion 论文总结

## 1. 核心问题与整体含义

- **研究背景**：文本驱动的人体运动编辑要求在实现文本指令所要求的修改的同时，保留源运动中与指令不冲突的兼容内容。这类编辑本质上接近"部分恒等映射"——指令通常只改变部分帧与部分关节坐标，其余内容应尽量保持。
- **核心问题**：现有扩散编辑器（如 TMED、SimMotionEdit、OmniME）主要依赖学习式条件（source conditioning）来间接保留未编辑内容，但模型仍需从高斯噪声重新合成整段序列，导致未编辑部分被反复重估并拉向"后验均值"。
- **关键发现（时序细节衰减）**：论文提出 *detail ratio*（运行中干净估计的二阶时间差分幅度 / 目标真值的同统计量）来度量细节保持。理想反向过程应使该比值趋于并稳定在 1×，但实测：
  - TMED 降至 0.33×，OmniME 0.66×，SimMotionEdit 0.71×；
  - 衰减集中在低噪声的末端步，此时估计已匹配目标细节水平，继续去噪反而压制局部时序变化。
- **理论解释**：用重建目标训练的去噪器逼近后验均值 E[x₀|xₜ]，而失真最优估计必然比单个样本更平滑（Blau & Michaeli, 2018）。因此"应当保留"的源内容被重新合成后会被平滑掉。
- **整体含义**：论文主张将"源复用"从隐式条件变为反向过程中的**显式算子**，在每个采样步把干净运动估计向时间对齐的源运动牵引，从而直接注入样本级高频时序细节。

## 2. 方法论

### 核心思想
- 提出 **Source-Preserving Denoising（SuperMotion）** 框架：在每个反向步中，通过一个**学习的源保持门控**把当前干净运动估计与**时间对齐的源运动**做逐帧、逐特征维度的凸混合，校正后的估计直接送入采样后验，而非仅作为网络输入。

### 关键技术细节

- **源对齐（Align）**：源与目标时长可能不同，对源做线性重采样至输出时间线，得到同长度的参考 $\bar{s} = \text{Align}(s, T) \in \mathbb{R}^{T \times D}$；残余错位由门控吸收。

- **保持门控（Preservation Gate）**：由 preservation head（3 层 MLP，512→1024→1024→207，SiLU，末层零初始化 + 偏置 −6）在同一目标 token 特征 $h$ 上预测：
  - $g = \sigma(f_\phi(h)) \in (0,1)^{T \times D}$，每帧每维度一个复用权重，且通过 $h$ 隐式依赖扩散步 $t$。

- **干净空间源锚点（Clean-Space Source Anchor）**：
  - $\tilde{x}_0 = \hat{x}_0 + g \odot (\bar{s} - \hat{x}_0) = (1-g)\odot \hat{x}_0 + g \odot \bar{s}$
  - 因 $g \in (0,1)$，每个坐标落在去噪预测与对齐源之间；在指令不改变的坐标上 $\bar{s} \approx x_0$，直接注入目标应有的细节，无需网络重新生成。

- **放置位置**：锚点应用在分类器无关引导（CFG）和干净运动重建**之后**，替换高斯后验中的干净目标：$p_\theta(x_{t-1}|x_t,s,c)=q(x_{t-1}|x_t,\tilde{x}_0)$。作者强调在干净空间而非速度空间做锚定，因为二者相差 $(1-\bar{\alpha}_t)^{-1/2}$ 因子，在 $t\to0$ 时无界；干净空间可保持 $g$ 为有界凸权重。

- **最优门控分析**：固定 $\hat{x}_0$ 对 $g$ 最小化锚点损失，解耦为逐坐标凸二次问题：
  - $g^*_{i,d} = \text{clip}\left(\frac{x_{0,i,d}-\hat{x}_{0,i,d}}{\bar{s}_{i,d}-\hat{x}_{0,i,d}}, 0, 1\right)$
  - 即"从预测到源的路上，目标所在的比例"。理论推论：编辑越大最优门控越小；$t\to0$ 时最优门控趋于消失（释放源）。

- **网络架构**：基于 SimMotionEdit。4 层 Transformer 条件编码器分别编码源运动线性投影与 CLIP ViT-L/14 文本嵌入；8 个 DiT 块（隐藏宽度 512）+ 对称块间 U-ViT 长跳连接；去掉源 token 后目标特征 $h \in \mathbb{R}^{T\times512}$ 分入两个头：
  - **pose head** 输出速度 $\hat{v}$（v-parameterization），$\hat{x}_0 = \sqrt{\bar{\alpha}_t}x_t - \sqrt{1-\bar{\alpha}_t}\hat{v}$；
  - **preservation head** 输出门控 $g$。
  - 采用速度预测而非直接预测 $x_0$，因速度损失的等价权重为 $(\text{SNR}(t)+1)\|x_0-\hat{x}_0\|_2^2$，在低噪声处对干净运动误差加权更大，正好对应细节损失集中区。

- **训练目标**：
  - 源锚点损失：$\mathcal{L}_{anc} = \frac{1}{TD}\sum_i \|\tilde{x}_{0,i}-x_{0,i}\|_2^2$（同时训练去噪器与门控，其逐坐标最优解即上式 $g^*$）；
  - 时序高频损失：$\mathcal{L}_{hf} = \frac{1}{(T-2)D}\sum_i \|\Delta^2\tilde{x}_{0,i}-\Delta^2 x_{0,i}\|_2^2$，匹配二阶时间差分，惩罚过度与不足的变化，梯度经锚点回传至门控；
  - 总目标：$\mathcal{L} = \mathcal{L}_v + 3\mathcal{L}_{anc} + 0.5\mathcal{L}_{hf} + 0.05\mathcal{L}_{cls}$（保留速度损失与 SimMotionEdit 的相似度损失）。
  - 以上目标**不需要显式编辑掩码**。

- **推理流程（Algorithm 1）**：对齐源 → 从噪声采样 $x_T$ → 每步评估无条件/仅源/源+文本三分支 → 由 Eq.3 组合引导速度 → 转为 $\hat{x}_0$ → 从全条件分支读取门控 $g$ → 混合得 $\tilde{x}_0$ → 采样 DDPM 后验（不把校正转回速度）。门控本身不做引导，以免破坏凸组合解释。

  - **公平性注意点**：MotionFix 的 full-pool 池仅 506 个 ID，batch 评测仅 480 个计分查询，作者在附录 A 主动披露了这些统计口径，并说明 batch 百分比并非全体 506 例上的统计；STANCE 的部分基线为作者复现，可能与原报告存在差异。

## 6. 主要结论与发现

- **性能提升**：
  - MotionFix：**79.17% batch R@1、33.20% full-pool R@1**，8 项指标中 7 项第一（OmniME 在 FR@3 上略高）；相比最强先前编辑器分别 +1.88 / +1.18 点。
  - STANCE：**46.88% batch R@1**，较最强基线 +3.13 点；full-pool AvgR 从 22.77 降至 19.21。
- **超越 copy-source 基线**：copy source 基线 BR@1 已达 74.79%，多数先前编辑器低于它，说明"从噪声重生成"破坏的源内容多于编辑本身带来的变化；只有 OmniME 与本文超过该基线，且本文在两个 benchmark 的**每一项检索指标**上都超过它。
- **细节恢复**：detail ratio 从先前方法的 0.66–0.71 恢复到 **1.035×**，验证锚点确实从源运动取回高频细节。

## 7. 局限性

论文自身及分析中可识别的局限包括：

- **时间对齐假设较强**：源对齐仅做线性重采样，隐含"源与目标在时间轴上近似线性对应"的假设。对于需要时间重排、速度突变或非线性时间对应的编辑（如"把跳跃提前"），对齐源 $\bar{s}$ 在局部可能严重错位，此时门控只能通过逐坐标抑制来规避，可能退化为局部"不复用"，丢失本可保留的内容。
- **门控缺乏跨关节结构约束**：门控按帧、按维度独立预测，理论上可以产生逐坐标不同、但整体运动学上不自然（如关节间协调性被破坏）的混合结果。论文未报告骨骼长度/关节连接等物理一致性约束或相应诊断。
- **推理开销**：每个反向步都需重新读取门控并做源混合，且需要无条件/仅源/源+文本三分支前向，相比基线并无推理加速；论文未给出耗时/显存对比。
- **评测指标偏检索**：主结论建立在 TMR 嵌入检索（R@k、AvgR）与 detail ratio 之上，缺少人类主观评分、FID/多样性或物理合理性（如足部滑步、地面穿透）指标，因此"编辑自然度"的证据间接。
- **基线复现差异**：STANCE 上 TMED / SimMotionEdit / MotionReFit 由作者运行官方代码并做表示转换，可能与原报告数字存在系统性偏差，跨表比较需谨慎。
- **数据与规模**：两个基准规模均有限（MotionFix 测试 1,013、STANCE 4,411），且模型为 8 层 DiT、宽度 512 的较小配置，未验证该框架在更大数据/更大模型下的扩展行为。
- **训练细节披露不足**：训练总时长、迭代数、混合精度与多卡情况均未报告，复现成本与可比性受限。

## 8. 总体评价与意义

- **方法层面**：论文把"保留源内容"从隐式的 source conditioning 重新表述为反向过程中的**显式凸混合算子**，并给出最优门控的闭式解（从预测到源的路径上目标所占比例），使"何时复用、复用多少"具有可解释的几何含义。这一视角不仅解释了扩散编辑器普遍存在的时序细节衰减，也提供了一种轻量、可插拔的修正方式。
- **实证层面**：detail ratio 从 0.66–0.71 恢复到 1.035×，加上在 MotionFix 与 STANCE 上对包括 OmniME 在内所有先前方法的全面超越（含对 copy-source 基线的反超），构成较强的经验证据链。消融对"增益来自机制而非额外优化"的排除尤为关键。
- **诊断价值**：copy-versus-edit 表揭示了一个此前被检索指标掩盖的事实——多数编辑器破坏的源内容多于其编辑带来的变化，这一观察本身对社区具有独立价值，提示后续工作应把"源保真"作为一等评测维度。
- **可迁移性**：由于锚定发生在干净空间、门控由目标 token 特征预测，该框架原则上可迁移至其他条件生成/编辑任务（如图像、视频编辑），但需验证对齐与门控粒度在非运动模态下的适配性。
- **整体判断**：这是一篇问题定义清晰、理论动机与工程实现自洽、实验设计较为完备的工作。其主要短板在于时间对齐的强假设、门控的结构一致性约束缺失以及评测维度偏检索，但这些并不动摇核心贡献的成立；相反，它们为后续研究指明了明确的改进方向。
