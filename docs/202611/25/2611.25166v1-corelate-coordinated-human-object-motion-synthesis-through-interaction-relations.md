## 摘要
人-物运动合成要求物体朝指定目标移动时人体进行协调参与。然而，到达物体目标并不能保证接触得以建立和维持，而为改善接触所做的调整又可能干扰任务完成。我们提出 CoRelate，一种扩散框架，通过显式交互关系和任务反馈来协调刚性与铰接物体的全身人-物运动。我们通过手-部件关系表示预期参与，该关系指定参与的手、其相对于部件的参考位置以及参与区间。这些关系既作为生成条件，也作为衡量交互实现程度的参考。在每个去噪步骤中，与生成器联合训练的时间细化器结合关系偏差、任务残差和当前预测的运动特征，以联合更新整个序列中的人体与物体运动。生成之后，时间运动校正通过优化局部运动片段来处理剩余的接触失败，同时保持物体轨迹和受保护的人体运动。实验表明，与所评估的基线相比，物体目标满足度、接触 F1 和完整交互成功率均有所提高。消融研究支持关系条件的益处以及任务反馈与关系反馈的互补作用。

## Abstract
Human-object motion synthesis requires coordinated human participation as objects move toward specified goals. However, reaching object targets does not ensure that contact is established and maintained, while adjustments that improve contact may interfere with task completion. We introduce CoRelate, a diffusion framework that coordinates full-body human-object motion through explicit interaction relations and task feedback for rigid and articulated objects. We represent intended participation through hand-part relations that specify the participating hand, its part-relative reference position, and participation interval. These relations serve both as generation conditions and as references for measuring interaction realization. At each denoising step, a temporal refiner trained jointly with the generator combines relation deviations, task residuals, and motion features from the current prediction to jointly update human and object motion across the sequence. After generation, temporal motion correction addresses remaining contact failures by optimizing local motion segments while preserving object trajectories and protected human motion. Experiments demonstrate improved object-goal satisfaction, contact F1, and complete interaction success over the evaluated baselines. Ablation studies support the benefits of relation conditioning and the complementary roles of task and relation feedback.

## 1. 核心问题与研究动机

- **任务背景**：全身人-物交互（HOI）运动生成，要求人在物体朝指定目标（稀疏 waypoint / 关节状态）移动的过程中"协调参与"，同时满足任务目标与人体参与方式两方面的要求。
- **核心痛点**：物体到达目标 **并不等于** 手-物接触被建立与维持。生成结果中常见两类失败：
  - 物体在接触建立之前就开始移动（提前脱手）；
  - 接触建立后又丢失，物体在"手已离开"的状态下继续移动。
- **关键矛盾**：单纯降低"关系误差/接触误差"并不能唯一确定修正方向——差距可通过改人手、改物体中间轨迹、或两者同时改来消除；而把物体拉向手可能破坏已满足的 waypoint，局部改善接触又可能破坏其他时段的参与与运动连续性。
- **研究问题**：如何**表示并使用交互关系**，使生成的人-物运动既能建立并维持接触，又能满足物体目标并保持运动质量。
- **整体含义**：论文主张把"人如何参与"显式建模为可度量、可作为条件的**手-部件关系**，并与**任务残差**一起在扩散去噪过程中联合驱动人与物体的更新，从而把"任务完成"与"参与实现"两件事在同一生成过程中对齐。

## 2. 方法论

### 2.1 核心思想
用一个扩散框架，把交互关系同时当作 **(a) 生成条件** 与 **(b) 衡量交互是否实现的参照**；在每一步去噪中，用"关系偏差 + 任务残差 + 运动特征"驱动一个联合细化器同时更新人体与物体；生成后再做**保物体轨迹**的局部时序修正。

### 2.2 问题设定与表示
- 条件 `c = (ℓ, X_init, g, M)`：语言指令、初始人-物状态、稀疏物体目标、物体模型；输出 `X = (H, O)`。
- 人体状态：24×3 关节位置 + 22×6 连续 6D 旋转，展平为 204 维；物体：刚性为 `(p, R)`，铰接为单活动关节 `q`（旋转或移动）。
- 几何度量统一使用 FK 解码后的关节位置 `J_t = FK(P_t, root, Θ_t)`；部件位姿 `(p_{j,t}, R_{j,t}) = FK_j( o_t )`，为刚性与铰接提供**统一的部件位姿接口**。

### 2.3 交互关系表示与构造
- 关系 `r = (h, j, x_rel, I, φ)`：参与手、目标部件、**部件局部坐标系下的手腕参考点**、参与区间、相位。
- `x_rel` 在部件坐标系中表达，随部件平移/旋转一起运动，从而**把"部件整体运动"与"手相对跟随的偏差"解耦**；它不必落在表面（手腕相对掌心/指接触点有偏移）。
- 相位 `φ: I_r → {establish, hold, release}`，区分接近、保持、离开；接近与离开不强制同一固定相对位置。
- **构造流程**：先用仅以 `c` 为条件的生成器采样一个 proposal → 依据手腕与目标部件的邻近度确定候选手与区间 → 在 hold 区间内取 proposal 手腕在部件坐标系下的**逐坐标中位数**作为 `x_rel` → 覆盖率规则与初始几何补齐/替换异常参考 → 单独训练的**时序预测器 P_η** 保守地延展区间 → 确定性分配相位带。关系在采样期间**固定**，其"实现程度"随预测演化被反复重算。
- 编码为逐帧的参与、参考、相位通道，外加双手与足部支撑标志；手、参考、区间可在同一任务目标下编辑。

### 2.4 条件生成（D_θ）
- 标准条件扩散前向加噪；**时序 Transformer** 同时处理人与物体通道，共享时间上下文。
- 文本用冻结 CLIP（512 维）给序列级动作语境；初始状态、稀疏目标、关系给帧级条件；采用 ControlNet 式并行控制模块 + 零初始化线性投影注入逐层特征。
- 物体形状用 **basis point set** 编码，经几何感知模块（受 MaMi-HOI 启发）与运动特征融合，形状/运动嵌入差异用于偏置注意力。
- 保留输出投影前的逐帧隐特征 `f ∈ R^{T×d}` 供细化器使用：`(X̂0, f) = D_θ(X_k, k; c, R)`。

### 2.5 反馈驱动的联合细化（F_ψ）
- **关系实现误差**（局部、对共同刚体变换不变）：
  `e_rel^{r,t} = R̂_{j,t}^⊤ ( ŵ_{h,t} − p̂_{j,t} ) − x_rel`
- **确定性提取器 E_rel** 汇总：误差及其幅值、时间变化、场景系表达、手到表面距离、关系标签；参考类特征仅在 hold 帧激活，表面距离在接近/离开阶段仍可观测（用于区分"相对跟随"与"表面贴合"两种不同信号）。
- **任务残差**：`e_task = g − P_task(X̂0)`，`P_task` 按约束掩码与帧索引抽取被约束坐标（含铰接关节状态），使用与 `g` 相同的归一化单位。
- **联合更新**：`(ΔH, ΔO) = F_ψ(f, z, e_task, k)`；共享手部编码器 + 时序注意力融合，两个零初始化头分别预测全身关节增量与物体原生自由度增量（刚性：平移 + 轴角增量旋转复合；铰接：活动关节状态）。
- 修正后的 `X̂0+ = Update(X̂0, ΔH, ΔO)` 参与扩散采样更新；下一步用同一 `R, g` 从新预测重算两类反馈。
- **联合训练**：`L_gen = L_motion + λ_FK L_FK + λ_geom L_geom + λ_sem L_sem`，监督施加在**修正后**的运动上，梯度同时穿过 D_θ 与 F_ψ（含几何反馈）；关系构造与 P_η 在梯度路径之外，proposal 生成器冻结。
- 生成后有**仅手指**的优化：训练得到的 PCA 手型先验 + 接触/穿模/释放/时序平滑项，保持身体、手腕位置、掌向与物体轨迹不变。

### 2.6 时序运动校正（推理期）
- 由关系确定参与手与区间，由当前几何定位接触违规，构造**可编辑掩码 M_edit**（肩/肘/腕旋转、扩展后的局部片段）；观测前缀与区域外运动受保护。
- 固定物体轨迹与根平移、网络参数，对每个片段联合优化：`L_seg = w_c L_c + w_s L_s + w_p L_p + w_a L_a + w_j L_j + w_d L_d`（接触、滑移、表面邻近代理、加速度变化、手腕步长、编辑幅度）。
- 跨帧联合优化把修正分摊到邻近帧，避免逐帧独立修正造成的突变与边界不连续；因物体轨迹不变，**物体目标误差不被改变**。

## 6. 主要发现与结论

- **接触与任务目标可以同时改善，而非此消彼长**：主实验中方法在物体端点/waypoint 误差与接触 F1、MCC 上同时占优，说明"把物体送到目标"与"手持续参与"并非固有冲突；前文所述的关键矛盾在显式关系表示 + 联合反馈下可被缓解。
- **"任务残差"是贡献最大的单项组件**：消融中引入任务反馈使 CIS 从 47.8 升至 66.4，表明在扩散去噪中直接把"离目标还差多少"回灌给人与物体的联合更新，是提升完成率的主力。
- **"关系反馈"补足的是接触质量与精度**：在任务反馈之上再加关系反馈，CIS 进一步升至 71.2，且接触类指标与目标精度同步改善，说明两类反馈**互补而非冗余**——任务反馈负责"到位"，关系反馈负责"以正确方式到位"。
- **关系作为"条件"本身即有效**：仅加入关系条件（未加细化器）已带来增益，说明把"哪只手、哪个部件、何时、相对何处"显式编码进条件，能让生成器在采样阶段就倾向可接触的构型，而不必完全依赖事后修正。
- **局部时序校正能在不改动物体轨迹的前提下改善运动质量**：由于固定物体轨迹与根平移，接触/滑移/穿模类指标改善而物体目标误差不被破坏，避免了"修正接触反而破坏 waypoint"的典型退化。
- **对铰接物体具备可迁移性**：在 ParaHome 上以统一部件位姿接口处理单活动关节，方法仍优于适配后的基线，说明"部件局部坐标系下的相对参考 + 原生自由度增量"这一设计不局限于刚性物体。
- **方法定位**：论文的实质贡献不是新的生成骨干，而是**一套"关系表示—关系度量—关系驱动更新"的闭环机制**，可与现有条件扩散 HOI 生成器组合使用。

## 7. 局限性

- **关系依赖 proposal 质量**：关系由"先采样一个 proposal → 取 hold 区间手腕在部件系下的逐坐标中位数"构造，若初始 proposal 本身未接触或接触错误，中位数参考会被污染（虽有覆盖率规则与几何补齐，但属修补而非根治）。
- **关系在采样期固定、不被优化**：参与手、区间、相位与参考点均视为给定，若任务本身存在多种合理解（换手、换抓取点），方法无法在生成中探索替代方案；双手协同、双手分别操作不同部件、多物体场景均未涉及。
- **单一主动手 + 单一目标部件的建模假设**：关系结构 `r = (h, j, x_rel, I, φ)` 天然偏向"一手一部件"的交互片段，复杂长时序操作需靠多个关系拼接，拼接处的一致性未专门讨论。
- **物理可行性未内嵌**：脚滑、穿模、物体动力学一致性主要靠损失项与推理期后处理抑制，而非在生成过程中显式满足物理约束；因此不保证物理可执行性。
- **手指处理与身体解耦**：手部仅为基于 PCA 手型先验的推理期优化，且保持手腕位置与掌向不变，意味着"抓取姿态"的表达能力受限，精细多指接触（如捏取）难以精确刻画。
- **采样成本高**：每次采样 1000 步扩散，叠加细化器逐步调用与推理期片段优化，实际推理开销较大；论文未报告耗时，实用性评估缺依据。
- **铰接范围窄**：仅支持单活动关节（旋转或移动），多关节/带约束机构未覆盖。
- **评测层面的局限**：接触判定依赖阈值与代理距离，MCC/CIS 的定义由作者设定，结论对阈值敏感度未知；缺少用户研究；算力与训练细节报告偏简略，复现难度较高。

## 8. 启示与可拓展方向

- **"关系即条件、亦即监督信号"的范式可复用**：把交互关系表达为与共同刚体变换无关的局部量（`R̂^⊤(ŵ − p̂) − x_rel`），既便于作为条件注入，也便于作为可微反馈，这一"双用"设计对其他细粒度条件生成（如工具使用、交接、协同搬运）具有参考价值。
- **反馈式联合细化优于纯条件注入**：消融显示"条件 + 反馈"明显强于"仅条件"，提示在扩散采样中把**任务残差与交互残差回灌到人-物联合更新**是提升可控性的高效路径，且不要求改动骨干网络。
- **保物体轨迹的局部修正思路**：以"固定物体轨迹、只编辑人体局部片段"的方式做后处理，是一种低风险的质量提升手段，可用于其他"任务目标已满足但交互不合理"的生成系统。
- **可拓展方向**：将关系集合扩展为多关系/多手/多物体并引入关系间的时序依赖；让关系本身可优化（在采样中搜索抓取点与换手时机）；引入物理仿真或动力学约束替代部分手工损失；报告推理耗时与多随机种子方差；补充用户研究与阈值敏感性分析。

## 9. 一句话总结

论文把"人如何参与"显式写成**部件局部坐标系下的手-部件相对关系**，让它在扩散采样中同时充当条件与误差参照，并通过"任务残差 + 关系残差"驱动的联合细化与保物体轨迹的局部时序修正，把"物体到位"与"手持续参与"在同一生成过程中对齐，在刚性与单关节铰接两类场景上同时改善了接触质量与任务完成度。
