## 摘要
长时程、实时可控的运动生成对于交互式动画和人形机器人至关重要，其中智能体必须在运动过程中响应不断变化的指令和空间目标。现有的自回归扩散方法以增量方式生成运动，但有界注意力缓存限制了对远距离历史的访问，而重复去噪则带来显著的推理开销。我们提出 Motion Mamba 2.0，一种基于 Mamba 的根-身体扩散架构，集成了局部注意力、可恢复循环状态和持久内容记忆（PCM），用于长时程可控运动生成。PCM 将来自 Mamba 循环状态的压缩运动历史，连同状态变化和文本条件特征，转换为可供局部注意力访问的动态更新内容槽。为实现高效推理，我们进一步开发了一种针对该架构定制的执行方案，结合 CUDA Graph 重放、融合内核和执行流简化，同时保留规范的历史更新。在重定向 HiPHI 上的评估表明，在长达 39.52 秒的 rollout 中实现了准确的终端控制；而在 BONES Seed 和重定向 HumanML3D 上的短时程比较表明，该模型还保持了强大的空间控制和文本-运动匹配能力。在 RTX 4090 上，优化后的执行将完整窗口延迟中位数从 1685.35 ms 降至 276.14 ms，在测试的 rollout 中保持相同输出和提交状态的同时，实现了 6.138× 的中位配对加速比。此外，我们在 Unitree G1 上进行了广泛的真实世界评估，展示了顺序文本引导的动作组合、富有表现力的运动，以及通过键盘和鼠标控制进行的交互式移动。

## Abstract
Long-horizon, real-time controllable motion generation is essential for interactive animation and humanoid robotics, where an agent must respond to changing instructions and spatial goals while moving. Existing autoregressive diffusion methods generate motion incrementally, but bounded attention caches limit access to distant history, while repeated denoising introduces substantial inference overhead. We present Motion Mamba 2.0, a Mamba-based root-body diffusion architecture that integrates local attention, resumable recurrent states, and persistent content memory (PCM) for long-horizon controllable motion generation. PCM transforms compressed motion history from Mamba recurrent states, together with state changes and text-conditioned features, into dynamically updated content slots accessible to local attention. To enable efficient inference, we further develop an execution scheme tailored to this architecture, combining CUDA Graph replay, fused kernels, and execution-flow simplification while preserving the canonical history update. Evaluations on retargeted HiPHI demonstrate accurate terminal control over rollouts of up to 39.52 s, while short-horizon comparisons on BONES Seed and retargeted HumanML3D show that the model also retains strong spatial control and text-motion matching. On an RTX 4090, the optimized execution reduces median complete-window latency from 1685.35 to 276.14 ms, achieving a median paired speedup of 6.138$\times$ while preserving identical outputs and committed states in the tested rollouts. Moreover, we conduct extensive real-world evaluation on the Unitree G1, demonstrating sequential text-guided action composition, expressive motion, and interactive locomotion through keyboard and mouse control.

  - **有界注意力缓存**：滑动 KV cache 会丢弃较早的运动特征；无界缓存则随序列增长带来存储与计算膨胀。
  - **重复去噪开销**：即使单次模型评估很小，逐窗口反复去噪的 kernel 启动、中间内存流量、主机调度仍造成巨大执行开销。作者强调二者是**不同维度**的问题——减少采样步数不延长可用历史，紧凑历史状态也不消除去噪开销。
- **状态空间模型（Mamba）的机遇与缺口**：SSM 用固定大小的循环状态压缩整段序列，但**压缩循环状态与注意力缓存暴露历史的方式不同**（前者携带演化上下文，后者支持显式特征检索）；简单地把两支并联并不能让循环历史被注意力直接访问，因此需要一个**学习式的"状态→注意力内容"接口**。
- **扩散特有的建模难点**：连续去噪候选是同一输出窗口的**替代方案**，不是运动流的时间推进；若把中间候选写入历史，会把"采样迭代"与"物理时间"混为一谈。因此必须显式定义**预测/历史提交边界**。
- **整体含义**：论文在 ARDY 的显式 root + latent body 混合表示之上，把 Mamba-3 循环状态、局部注意力、持久内容记忆（PCM）整合进自回归扩散去噪器，并配套一套**保语义的推理加速方案**，目标是"用有界历史上下文实现长时程、可实时控制的 G1 运动参考生成"。

## 2. 方法论

### 2.1 流式形式化与运动表示
- 输出划分为长度 C token 的窗口，每 token 对应 P 帧（实验中 52 帧窗口 ≈ 2.08 s，25 Hz）。
- 条件分解：`p(x_{0:T} | s,g,v) = Π_t p(x_t | s_t, g_t, v_t; M_{t-1})`，其中 `M_{t-1}` 由**已接受**的运动前缀构造。
- 混合表示（沿用 ARDY）：每帧 root 为位置 `p∈R³` 与朝向 `ψ`；token `x_i = [r_i; b_i]`，`r_i∈R^{5P}` 为 root patch，`b_i∈R^L` 为因果运动 codec 压缩的身体 latent；解码时用 `Local(·)` 提供的局部 root 特征重建关节旋转/位置/速度/接触。
- 前向扩散为标准高斯加噪 `z_{τ} = √ᾱ_τ x + √(1-ᾱ_τ) ε`。

### 2.2 两阶段 root–body 去噪
- 每次去噪评估**先预测全局 root，再以该 root 的局部特征条件预测身体**；root 与 body 两套 DiT 堆栈参数独立、层内记忆独立。
- 关键点：每个去噪步都刷新 root→body 条件，使两者在**整个采样过程中耦合**，而非生成后拼接。
- 有效 root 观测替换对应噪声坐标；未来目标嵌入到其目标位置，空位被 mask。

### 2.3 混合序列混合器（Attention + Mamba-3）
- 每个 DiT 层含 AdaLN 调制与门控残差 MLP；sequence mixer 内**注意力与 Mamba 处理同一份归一化特征**，输出由**逐层学习门控**融合。
- Mamba-3 采用**可恢复（resumable）SISO scan**：相位累积 `φ_i = φ_{i-1} + πΔ_i tanh(θ_i)`，用旋转 `R(φ_i)` 作用于 `B_i, C_i`，梯形更新 `H_i = α_i H_{i-1} + β_i u_{i-1} B̃^T_{i-1} + γ_i u_i B̃^T_i`，`y_i = H_i C̃_i + D u_i`；携带状态包含循环矩阵、累积相位、上一状态输入与值向量，**尺寸与已接受序列长度无关**。

### 2.4 持久内容记忆（PCM）
- **分工**：滑动缓存直接暴露最近 W 个已接受窗口的 K/V；Mamba 携带定长压缩历史但本身不是注意力 token；PCM 学习把压缩状态映射为**注意力可读的内容槽**。
- **静态 sink**：学习的 sink token 与 PCM 槽不同，cache 为空时仍可用，但不存储本回合历史。
- **内容构造**：
  - 池化并投影循环矩阵得摘要 `s_t = Π(H_t)`，状态变化 `d_t = s_t − s_{t−1}`；
  - 文本嵌入经 LN 投影产生**逐特征调制参数** `(γ_t, β_t)`，调制归一化后的差值：`ẽd_t = (1+tanh γ_t)⊙LN(d_t) + β_t`；
  - 候选槽内容 `j_t = [s_t; ẽd_t; ẽ_t]`，`Z_t = LN(f_p(j_t))`。
- **门控写入**：`w_t = η·σ(f_w([j_t; vec(P_{t−1})]))`，`P_t = (1−w_t)⊙P_{t−1} + w_t⊙Z_t`，写入率上限 `η = 0.25`；文本同时条件化候选内容与写入率，使同一状态转移在不同指令下产生不同记忆更新。
- **残差注意力读出**：`A_P` 为把投影槽插入 sink 之后的增强注意力；`Y = A_0 + tanh(ρ)(A_P − A_0) + σ(ζ)M`。`ρ` **零初始化**使初始输出与 Native mixer 完全一致（区别于"槽初始化为零"，后者仍会改变注意力归一化）。查询构造不变，状态摘要只经"内容写入"进入。

### 2.5 仅接受历史的状态更新
- 去噪期间读取**不可变快照**，产生的临时状态提议 `M̃_{t,τ}` **不提交**；采样后在扩散时间 0 的规范化干净 pass 中，root/body 两栈**一并提交** cache 追加、循环状态替换与 PCM 写入；pass 失败则两栈保留旧状态。
- 由此，cache 只增长到 W 窗口，循环状态与槽银行定长 ⇒ 每新窗口的内存与计算**不随已生成时长增长**（作者明确限定：这是计算上下界，不意味着任意时长无误差）。

### 2.6 保状态的高效推理
- **只读执行**：不物化预测与后续提交都不消费的状态提议与诊断量；规范化干净 pass 仍构造完整接受状态。
- **融合内核**：把 Mamba 转移预处理（衰减激活、衰减下限、步长变换、`Δ_iA_i` 乘积）融合为单次遍历，中间值留在 FP32 寄存器：`χ(a)=max(a,0)+(1−min(a,0))^{-1}`，`A_i=min(−χ(a_i),−a_min)`，`Δ_i=softplus(d_i+b_Δ)`，`Ξ_i=Δ_iA_i`；兼容的 scale–shift 与门控残差也融合。
- **CUDA Graph 重放**：root

**CUDA Graph 重放**：root 与 body 两套 DiT 栈分别捕获为静态执行图，将每步去噪中形状固定的 kernel 序列（AdaLN 调制、混合 mixer、PCM 读写、root→body 条件注入）一次性录制并重放，从而消除逐 kernel 的主机端启动与调度开销；动态输入（噪声候选、文本/目标条件、历史快照）通过**固定地址的静态缓冲区**传入，图重放前仅做一次异步拷贝，避免主机同步。由于提交边界已把“读取快照”和“写入状态”分离，图内只执行只读推理，状态更新留在图外的规范化干净 pass 中，因此重放不破坏状态语义。

- **三者协同的效果**：只读执行削减无用状态提议与诊断量的物化；融合内核降低 Mamba 转移的中间内存流量；CUDA Graph 消除启动开销。三者共同针对“单次评估小但调用极频繁”的扩散执行特征，而非改变采样步数或历史长度。

### 2.7 训练目标与状态一致性
- 主目标为标准的条件扩散去噪损失，在 root 与 body 两栈上分别计算；root 栈的预测通过 `Local(·)` 为 body 栈提供条件，二者联合优化。
- PCM 的写入门控与读出残差以零初始化/低写入率起步，使训练初期模型退化为 Native mixer，随后逐步学习利用记忆槽；这既稳定优化，也保证“记忆是增量能力而非必需通路”。
- 训练时对历史状态采用与推理一致的**已接受前缀**构造，避免模型依赖推理时不可得的中间去噪候选；对空 cache、短历史与长历史做混合采样，使 sink token 与 PCM 槽在冷启动与饱和两种情形下都被覆盖。
- 由于循环状态尺寸与序列长度无关，训练可按窗口截断展开，而无需存储整段历史的反向图，显存开销与生成长度解耦。

- **指标维度**：
  - **运动质量**：与参考动作的关节/root 误差、接触与脚滑指标、物理合理性；
  - **长时程一致性**：长序列上的漂移、历史依赖任务（如回到先前位置、延续早先指令）的成功率；
  - **可控性**：文本切换响应延迟与语义符合度、空间目标到达精度；
  - **效率**：单窗口延迟、吞吐、显存/状态占用随生成长度的增长曲线。

## 4. 主要结果（按论文主张归纳）

- **有界上下文下的长时程生成**：滑动 cache 固定为 W 窗口后，循环状态与 PCM 槽保持定长，内存与每窗口计算不随已生成时长增长；长序列上的质量漂移显著小于纯滑动 cache 基线，接近无界 cache 的表现，但资源占用恒定。
- **历史可访问性**：消融显示，去掉 PCM、仅保留 Mamba 循环状态时，需要显式检索早期特征的任务（如遵循早先指令、回到旧目标）性能下降；说明“压缩状态→注意力内容”的接口是必要的，而非并联 Mamba 即可替代。
- **可控性与实时性**：文本与空间目标可在生成过程中注入并影响后续窗口；融合内核 + CUDA Graph 带来明显的端到端延迟下降，使交互式频率下的连续生成成为可能，且加速不改变采样语义（与未加速版本输出分布一致或差异在噪声范围内）。
- **提交边界的必要性**：若把去噪中间候选写入历史，训练/推理出现语义错位，表现为运动抖动与条件遵循退化；仅在扩散时间 0 的干净 pass 提交可消除该问题。
- **加速方案的正交性**：减少采样步数会损害质量且不延长可用历史；增大窗口提高单窗成本；本文方案在保持采样步数与窗口不变的前提下降低执行开销，因而与采样器改进可叠加。

## 5. 讨论与局限

- **“有界”不等于“无限”**：定长状态给出的是计算与内存的上界保证，不保证任意长时程下无信息损失；极早历史的细节仍可能被压缩掉，PCM 的槽容量构成新的信息瓶颈。
- **提交失败的处理**：干净 pass 失败时保留旧状态可避免污染，但会造成该窗口历史缺失，长期运行下的失败累积值得关注。
- **硬件与实现依赖**：融合内核与 CUDA Graph 的收益依赖具体 GPU 与 kernel 启动开销；在启动开销较低的平台上相对增益会缩小。
- **评价范围**：主要在 G1 与特定运动 codec 上验证，跨形态、跨数据分布的泛化性尚未充分覆盖。

## 6. 结论与启示

论文的核心贡献可概括为三点：其一，明确区分“历史容量”与“去噪执行开销”两个正交问题，并分别用定长循环状态 + PCM 与只读执行/融合内核/图重放来应对；其二，提出学习式的“状态→注意力内容”接口，使 Mamba 的压缩历史可被注意力直接读取，而非与注意力简单并联；其三，以“仅接受历史提交”为原则，严格分离采样迭代与物理时间推进，保证自回归扩散在流式设定下的语义正确性。整体上，它为“有界上下文、实时可控的长时程运动生成”提供了一个可复用的系统级范式。
