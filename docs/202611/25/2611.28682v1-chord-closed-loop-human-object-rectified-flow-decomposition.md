## 摘要
文本驱动的三维人-物交互（HOI）生成需要合成在接触过程中保持耦合的全身人体与物体运动。然而，现有生成器要么将支配交互的核心变量（物体位姿、接触区域和肢体姿态）与数十个从属关节纠缠在一起，要么仅规划末端执行器或粗略轨迹。生成的任一阶段都没有以一种既已确定又可被观测的形式保持该交互，这使得接触只能依赖外部引导、事后精修器，或在没有表面测量的情况下依赖内部引导。我们提出 CHORD，一个两阶段修正流框架，它将交互确定为一个紧凑计划，并在该计划生成过程中对照物体表面对其进行观测。首先，Draft 在每个时间片段上使用十二个部件 token，联合规划 6-DoF 物体轨迹、接触状态以及每个运动链的末端与中间关节。在每个流步骤中，Draft 从闭式干净估计中解码出期望交互，将其与物体表面进行度量，并将该反馈路由到负责的部件 token，且无需额外的网络评估。其次，Full 保持该计划不变，并填充其余身体与手指关节。在 InterAct 上，CHORD 将 FID 降低 33%，并将手部接触 F1 从 0.730 提升至 0.834；同时，其反馈可改善未见物体上的接触，并可即插即用地迁移到现有 HOI 生成器。

## Abstract
Text-driven 3D human-object interaction (HOI) generation requires synthesizing whole-body human and object motions that stay coupled through contact. Yet existing generators either entangle the core variables that govern an interaction (object pose, contacting regions, and limb posture) with dozens of subordinate joints, or plan only end-effectors or coarse trajectories. No stage of generation holds the interaction in a form that is both settled and observed, which leaves contact to external guidance, post-hoc refiners, or internal guidance without a surface measurement. We present CHORD, a two-stage rectified-flow framework that settles the interaction in a compact plan and observes that plan against the object surface while it is being generated. First, Draft uses twelve part tokens per temporal patch to jointly plan the 6-DoF object trajectory, contact states, and the end and middle joints of every kinematic chain. At each flow step, Draft decodes the expected interaction from the closed-form clean estimate, measures it against the object surface, and routes this feedback to the responsible part token with zero extra network evaluations. Second, Full keeps this plan unchanged and infills the remaining body and finger joints. On InterAct, CHORD reduces FID by 33% and lifts hand contact F1 from 0.730 to 0.834, while its feedback improves contact on unseen objects and transfers plug-and-play to existing HOI generators.

## 1. 核心问题与整体含义（研究动机与背景）

- **任务定位**：文本驱动的三维人-物交互（HOI）生成，需要同时合成 6-DoF 物体轨迹与包含手指的全身人体运动，并保证二者在整个交互过程中通过接触保持耦合。
- **现有方法的两类路线**：
  - 单阶段生成器：通过 cross-attention、联合学习接触、或对不同 token 组使用不同噪声水平来耦合人体与物体分支。
  - 粗到细（coarse-to-fine）流程：先产生稀疏引导（手部位置或粗轨迹），再合成细节。
- **核心痛点**：论文指出，现有方法在生成过程中，没有任何阶段把交互保持为“既已确定（settled）又可被观测（observed）”的形式：
  - **不 settled**：决定交互的核心变量（物体如何运动、哪些身体区域接触、每条肢体如何摆姿）没有专门的承载位置，被混入所有自由度中，或只规划末端/粗轨迹而让肢体姿态开放。
  - **不 observed**：生成器得不到“当前预测相对物体表面处于何处”的测量，接触只能依赖外部引导、事后精修器，或缺乏表面测量的内部引导。
- **后果**：身体与物体在交互中逐渐漂移分离，出现悬空、穿模、接触中断等问题。
- **整体含义**：CHORD 试图把“决定交互”和“校验交互”统一到生成过程内部，在不增加额外网络评估的前提下实现闭环接触控制。

## 2. 方法论

### 2.1 核心思想

- 采用**两阶段 rectified-flow 框架**：
  - **DRAFT**：用紧凑的“部件结构化计划”确定交互（物体位姿、接触状态、各运动链末端与中间关节），并在每个流步骤对照物体表面进行测量与反馈。
  - **FULL**：保持该计划不变，填充剩余身体关节与手指关节。
- 一句话概括：**在可校验之处决定交互，在决定之处校验交互**。

### 2.2 第一阶段 DRAFT：部件结构化计划

- **时间分片**：每 K=4 帧为一个 temporal patch。
- **12 个部件 token**：1 个物体 token + 11 个计划关节 token（pelvis、双手、双脚、双肘、双膝、chest、head），root orientation 归入 pelvis token。
- **每帧预测的 48-D 状态**：物体平移+6D 旋转（9 维）、pelvis/手/脚的世界坐标（15 维）、root orientation（6 维）、pelvis 坐标系下的 chest/knee/elbow/head 位置（18 维）；另预测 8 个身体区域的二元接触指示（手、脚、pelvis、back、forearms）。
- **计划的设计逻辑**：一旦物体位姿、pelvis、各链末端与中间关节固定，其余身体关节受骨骼几何强约束——因此计划已把身体姿态约束到手指以外，FULL 只需在约束内填充。
- **网络结构**：每个 transformer block 包含：
  - 12 个部件 token 间的空间自注意力；
  - 每个部件沿轨迹的时间自注意力；
  - 对条件 token 的 cross-attention（物体几何的 basis point set 编码、body shape、序列长度），并用 adaLN 以 flow time 和条件调制；
  - **按 token 类型路由的 FFN**（object / hands / body）。
- **部件级文本注意力**：指令由冻结的 Qwen2.5-1.5B 编码为词特征，每个部件有 part anchor；每个 token 以自己的 query 对词做注意力（含 patch 位置与词位置的相对距离偏置），使每个部件关注与自己相关的词，而非共享一个池化表示。

### 2.3 第二阶段 FULL：完成

- 保持 DRAFT 的物体轨迹与 11 个计划关节**不变**，只生成剩余 13 个身体关节和 28 个手指关节。
- 手指位置表示为相对 hand joint 的偏移；每帧用 body token + finger token，block 内做 token 间注意力、时间注意力、对指令词与 12 个 plan token 的 cross-attention，以及类型路由 FFN。
- finger token 额外接收距计划手部最近的物体表面点。

### 2.4 生成中的接触反馈（闭环）

- **期望交互解码**：每个流步骤由 rectified flow 的闭式干净估计（clean estimate）得到期望接触区域位置与期望物体位姿，并将各区域变换到期望物体坐标系。
- **表面测量**：对每个接触区域找最近 canonical 表面点，构造 11 维几何特征，包括：
  - 表面偏移向量 δ 及其范数（悬空区域需闭合的间隙方向与大小）；
  - 帧间偏移差（在物体坐标系下，刚性随物体运动应为零，非零即暴露漂移/滑动）；
  - 尺度归一化的最近表面点（指示在物体上的位置）；
  - 可用性标志位（首步或无反馈时整特征为零）。
- **路由**：手/脚/pelvis 的测量进入各自 token，back 进入 chest token，forearm 进入 elbow token；通过零初始化线性通路在 token embedding 处及每个 block 前注入。
- **关键优势**：反馈复用 velocity field 已产生的 clean estimate，**零额外网络评估**，无需梯度引导或辅助网络；修正成为 velocity field 的一部分。

### 2.5 训练与推理

- **DRAFT 损失**：分组 velocity loss + 接触 BCE + 接触区域在物体坐标系下的锚定损失 + 肢体长度保持 + 脚部滑步惩罚 + 静止物体运动惩罚；后几项在 clean estimate 上计算。
- **两遍训练**：90% 样本先做 stop-gradient 的第一遍（在更早、更噪的 flow time s0=s−Δs，无反馈），其反馈再条件化第二遍（在 s，接收梯度），以模拟采样时反馈来自上一 Euler 步；10% 样本无反馈，匹配首步。
- **推理**：N=32 个 DRAFT Euler 步 + 8 个 FULL Euler 步，CFG scale 0.5，共 72 次网络评估；第 k 步复用第 k−1 步期望交互的反馈。
