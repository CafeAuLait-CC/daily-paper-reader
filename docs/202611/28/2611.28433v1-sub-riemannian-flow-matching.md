## 摘要
我们研究用于具有指定速度约束的生成式传输的次黎曼条件流匹配（SRCFM）。训练使用采样源点与目标点之间的路径，这些路径的速度在每一状态均位于允许的水平方向内。神经网络以时间和完整状态为输入，预测这些方向的系数，随后由水平标架确定用于生成的完整速度。我们描述了基于 Heisenberg 测地线和自由二步 Carnot 群中联合端点方程的构造。我们提出一种可扩展的分段算法，可直接由端点计算水平路径。一条直线段设定水平坐标，而这些坐标中的一个环路修正剩余的垂直位移。我们在高维测试中将该算法的端点精度验证至数值精度。合成实验展示了沿水平轨迹的近似分布传输。在调整尺寸后的 MNIST 上，我们使用相同的构造，从高斯输入生成图像，且控制量少于像素数。

## Abstract
We study sub-Riemannian conditional flow matching (SRCFM) for generative transport with prescribed velocity constraints. Training uses paths between sampled source and target points whose velocities lie in the allowed horizontal directions at each state. A neural network takes time and the full state as input and predicts the coefficients of these directions, and the horizontal frame then determines the full velocity used for generation. We describe constructions based on Heisenberg geodesics and joint endpoint equations in free step-two Carnot groups. We propose a scalable piecewise algorithm that computes horizontal paths directly from their endpoints. A straight segment sets the horizontal coordinates, and a loop in those coordinates corrects the remaining vertical displacement. We verify the algorithm's endpoint accuracy to numerical precision in high-dimensional tests. Synthetic experiments illustrate approximate distribution transport along horizontal trajectories. On resized MNIST, we use the same construction to generate images from Gaussian inputs with fewer controls than pixels.
