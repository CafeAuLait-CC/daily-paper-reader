## 摘要
生成高质量的三维点云需要同时捕捉全局形状拓扑和局部几何细节。现有的基于流的方法依赖于连续归一化流（CNFs），其在训练过程中需要昂贵的常微分方程求解和迹估计，而扩散模型则需要数百次迭代去噪步骤。此外，大多数方法直接在点空间中进行单层级生成，忽略了三维形状固有的层次结构。我们提出了层次化流匹配（HFM），将流匹配扩展到双层级结构，用于无条件三维点云生成。HFM通过最优传输流匹配将任务分解为两个层级：\textit{Latent Flow Matching}在紧凑的潜在空间中建模全局形状流形，\textit{Conditional Point Flow Matching}以潜在代码为条件重建详细的点云。两个流均使用简单的均方误差（MSE）回归损失进行训练。由此产生的直线最优传输路径使得每个流仅需少至15步的欧拉采样即可实现高效采样，同时结构化的潜在空间支持包括分类在内的下游任务。在ShapeNet和ModelNet基准上的大量实验表明，与先前最先进的方法相比，HFM取得了具有竞争力甚至最佳的性能。

## Abstract
Generating high-quality 3D point clouds requires capturing both global shape topology and local geometric details. Existing flow-based methods rely on continuous normalizing flows (CNFs) that demand expensive ODE solving and trace estimation during training, while diffusion models require hundreds of iterative denoising steps. Moreover, most approaches adopt single-level generation directly in point space, disregarding the hierarchical structure natural to 3D shapes. We propose Hierarchical Flow Matching (HFM) that extends flow matching to bilevel structure for unconditional 3D point cloud generation. HFM decomposes the task into two levels via optimal-transport flow matching: a \textit{Latent Flow Matching} models the global shape manifold in a compact latent space, and a \textit{Conditional Point Flow Matching} reconstructs detailed point clouds conditioned on the latent code. Both flows are trained with simple MSE regression losses. The resulting straight OT paths enable efficient sampling with as few as 15 Euler steps per flow, while the structured latent space supports downstream tasks including classification. Extensive experiments on ShapeNet and ModelNet benchmarks demonstrate that HFM achieves competitive or even best performance compared with prior state-of-the-art methods.

- **现有 Flow Matching 点云方法（PSF、Not-So-OT 等）** 均为单层级生成，直接在点空间操作，没有利用形状的层次结构。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 核心思想

HFM 受 PointFlow 双层级设计的启发，但将其昂贵的 CNF 骨干替换为免模拟的 Flow Matching，在获得层次结构的同时消除 ODE 求解负担。整体框架由以下两个模块组成：

- **Latent Flow Matching**：对全局形状潜在变量 z 的先验分布 p(z) 建模；
- **Conditional Point Flow Matching**：对给定潜码 z 时的条件点云分布 p(X|z) 建模。

### 2.2 关键技术细节

**（1）条件流匹配（CFM）基础**

采用最优传输（OT）路径，在噪声 x₀~N(0,I) 与数据点 x₁ 之间线性插值：

> x_t = (1 - t/T)x₀ + (t/T)x₁, u_t = (x₁ - x₀)/T

训练目标简化为对闭合形式的回归：

> L_CFM = E[‖v_θ(x_t, t) - (x₁ - x₀)/T‖²]

该过程无需 ODE 求解器、无需对数似然计算、无需迹估计，仅需简单 MSE 损失。直线 OT 路径支持使用欧拉法反向积分实现高效采样。

**（2）Latent Flow Matching**

- 使用 PointNet++ 作为编码器 q(z|X)，将点云 X∈R^{N×3} 映射到 128 维潜码 z∈R^d。
- 潜码捕获全局拓扑与类别级结构，细粒度细节交给条件点流。
- 潜在空间中，OT 路径在潜码 z 与高斯噪声 z₀ 之间直线插值，目标速度为 (z₀ - z)/T。
- 低维潜空间的直线插值已接近最优传输映射，因此仅需少量函数评估即可有效建模形状码流形。

**（3）Conditional Point Flow Matching**

- 每个点 x^(i) 独立地朝各自的高斯噪声样本插值。
- 所有点共享同一个条件潜码 z，提供全局上下文以协调各点轨迹为连贯形状。
- 点速度网络 v_θ(x_t, t, z) 使用 MLP，逐点独立操作，通过 AdaptiveConditionLinear 调制层将时间 t 与形状码 z 的拼接向量作为条件注入网络。
- 逐点处理天然满足置换等变性。

**（4）完整训练目标**

> L_total = L_point + L_latent + L_entropy

其中熵正则项 L_entropy = -λ·H[q(z|X)] 对对角高斯编码器有解析形式，用于鼓励编码器保持非退化后验，防止后验坍缩。λ 在生成实验中设为 10⁻⁴。

**（5）两种训练配置**

- **生成任务**：使用完整目标，端到端联合训练，潜流学习灵活先验；
- **自编码任务**：禁用潜流与熵项，仅保留 L_point，作为确定性自编码器，潜码专为保留形状信息优化。

**（6）采样与推断**

采用反向欧拉积分，从 t=T 到 t=0，先由噪声生成潜码 z，再以 z 为条件由噪声生成点云。T 设为 0.5，每个流使用 15 步欧拉积分。论文提到 Heun 积分器无明显改进，印证了 OT 轨迹的近似直线性。

### 2.3 算法流程

训练时：编码器将点云编码为潜码 → 分别采样时间步与噪声 → 计算潜流 MSE 损失与点流 MSE 损失 → 加上熵正则项 → 反向传播（梯度过重参数化潜码回传至编码器参数）。采样时：先从高斯噪声经反向潜流生成潜码，再从高斯噪声经反向点流生成点云。

## 7. 优点

1. **双层级结构设计合理**：将"全局形状"与"局部几何"自然分离，符合三维形状的天然层次属性；
2. **训练简单高效**：纯 MSE 回归，无需 ODE 求解器、迹估计或对数似然计算，训练过程大幅简化；
3. **端到端单阶段训练**：无需重流（reflow）或蒸馏（distillation）等额外阶段，与 PSF 的三阶段流程相比显著简化；
4. **采样高效**：直线 OT 路径使得少量欧拉步数即可达到高质量生成，相较于扩散模型数百步的采样有量级优势；
5. **结构化潜空间支持下游任务**：编码器可用于无监督表示学习，在 ModelNet 上取得最优的分类准确率；
6. **置换等变保证**：逐点处理的 MLP 天然满足点云的置换不变性；
7. **充分消融**：对潜流、熵系数、采样步数三个关键设计因素进行了验证，结论清晰；
8. **框架简洁通用**：不依赖离散 tokenization 或特定网络结构，有扩展至 Transformer 骨干的潜力；
9. **相对训练成本低**：单类别约 9.8 GPU 小时即完成训练，相比扩散模型的训练开销有明显优势。

## 8. 不足与局限

1. **逐点独立 OT 耦合**：每个点独立地沿 OT 路径从噪声到数据，除了共享潜码 z 外没有显式的跨点耦合。论文作者承认，近期关于 minibatch OT 耦合的研究表明，在形状内部耦合噪声可能进一步改善局部结构的一致性和覆盖度；
2. **MLP 表达力有限**：当前速度网络基于 MLP，逐点处理，在捕捉跨点长程依赖方面不如 Transformer 架构。作者指出，探索 Transformer 骨干与流匹配框架的结合是未来方向；
