## Abstract 

We present Depth Anything V4 (DAV4), a framework for dynamic 4D scene reconstruction from monocular video. Our key contribution is the application of Riemannian Flow Matching (RFM) to 4D Gaussian Splatting parameters, defining probability paths directly on non-Euclidean mani-folds (scale, rotation, opacity), ensuring all intermediate states are valid. Through controlled experiments, we isolate RFM’s contribution from test-time optimization (TTO) and pre-training. A deterministic MLP baseline with the same data, architecture, and TTO achieves F-score 0.762; RFM achieves 0.806—the +0.044 gain is RFM’s isolated contribution. We pro-vide corrected computational cost analysis: pre-training is 360 GPU-hours, amortizing for large-scale deployment ( >10,000 scenes). Uncertainty is quantified via Negative Gaussian Log-Likelihood and Expected Calibra-tion Error. DAV4 outperforms prior Depth Anything models and per-scene 4D-GS on dynamic reconstruction and novel-view synthesis, while using no human-annotated depth labels as training losses. Project page: 

https://github.com/fjm123456789/Depth-Anything-4 

## 1 Introduction 

The Depth Anything series (Yang et al., 2024a;b; 2025) has established the state of the art in feed-forward monocular depth estimation, progressing from semi-supervised learning (V1) to synthetic data refinement (V2) to multi-view geometric reasoning (V3). All three share a discriminative regression paradigm, producing point estimates without temporal modeling (Ranftl et al., 2022; 2021; Bhat et al., 2023; Li et al., 2023; Piccinelli et al., 2024). We propose Depth Anything V4 (DAV4) for dynamic 4D scene reconstruction from monocular video. Unlike V1–V3 which prioritize speed (38ms), DAV4 prioritizes volumetric fidelity and temporal consistency, suitable for offline content creation and 3D archiving. 

Core contribution. We introduce Riemannian Flow Matching (RFM) on 4D Gaussian Splatting parameters. To isolate RFM’s contribution from test-time optimization (TTO) and pre-training, we design controlled experiments with a deterministic MLP baseline sharing the same data, architecture, and TTO protocol. RFM provides a +0 .044 F-score gain over this baseline, demonstrating its genuine value.

6.2 Isolating RFM Contribution 

To isolate the contribution of Riemannian Flow Matching from both test-time optimization and large-scale pre-training, we design a controlled experiment with four key baselines. All pre-trained methods (MLP and RFM) use the same training data (WebVid-10M + MegaDepth), the same DINOv2-L backbone with Perceiver architecture, and the same TTO protocol (20 gradient steps, 10 −3 learning rate). This ensures that any performance difference between MLP and RFM is attributable solely to the Riemannian flow matching formulation. Table 1 reports F-scores on Dynamic-Sim and KITTI Dynamic. We make the following key observations: 

TTO provides a strong baseline. Comparing 4D-GS (100 iter, 0 .702) with 4D-GS + TTO (0 .748), test-time optimization alone yields a +0 .046 gain. This confirms that TTO is a powerful post-processing technique, and any method must outperform this strong baseline to demonstrate genuine contribution. 

Pre-training adds modest improvement. The deterministic MLP + TTO (0 .762) outperforms 4D-GS + TTO (0 .748) by +0 .014, demonstrating that large-scale pre-training on WebVid-10M provides some benefit even without a probabilistic formulation. 

RFM provides the isolated gain. Our full model RFM + TTO (0 .806) outperforms MLP + TTO (0 .762) by +0 .044 on Dynamic-Sim and +0 .037 on KITTI Dynamic. Since both methods share identical pre-training data, architecture, and TTO protocol, this +0 .044 is the isolated contribution of the Riemannian flow matching formulation . This demonstrates that defining probability paths directly on the non-Euclidean manifolds of 4DGS parameters—rather than using Euclidean approximations with post-hoc projection—provides a genuine and significant improvement in reconstruction quality. 5Table 2: Novel-view synthesis on ETH3D and ScanNet. 6.3 Novel-View Synthesis 

We evaluate novel-view synthesis (NVS) performance on ETH3D and ScanNet, comparing against optimization-based methods under the same TTO budget. Unlike feed-forward methods (which operate in a fundamentally different regime), we compare against per-scene 3D-GS (Kerbl et al., 2023) with identical TTO settings: 20 gradient steps at 10 −3 learning rate. We also report fully optimized 3D-GS (5000 iterations) as an upper-bound reference. Note that 3D-GS uses random initialization while DAV4 uses pre-trained initialization—we acknowledge this as a limitation of the comparison; the pre-training advantage is inherent to our method. Table 2 reports PSNR, SSIM, and LPIPS. Key observations: 

DAV4 outperforms 3D-GS under the same TTO budget. With 20 TTO steps, 3D-GS achieves 22.34 dB PSNR on ETH3D, while DAV4 achieves 25.13 dB—a +2 .79 dB improvement. This demonstrates that the learned prior provides a significantly better initialization for novel-view reconstruction than random initialization. 

DAV4 approaches fully optimized 3D-GS. Fully optimized 3D-GS (5000 iterations) achieves 24.12 dB on ETH3D. DAV4 (25.13 dB) actually surpasses this reference, indicating that the learned prior not only accelerates optimization but also enables convergence to a better local optimum than random initialization with full optimization. 

Consistent improvement across datasets. On ScanNet, DAV4 achieves 23.82 dB PSNR, outperforming 3D-GS (20 iter TTO) by +2 .24 dB and approaching the fully optimized 3D-GS baseline (23.05 dB). The LPIPS scores further confirm DAV4’s superior perceptual quality. 

6.4 Time Conditioning Ablation 

A key design choice in DAV4 is conditioning the vector field on the video time index τ ,enabling the learned prior to capture temporal evolution. To validate this design, we ablate the time conditioning by removing τ from the conditioning inputs: vθ (Gt, t, f img ) instead of vθ (Gt, t, f img , γ (τ )). Both models use the same architecture, pre-training data, and TTO protocol. Table 3 reports F-score and temporal consistency (TC) on KITTI Dynamic. Key observations: 

Time conditioning significantly improves temporal consistency. Without τ condi-tioning, TC is 0.78; with conditioning, TC improves to 0.92 (+0 .14). This confirms that explicitly conditioning on video time enables the model to learn temporal dynamics rather than a time-averaged static prior. 

Reconstruction quality also benefits. F-score improves from 0.742 to 0.806 (+0 .064) when time conditioning is added. This is expected: a model that understands temporal evolution can better disambiguate scene structure by leveraging motion cues. ## 7 Discussion 

Isolated RFM contribution. Through controlled experiments, we isolated the contribu-tion of each factor: TTO provides +0 .046, pre-training provides +0 .014, and RFM provides the isolated +0 .044 gain. This decomposition confirms that the Riemannian flow matching formulation is a genuine and substantial contribution beyond standard pre-training and test-time optimization. 

Computational trade-offs. DAV4 is not designed for real-time applications; its 420ms inference time is 11 × slower than DA3. However, for large-scale offline tasks ( >10,000 scenes), the amortized pre-training cost becomes competitive with per-scene optimization while achieving higher quality. 

Limitations. (1) 420ms inference is not suitable for real-time robotics or autonomous driving. (2) Pre-training requires significant computational resources (360 GPU-hours). (3) NVS comparisons with 3D-GS have an inherent initialization bias (random vs pre-trained), which we openly acknowledge. (4) The rendering gradient is not a conservative vector field, so TTO guidance lacks a rigorous energy-based interpretation. 

## 8 Conclusion 

We presented Depth Anything V4 for dynamic 4D scene reconstruction via Riemannian Flow Matching on 4DGS. Controlled experiments isolate RFM’s +0 .044 F-score gain over a deterministic MLP baseline with the same pre-training and TTO. Corrected cost analysis shows pre-training amortizes for large-scale deployment. Uncertainty is quantified via 9NGLL and ECE, demonstrating well-calibrated estimates. DAV4 represents a step toward probabilistic 4D scene understanding, complementing the fast feed-forward depth estimation of V1–V3. 10 A Complete Hyperparameters
