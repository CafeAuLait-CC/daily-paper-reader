## 摘要
最近基于数据驱动的六自由度抓取姿态合成方法使用生成模型来学习复杂的抓取姿态分布并生成多样的候选姿态。特别是，SE(3)-等变流模型生成的抓取姿态能够与物体的旋转和平移保持一致地变换。然而，这些方法通过迭代数值积分进行采样，每次抓取需要数十次函数评估，限制了它们在实时操作中的应用。我们提出了GraspMeanFlow，一个用于少步6-DoF抓取生成的SE(3)-等变MeanFlow框架。我们的方法学习有限时间区间上的平均速度，该速度通过时间有序指数定义，从而精确地再现该区间内累积的刚体位移。我们证明了由等变平均速度流图传输的点云条件分布保持不变性，因此在少步采样下等变性得以保留，并且我们通过将一对时间提升为等变向量来对场进行条件化，而保持主干网络不变。为了稳定训练，我们将流匹配边界项与两个一致性项之一配对：差分MeanFlow恒等式（其目标需要雅可比向量积）或避免该积的等效半群损失。在ACRONYM上的实验表明，GraspMeanFlow的单次函数评估达到了迭代SE(3)流模型需要五步才能接近的EMD，同一框架的第二个实例在少步机制中将抓取成功率提高了多达24.3个百分点，并且两者生成的抓取分布都随物体精确变换。

## Abstract
Recent data-driven methods for synthesizing 6-DoF grasp poses use generative models to learn complex grasp pose distributions and generate diverse candidate poses. In particular, SE(3)-equivariant flow-based models generate grasp poses that transform consistently with object rotations and translations. However, these methods sample by iterative numerical integration, requiring tens of function evaluations per grasp and limiting their use in real-time manipulation. We propose GraspMeanFlow, an SE(3)-equivariant MeanFlow framework for few-step 6-DoF grasp generation. Our method learns the average velocity over a finite time interval, defined through the time-ordered exponential so that it reproduces exactly the rigid-body displacement accumulated over that interval. We prove that a point-cloud-conditioned distribution transported by an equivariant average-velocity flow map remains invariant, so equivariance is retained under few-step sampling, and we condition the field on a pair of times by lifting both to equivariant vectors, leaving the backbone otherwise unchanged. For stable training, we pair a flow-matching boundary term with either of two consistency terms: the differential MeanFlow identity, whose target requires a Jacobian-vector product, or an equivalent semigroup loss that avoids it. Experiments on ACRONYM show that a single function evaluation of GraspMeanFlow reaches the EMD that an iterative SE(3) flow model needs five steps to approach, that a second instantiation of the same framework improves grasp success by up to 24.3 points in the few-step regime, and that both generate grasp distributions transforming exactly with the object.

## 2. 论文提出的方法论

### 核心思想
- **SE(3)-等变平均速度**：通过时间有序指数（time-ordered exponential）定义SE(3)上的平均速度，使学习的李代数元素精确复现该区间内累积的刚体位移。对于轨迹 Tτ = (Rτ, xτ)，区间[s, t]上的平均速度(ω_avg, v_avg)满足：
  - exp((t-s)[ω_avg]) = T_exp(∫ₛᵗ [ωτ]dτ)
  - (t-s)v_avg = ∫ₛᵗ vτ dτ
- **微分形式与左雅可比**：对上述定义关于t求导，得到SE(3)上的MeanFlow恒等式：
  - J(ω_{s→t}) · (d/dt)ω_{s→t} = ω_t
  - 其中J为SO(3)的左雅可比矩阵，其闭式解通过积分J(φ)=∫₀¹e^{α[φ]}dα给出。

### 两种训练实例
- **GMF-SG（半群损失）**：利用半群性质（两段转换的复合等于直接转换），通过log(exp([ω_{m→t}])·exp([ω_{s→m}]))构造无雅可比的目标，全程仅使用exp/log运算和加法，避免了JVP和左雅可比。配以流匹配边界项L = λ_bd·L_bd + λ_sg·L_sg防止坍塌。
- **GMF-JVP（微分损失）**：使用逆雅可比目标形式的微分MeanFlow恒等式，配合逐物体最优传输耦合，需要一次雅可比-向量积（JVP）。

### 关键理论保证
- **等变性保留**：证明在点云条件分布被等变平均速度流图传输时，分布具有不变性。Proposition 2针对pushforward测度而非密度证明，因此在少步（几步）采样下依然有效，不要求传输映射是微分同胚。
- **两时间条件机制**：将时间对(s,t)分别通过已有的等变提升机制（乘以共享的等变方向）注入模型，新增参数仅512个（<0.1%），保持网络总参数量633K。

### 训练流程
- 两阶段训练：第一阶段为α-Flow热身（18k步，α从1到0.2退火），使用数据速度提供近端段；第二阶段切换为边界+一致性目标（102k步）。
- 空间系（spatial frame）参数化速度场（而非体体系），这是等变头可训练的关键——体体系角速度是旋转不变的，与向量神经元输出的协变类型不匹配。

## 8. 不足与局限

- **类别不一致的增益**：Pencil类别是GMF-SG在每一步预算下均落后于EquiGraspFlow的类别；GMF-JVP虽在NFE 5和10领先，但在NFE 20反超。作者归因于铅笔绕长轴的近似旋转对称性——在物理上等价的抓取方向差异被log-位移目标当作真正的距离处理，建议采用对称性感知的目标但未实现。
- **端点采样器步数调度未解决**：如何根据步数预算调度端点采样器的加速率η仍待解决；在NFE 1和2时exp-SO(3)采样器特别不适合（η饱和到1，首步提交到从几乎未传输的先验样本预测的端点，无任何方法可用）。

- **采样器的交互效应**：Euler与exp-SO(3)采样器结果差异较大（表7），特别是在小步预算下（NFE 2时成功率差异巨大），对采样器的选择较敏感；后训练对Euler有效但对端点采样器有害，方法的最终输出质量对推理采样器选择存在依赖。
