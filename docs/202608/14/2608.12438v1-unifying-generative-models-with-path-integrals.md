## 摘要
我们将生成建模表述为一个路径积分，其中基于流、基于扩散、变分和对抗模型作为单一主作用量的不同评估原则出现。其Martin-Siggia-Rose-Janssen-de-Dominicis (MSRJD)形式将自由概率流与相互作用概率流分开，并将其开放给图解微扰理论。该展开产生对确定性采样器的一圈修正，且无需随机采样成本，我们在可解和非线性漂移上验证了这一点，将其53%的树级误差降至1.6%。不完美的学习得分作为插入项出现，并产生响应加权得分匹配目标，而对称等变漂移设计成为具有EFT功率计数的算子展开。

## Abstract
We formulate generative modeling as a path integral in which flow-based, diffusion-based, variational, and adversarial models arise as different evaluation principles for a single master action. Its Martin-Siggia-Rose-Janssen-de~Dominicis (MSRJD) form separates free from interacting probability flows and opens them to diagrammatic perturbation theory. The expansion yields a one-loop correction to deterministic samplers at no stochastic-sampling cost, which we validate on solvable and nonlinear drifts, where it reduces a 53 % tree-level error to 1.6 %. Imperfect learned scores enter as insertions and yield a response-weighted score-matching objective, and symmetry-equivariant drift design becomes an operator expansion with EFT power counting.

## 2. 方法论：核心思想、关键技术细节与公式

### 2.1 统一主作用量（Master Action）

- 从潜变量模型出发，将潜变量链推广为连续轨迹，并通过对**反向扩散过程**的离散化得出路径积分形式。
- 核心表达式为数据密度的路径积分表示：

  pdata(z₀) = ∫ dz₁ pprior(z₁) ∫ Dz exp[−∫₀¹ dt ||ż(t) − f_rev(z(t), t)||² / (2g²(t))]

- 其中 f_rev 为反向漂移，包含分数项（score）：f_rev = f − g²∇log p；该指数权即为 **Onsager–Machlup 作用量**。

### 2.2 MSRJD 形式与自由–相互作用分裂

- 将反向漂移分解为线性部分与非线性剩余部分：

  f_rev(z, t) = A(t)z + b(t) + f_int(z, t)

- 引入**响应场 ẑ(t)**，将二阶 Onsager–Machlup 作用量改写为一阶 MSRJD 泛函积分：

  S_MSRJD[z, ẑ] = ∫dt [ iẑ·(ż − A z − b) + ½g²(t)||ẑ||² ] − i∫dt ẑ·f_int(z, t)

- 这一形式将非线性项推向“相互作用顶点”，开创了**图示微扰理论**：响应传播子 G(t,t′)、噪声诱导关联 C(t,t′) ∝ g²、树级图与单圈图（inter-vertex loop、tadpole）均有清晰的图拓扑。

### 2.3 各生成模型的统一分类

| 模型 | 路径积分角色 |
|---|---|
| NF / CNF | g → 0 的确定性鞍点（经典极限） |
| 扩散模型（DDPM/SM） | 全路径测度下的随机过程，训练对应分数匹配 |
| 条件流匹配（CFM） | 概率流 ODE 评估原则 |
| Schrödinger bridge | 路径空间上的全局 KL 变分（Doob h-变换） |
| VAE | 单潜变量、变分重要性采样（ELBO） |
| GAN | 似然缺失情形下的对抗鞍点（似然-free） |

### 2.4 单圈修正公式（核心创新）

- 围绕经典轨迹 z_cl(t) 展开：z(t) = z_cl(t) + η(t)，得到高斯涨落作用量。
- 协方差满足 **Lyapunov 方程**（沿采样时钟 s = 1−t 传播）：

  −dC/dt = −(A_cl C + C A_clᵀ) + g²(t)I

- 非线性漂移产生的**平均位移（tadpole mean shift）**满足：

  −dδm/dt = −A_cl δm − ½ ∇²f_rev : C

- 可观测量的单圈修正公式为：

  ⟨O[z(0)]⟩ ≈ O[z_cl(0)] + ∂O·δm(0) + ½ ∂∂O : C(0) + O(g⁴)

- 数值验证只需积分**经典轨迹 + 两个辅助 ODE（协方差与平均位移）**，无需随机采样，即可修正确定性采样器的输出。

### 2.5 分数不完美与 EFT 对称设计

- 不完美学习分数 δf = −g²(s_θ − ∇log p) 作为**单点插入项**进入作用量，其树级效应为端点均值偏移，顺带导出**响应加权分数匹配目标**：

  λ_resp(t) ∝ g⁴(t)‖G(0,t)‖²

- 对称等变漂移设计：在 SN × O(m) 对称性下，按标度律 z → λz 赋予算子维度，将漂移组织为度1（线性自由项）与度3（领头相互作用）的**有限算子枚举**，对应 EFT 有效场论功率计数。

## 3. 实验设计

## 6. 主要结论与发现

- **统一性**：NF、CNF、扩散模型、条件流匹配、Schrödinger bridge、VAE、GAN 均可作为同一 Onsager–Machlup 路径积分主作用量下的特殊极限或评估原则，构成了一个分类方案。
- **可微扰性**：MSRJD 形式将非线性概率流系统化为图示微扰展开；树级对应确定性输运、单圈对应有限 g² 的涨落修正。
- **单圈修正有效性**：
  - 自由理论：单圈预测与 SDE 模拟相对偏差低于 0.15%，完全一致。
  - 三次漂移：在 g²=0.8 时把树级 53% 的相对误差降至 1.6%，残差以 O(g⁴) 标度收敛；去掉 tadpole 后标度降为 O(g²)，证明 tadpole 项是单圈阶的必需部分。
  - 24 维等变模型：g²=0.1 时相对误差从 41% 降至 1.1%，强耦合时仍优于树级约 4–6 倍。
- **分数不完美**：得出响应加权分数匹配目标 λ_resp(t)，为损失加权提供第一性原理依据。
- **对称架构设计**：功率计数 + 对称性约束将架构选择转化为有限算子枚举，预测耦合层级（ε = |λ|ℓ²/|a|），可证伪、可测量。

## 7. 优点（亮点）

1. **理论统一的深度与广度**：将七大生成模型类别归入单一作用量，既有分类学意义，又提供了统一的误差与训练目标分析工具。
2. **图微扰框架的物理严格性**：从路径积分到 MSRJD、从传播子到图示展开，再到 Duhamel 公式对插入结构的精确印证，逻辑链完整严谨。
3. **修正公式的实用性与可移植性**：单圈修正只需两个伴随 ODE，与确定性轨迹并行积分即可获得，计算成本 O(d²)，不需要额外随机采样；低秩/对角近似可扩展到高维。
4. **数值验证的严谨性**：三重独立参考（解析 / FP / SDE）、明确的采样误差带、残差标度检验（log–log 斜率 vs 理论 O(g⁴)）、tadpole 项消融实验，均体现较高的可信度。
5. **有效场论类比带来具操作性的设计原则**：等变漂移的“算子枚举 + 层级预测 + 可证伪检验”超越了常见“对称即架构”的叙述，为科学数据的生成建模（如粒子物理喷注）提供了全新设计视角。
6. **Riccati 混合传播方法**：为焦点/散焦区域协方差退化问题提供稳健的数值方案。

## 8. 不足与局限

1. **无真实数据与真实训练验证**：论文未在真实数据集（如图像、粒子物理事件）上训练任何生成网络，“统一框架”在实践层面的收益有待检验；单圈修正与学习分数的竞争关系也未被实证评估。
2. **合成场景范围有限**：仅一维、二维及一个 24 维等变示例；观测对象仅限第二矩，梯度/高阶矩/似然等更丰富可观测量未作检验。
3. **等变 EFT 预测未闭环**：虽然给出了 operator 列表和耦合层级预测（ε），但没有通过拟合实际模型验证 degree-5 算子确实被抑制，即预测未经验证作结。
4. **假设与边界条件较强**：扩散系数 g(t) 为标量性、漂移展开假定低耦合与 ℓ ≪ Λ；对强相互作用、非高斯噪声、乘性噪声情形，框架的扩展性讨论不足。
5. **计算成本缺乏讨论**：对高维 (d 很大) 时全协方差传播的 d² 内存/计算开销，除低秩近似一句带过外没有详细基准测试；Riccati-C 混合切换的数值稳定性也没有进行系统测试。
6. **与现有工作定位的区分度**：与文献 [22]（Hirono et al.）的差异在文中虽已阐明（修正目标为 smooth observable 而非 likelihood），但两套方案的优劣尚无实证对比。
