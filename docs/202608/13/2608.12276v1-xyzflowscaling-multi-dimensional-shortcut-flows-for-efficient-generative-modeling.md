## 摘要
高保真图像生成面临速度与质量之间的权衡。扩散模型产生强大的视觉效果，但需要昂贵的迭代采样。现有的高效方法主要将预训练模型蒸馏为少步采样器，这是一个依赖于教师模型质量的具有挑战性的过程。在本文中，我们介绍了XYZFlow，一个通过流匹配的多维扩展重新思考高效生成的框架。与单步映射不同，XYZFlow通过结构化多维条件使概率路径更可识别和可学习，从而增强表达性。我们将自回归建模视为隐式流拉直，其中更丰富的上下文减少了轨迹模糊性。XYZFlow通过两个正交维度实现这一思想：时间扩展，利用对完整去噪历史的非马尔可夫条件化；以及空间扩展，通过下一捷径预测实现，该预测使用先前补丁的去噪轨迹作为先验来顺序生成补丁。实验表明，XYZFlow实现了最先进的性能，具有7.2-8.5倍的教师加速和竞争力的FID，而下一捷径预测在质量-延迟权衡上优于模型扩展或步骤减少。

## Abstract
High-fidelity image generation faces a trade-off between speed and quality. Diffusion models produce strong visuals but require costly iterative sampling. Existing efficient methods mainly distill pretrained models into few-step samplers, a challenging process that depends heavily on teacher-model quality. In this paper, we introduce XYZFlow, a framework that rethinks efficient generation through multidimensional scaling of flow matching. Unlike single-step mappings, XYZFlow enhances expressivity by making probability paths more identifiable and learnable through structured multidimensional conditioning. We view autoregressive modeling as implicit flow straightening, where richer context reduces trajectory ambiguity. XYZFlow realizes this idea through two orthogonal dimensions: temporal scaling, which uses non-Markovian conditioning on the full denoising history; and spatial scaling, enabled by Next Shortcut Prediction, which sequentially generates patches using preceding patches' denoising trajectories as priors. Experiments show that XYZFlow achieves state-of-the-art performance, with 7.2-8.5X teacher speedups and competitive FID, while Next Shortcut Prediction delivers superior quality-latency trade-offs over model scaling or step reduction.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 总体框架

XYZFlow以**多维条件化**为核心，沿两个正交维度扩展流的表达力：

### 2.2 时间扩展（Temporal Scaling）：非马尔可夫轨迹条件化

- 每个去噪步骤的预测都**基于该补丁自身的完整去噪历史**，而非仅当前状态，将去噪过程从马尔可夫转为非马尔可夫。
- 历史的键值缓存（KV cache）作为条件锚点，提供稳定的时间坐标系，帮助拉直生成路径。
- 时间条件化损失为：

  **L^p_temp = E[ || v_θ(x^p_t | t, H^p_t) − (x^p_1 − x^p_0) ||² ]**

  其中 H^p_t = {x^p_τ}^{t−ΔT}_{τ=0} 为补丁 p 截至时间 t 的历史轨迹。

### 2.3 空间扩展（Spatial Scaling）：Next Shortcut Prediction

- 将图像划分为 m×m 网格（如2×2、4×4），以**补丁为单元**顺序生成。
- 关键创新：后续补丁不仅依赖前序补丁的**最终输出**，更依赖其**完整去噪轨迹**：

  **p(x_p | x_1,...,x_{p−1}) = p(x_p | T_{<p})**

  其中 T_{<p} = {τ₁, τ₂, ..., τ_{p−1}}，τᵢ = {x^i_t}¹_{t=0} 为前序补丁的完整轨迹。每个轨迹提供多个时间锚点，显著缩小求解空间，使逆向过程更确定性。

- **渐进式去噪步数分配**：越后面的补丁需要的去噪步数越少（即"捷径"）：

  **T(p) = T_full − ΔT·(p−1)**，约束 T(p) ≥ T_min > 0。

- 生成过程的单步更新定义为：

  **x^p_{t−1} = G(x^p_{T(p):t}, T_{<p}, t) = x^p_t + (γ(t−1) − γ(t))·v_θ(x^p_{T(p):t}, t, T_{<p})**

  其中 γ 为噪声调度，v_θ 为学生网络（教师轨迹蒸馏）。

### 2.4 训练目标

- 核心目标函数为**Next Shortcut Prediction Loss**：

  **L_NextShortcut = Σ^{T(p)}_{t=1} || G_θ(x^p_{T(p):t}, t, T_{<p}) − x^p_{t−1} ||²**

  即回归教师模型轨迹上每一步的真实目标样本。

- 模型采用Transformer架构，配合**分块因果注意力掩码（block-wise causal attention mask）**，使模型可同时利用完整轨迹历史与空间上下文。
- 可选引入**判别器损失**（GAN），作用于最终生成的补丁，进一步提升高频细节质量。

### 2.5 推理过程

- 第一个补丁使用全部步数预算 T(1)=T_full 生成，建立可靠锚点。
- 后续每个补丁从 x^p_{T(p)} 出发，自回归地逐步预测，利用KV cache高效管理历史信息，显著减少总推理步数。

- **与其他蒸馏范式结合**：如与一致性蒸馏、对抗蒸馏结合，能否进一步压缩步数至1–2步；
- **自动化超参搜索**：细胞大小、步数调度是否可通过可学习方式自动确定，而非人工设定；
- **更高效的轨迹存储**：探索在线蒸馏或压缩轨迹表示，降低预计算开销，使训练流程更加实用。
