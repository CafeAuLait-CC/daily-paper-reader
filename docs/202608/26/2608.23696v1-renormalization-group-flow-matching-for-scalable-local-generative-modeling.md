## 摘要
尽管生成模型在建模复杂数据方面取得了显著成功，但它们面临着一个根本性的权衡。全局方法能够捕捉完整的结构连贯性，但计算成本高昂，而局部模型虽然高效，却常常无法再现长程相关性和全局连贯性。重正化群（RG）通过无缝连接不同长度尺度上的空间结构弥补了这一差距，在每一步保留准局部描述的同时，保持长程相关性。我们引入了重正化群流匹配（RGFM），这是一个在不同空间尺度上系统化组织数据生成的生成框架。通过使用精确的RG流作为概率路径，RGFM从长波长结构逐步生成到短波长结构。为了兼顾可扩展性与全局结构，我们利用了RG的两个关键性质：准局部性和尺度分离。我们严格证明了RGFM概率流可以通过作用在空间范围$O(Λ^{-1}[\ln L+\ln(1/\varepsilon)])$内的局部速度场来精确近似，其中$Λ$为RG波数尺度，$L$为线性系统尺寸，$\varepsilon$为指定的误差容限。这一性质使得使用大小为$O(\ln L)$的块进行局部生成建模成为可能，且计算成本随系统体积近似线性增长。我们通过数值实验证明，在代表性的一维分布中，局部RGFM能够再现远超其感受野的长程相关性，而传统的局部流匹配在长距离上表现出显著误差。在FFHQ图像上，RGFM在64x64和256x256分辨率下生成的样本比局部流匹配更连贯、质量更高。我们的结果确立了RG引导的概率流作为一条有前景的路径，用于仅通过局部计算捕捉长程结构的可扩展生成建模。

## Abstract
Despite their remarkable success in modeling complex data, generative models face a fundamental tradeoff. Global approaches can capture full structural coherence but suffer from high computational costs, while local models are efficient but often fail to reproduce long-range correlations and global coherence. The renormalization group (RG) bridges this gap by seamlessly connecting spatial structures across different length scales, retaining quasi-local descriptions at each step while preserving long-range correlations. We introduce renormalization group flow matching (RGFM), a generative framework that systematically structures data generation across different spatial scales. By using an exact RG flow as the probability path, RGFM progressively generates data from long- to short-wavelength structures. To reconcile scalability with global structure, we exploit two key properties of the RG: quasi-locality and scale separation. We rigorously show that the RGFM probability flow can be accurately approximated by local velocity fields acting over a spatial range $O(Λ^{-1}[\ln L+\ln(1/\varepsilon)])$ for RG wavenumber scale $Λ$, linear system size $L$, and prescribed error tolerance $\varepsilon$. This property enables local generative modeling with patches of size $O(\ln L)$ and a computational cost that scales nearly linearly with the system volume. We numerically demonstrate that local RGFM reproduces long-range correlations far beyond its receptive field in representative one-dimensional distributions, while conventional local flow matching exhibits substantial errors at long distances. On FFHQ images, RGFM yields far more coherent and higher-quality samples than local flow matching at 64x64 and 256x256. Our results establish RG-guided probability flows as a promising route toward scalable generative modeling that captures long-range structure using only local computation.

## 一、论文的核心问题与整体含义

- 生成模型面临一个核心**权衡**：
  - **全局建模**（如全局注意力 diffusion/flow）能保持长程一致性和全局结构，但计算复杂度通常随数据维度二次增长，难以扩展到高分辨率图像或大规模物理系统。
  - **局部建模**（如 patch-based）计算效率高、训练内存小，但仅依赖固定感受野，难以协调远距离区域，导致长程相关性丢失和全局结构不连贯。
- 作者认为这一问题的本质是**跨尺度连接困难**，并借用统计物理中的**重正化群（RG）**思想：
  - RG 在微观与宏观描述之间建立了系统化的桥梁，能逐级粗粒化短距离自由度，同时保留剩余长程结构的信息。
  - RG 具备两个关键性质：**尺度分离**（scale separation）和**准局部性**（quasi-locality），恰好可用于设计一种“低波数→高波数”渐进生成的概率路径。
- 论文提出 **RGFM（Renormalization Group Flow Matching）**，将精确 RG 流作为 flow matching 的概率路径，从而在**仅用局部计算**的前提下生成具有长程相关性的高维数据，兼顾可扩展性与全局连贯性。

## 二、方法论：核心思想与关键技术

### 1. 核心思想
- 将数据看作空间上的场配置（如 RGB 图像是像素格子上的三维场）。
- 沿 RG 流，从高波数到低波数逐步将非高斯自由度转化为高斯噪声；反向生成时则从长波（大尺度）结构出发，逐级补充短波细节。
- 利用 RG 的**准局部性**：在运行尺度 $Λ(t)$ 下，速度场/概率流的有效相互作用集中在 $O(Λ^{-1})$ 范围内。
- 通过**位点抽稀（site decimation）** 变换，将剩余低波数模式映射到更粗格点上，使“得分/速度场的局部长度”始终保持 $O(L^0)$，从而可用固定尺寸的局部 patch 进行建模。

### 2. 技术细节
- 采用 **Polchinski 精确 RG** 构造概率路径 $p_t(\phi)\propto e^{-S_{\Lambda(t)}(\phi)}$，并用热核型 RG 截断函数 $K_\Lambda(k)=e^{-(k^2+m^2)/\Lambda^2}$。
- 定义 **RG 扩散**：
  $$p_t(\phi|\phi_0)=\prod_k \mathcal{N}(\phi_k; \sqrt{\bar\alpha_{tk}}\phi_{0k},\, \bar\beta_{tk}),$$
  其中 $\bar\alpha_{tk}=K_{tk}$，$\bar\beta_{tk}=G_0(k)(1-K_{tk})$。
- 对应条件速度场（式 28）：
  $$u_{tk}(\phi|\phi_0)= -\frac{\partial_t K_{tk}}{2(1-K_{tk})}\left(\phi_k-\sqrt{K_{tk}}\phi_{0k}\right)+\frac{\partial_t K_{tk}}{2\sqrt{K_{tk}}}\phi_{0k}.$$
- 通过学习局部速度场 $v_{\mathrm{loc},\theta}$ 来最小化局部 flow matching 损失（式 33）：
  $$\mathcal{L}^{\mathrm{loc}}_{\mathrm{RGFM}}(\theta)= \mathbb{E}_{t,\phi_0,\phi_t}\left[\sum_i \left\| v^{A_i}_{\mathrm{loc},\theta}\big((eR_t\phi)_{A_iB_i},t\big) - (eR_t u_t(\phi|\phi_0))_{A_i}\right\|^2_{A_i}\right].$$
  - 这里 $eR_t$ 是分段常数的位点抽稀变换，$A_i$ 为目标 patch，$B_i$ 为 buffer region。
- 采样过程：从高斯分布采样 → 在局部 ODE 上反向积分 → 在粗格点间“随机提升”（从高斯扇区采样被丢弃的高波数模式）→ 重复直到 $t=0$。

### 3. 理论保证
- 在**局部分布**（如 Ising 模型、近邻相互作用）和**条件局部分布**（全局结构由潜变量调制，给定潜变量后条件分布局部）两类数据分布假设下，证明了曲率/作用量的指数准局部性可沿 RG 流保持。
- 核心定理（非正式）：
  - **局部性定理**：为达到误差容限 $\varepsilon$，所需 patch 的 buffer 宽度为
    $$l_{B,t}=O\left(\Lambda(t)^{-1}\left[\ln L+\ln(1/\varepsilon)\right]\right),$$
    由此二维 Wasserstein 距离满足 $W_2(p_{\rm data}, p^{\rm loc}_{\rm data})\le\varepsilon$。
  - 这保证了局部 RGFM 的计算复杂度可达到**近似线性**（仅含 polylog 因子），相对全局模型的 $O(D^2)$ 显著降低。

## 三、实验设计

### 1. 一维局部分布：Ising 模型
- 数据分布：$p_{\rm Ising}(\phi)\propto e^{K\sum_x \phi_x\phi_{x+1}}$，$\phi_x\in\{\pm1\}$，$L=1024$。
- 取相关长度 $l_{\rm corr}=32,64,128,256$ 四组。
- 网络：6 层卷积核大小为 5 的 CNN，感受野 25 个格点（$l_A=1$, $l_B=12$）。
- 对比方法：在相同 CNN 架构与相同感受野下训练**标准 flow matching（FM）**。
- 评估：生成样本的密度分布、相关函数 $C(r)=\langle\phi_x\phi_{x+r}\rangle$ 与 Ising 精确解的对比。

### 2. 一维条件局部分布
- 数据：$p_{\rm cond}(\phi)=\int dz\, p(\phi|z)p(z)$，给定潜变量 $z=(a_m,\eta_m)$ 后，$\phi_x\sim\mathcal{N}(f_z(x),\sigma^2)$ 是独立的局部高斯；边际分布显示出**不衰减振荡的长程相关**。
- $L=1024$, $\sigma=0.05$，使用与 Ising 实验相同的 CNN 与感受野。
- 对比：同样结构的 local FM。
- 评估：生成配置形态与理论相关函数 $C(r)$。

### 3. 图像生成：FFHQ
- **64×64**：
  - 目标 patch 大小 $l_A=16$，感受野 patch 大小 $l_A+2l_B=32,48,64$ 三档。
  - 使用 U-Net（带自注意力、坐标通道），对比 local FM。
  - 主要指标：FID（50,000 张生成图，clean-FID 预处理），另附定性样本。
- **256×256**：
  - 使用 FFHQ 前 5,000 张图，$l_A=16$、感受野 32。
  - 对比 local FM，评估样本全局连贯性（定性为主），**未报告 FID**。

### 4. 对比与公平性
- 所有对比中，RGFM 与 FM 使用**相同网络架构、相同 patch 尺寸、相同训练/采样步数**，仅改变概率路径构造方式。
- 1D 实验中，FM 仅在原网格上训练，而 RGFM 按 RG 层次在逐级抽稀的格点上训练（这是 RGFM 方法本身的组成部分）。

## 六、主要结论与发现

1. **局部 RGFM 能超越感受野捕捉长程相关**：
   - 在 Ising 模型中，即使 CNN 感受野只有 25 个格点，RGFM 仍还原了相关长度 $l_{\rm corr}\le256$ 的指数衰减相关函数；而 local FM 在超过感受野的距离上明显偏离真实值。
2. **潜变量调制的全局结构也能局部重建**：
   - 条件局部分布实验显示，RGFM 可以同时恢复平滑的全局波形和局部高斯涨落，并正确复现不衰减的振荡相关函数；local FM 则失败。
3. **图像生成上的显著提升**：
   - 64×64 FFHQ 上，local RGFM 的 FID 在 32/48/64 三种 patch 尺寸下均显著低于 local FM，且在较小 patch 下性能退化很小（鲁棒性符合理论预测）。
   - 256×256 上，RGFM 仍比 local FM 生成的作品明显更连贯；但仍有跨区域脸部组件（如两只眼睛）不一致的问题。
4. **理论贡献**：严格证明了在合理物性假设下，RGFM 概率流可用 $O(\Lambda^{-1}\ln L)$ 的局部 patch 以任意精度近似，计算复杂度近线性，为“以小搏大”的生成建模提供了理论根据。

## 七、优点

- **理论深度**：将物理学中成熟的 RG 思想引入生成模型，并用严格的数学定理（局部误差指数衰减、Wasserstein 稳定性界限）支撑方法，而不仅是启发式。
- **新颖性**：将 RG 作为“概率路径的设计原则”，直接构造可局部近似的 flow，与现有多尺度扩散/流模型的“经验式级联”不同。
- **可扩展性**：通过 site decimation 保持局部长度不随系统尺寸增长，使训练/生成的计算/内存成本近似线性，这对高分辨率和物理大系统很有吸引力。
- **实验一致性好**：理论研究与数值现象（长程相关恢复、patch 尺寸鲁棒性）吻合，增强了结论可信度。
- **结果具有实用性**：在 FFHQ 上即使只用局部 patch 也得到接近全局一致性的结果，且明显优于同限制下的局部 FM。

## 八、不足与局限

- **假设较强**：
  - 理论要求数据动作（或条件动作）严格局部或“条件局部 + 潜变量局部可预测”；真实场景中的非局部效应（如长程交互、非平衡集体效应）可能不满足指数准局部性。
  - RG 局部性假设（Assumption IV.3）虽物理上合理，但并未被数学上完全证明（文中引用的是已有部分结果）。
- **高分辨率性能仍有限**：
  - 256×256 下 RGFM 仍有跨区域不一致，说明对于高层语义属性（姿态、身份、光照），固定大小局部 patch 中信息不足，潜变量局部可预测假设在该尺度偏弱。
- **实验覆盖不足**：
  - 缺乏 256×256 的 FID 等定量指标；没有更复杂数据集上的验证。
  - 没有做消融实验，无法完全分清“RG 尺度逐级结构”和“概率路径局部性”各自对效果的贡献。
- **计算成本并非完全免费**：
  - 1D 实验仍需约 3 小时，64×64 需约 3 天，256×256 需 6 天（虽然都比全局模型省很多，但仍不便宜）。
  - 逐步抽稀要求在多个尺度和时间区间分别训练模型副本/分段，调度和超参数选择较繁琐。
- **可能的应用局限**：
  - 对非局部、非条件局部系统（如长程作用模型、某些物理系统）的适用性需进一步验证。
  - 离散数据（如 Ising spins）要通过嵌入连续空间处理，某些严格离散结构可能受影响。
