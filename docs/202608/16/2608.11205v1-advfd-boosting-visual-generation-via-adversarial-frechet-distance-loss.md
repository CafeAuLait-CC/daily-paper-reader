## 摘要
弗里歇距离最近已成为生成器后训练中一种有效的分布级目标，补充了传统的样本级扩散和流匹配损失。然而，直接优化弗里歇目标可能导致弗里歇黑客攻击。目标指标持续改善，但视觉质量和其他特征空间中的弗里歇对齐可能停滞或恶化。我们将这种失败归因于现有弗里歇损失所使用的静态预训练特征空间。这些特征空间提供了真实分布与生成分布之间不完整且固定的视角。为解决这一局限，我们提出了对抗式弗里歇距离（AdvFD），通过校准的对抗学习表示来补充FD-Loss中的静态表示目标。AdvFD用可学习的表示增强原始静态弗里歇目标，该表示对抗性地最大化真实样本与生成样本之间的弗里歇差异，而生成器在所得自适应特征空间中最小化相同差异。为防止对抗表示通过特征放大平凡地增加目标，我们进一步引入真实特征白化，以归一化其尺度和协方差几何，并稳定最小-最大优化。大量实验表明，AdvFD在JiT和pMF骨干网络以及不同模型规模上均持续改善一步生成器后训练。

## Abstract
Fréchet distance has recently emerged as an effective distribution-level objective for generator post-training, complementing the conventional sample-level diffusion and flow-matching losses. However, directly optimizing Fréchet objectives can cause Fréchet hacking. The target metrics keep improving, but visual quality and Fréchet alignment in other feature spaces may stagnate or deteriorate. We attribute this failure to the static pretrained feature spaces used by existing Fréchet losses. These feature spaces provide incomplete and fixed views of the differences between real and generated distributions. To address this limitation, we propose Adversarial Fréchet Distance (AdvFD), which complements the static representation targets in FD-Loss with a calibrated adversarially learned representation. AdvFD augments the original static Fréchet objective with a learnable representation that adversarially maximizes the Fréchet discrepancy between real and generated samples, while the generator minimizes the same discrepancy in the resulting adaptive feature space. To prevent the adversarial representation from trivially increasing the objective through feature amplification, we further introduce real-feature whitening, which normalizes its scale and covariance geometry and stabilizes the min--max optimization. Extensive experiments show that AdvFD consistently improves one-step generator post-training across both JiT and pMF backbones and across different model scales.

### 1. 核心问题与研究动机

- **背景**: 在视觉生成领域，扩散模型和流匹配模型主要依赖样本级损失（如预测噪声或速度）进行训练。最近提出的 FD-Loss 引入了一种分布级匹配目标，通过最小化真实与生成图像在预训练编码器（如 Inception、SigLIP、MAE）特征空间中的 Fréchet 距离，来提升生成器（尤其是单步生成器）的后期训练效果。
- **核心问题（Fréchet Hacking）**：论文识别出直接优化静态 Fréchet 目标会导致严重的 **Fréchet hacking** 现象。即，**被优化的目标指标（如 FD-r-Inception）持续改善，但视觉质量和其他未被优化的特征空间（如 FD-r-CLIP）中的对齐程度却停滞甚至恶化**。例如，在训练后期，FD-r-Inception 指标下降 29.4%，而 FD-r-CLIP 指标反而上升了 8.5%。
- **问题根源**：作者将这一失败归因于 **静态预训练特征空间的局限性**。这些特征空间为真实与生成分布之间的差异提供了**不完整且固定**的视角。生成器会过度适配这些固定的比较空间，而该空间未能捕捉到的误差（如高频伪影、结构畸变）则得不到有效惩罚，导致视觉质量退化。作者通过实验证明，仅通过优化 Inception FID 就能学习到一种通用扰动，在显著降低 FID 分数（从 3.31 降至 2.56）的同时引入明显的可见伪影，直接证实了静态表示的“盲区”问题。

### 2. 方法论：Adversarial Fréchet Distance (AdvFD)

- **核心思想**：为了解决静态特征空间的问题，AdvFD 在原有静态 Fréchet 目标的基础上，引入一个**可学习的对抗性表示网络**。该网络被训练为**最大化**真实与生成样本之间的 Fréchet 差异，以持续暴露静态表示忽略的残余分布不匹配；而生成器则被训练为在**这个动态演变的特征空间**中**最小化**同一个 Fréchet 差异。这与 GAN 的 min-max 博弈类似，但发生在特征空间层面。
- **算法流程（交替更新）**：
    1.  **G-step（更新生成器）**：冻结静态表示和对抗性表示，仅通过生成样本传播梯度，更新生成器参数 θ。其目标函数为 `L(θ) = D_static(p, q_θ) + λ_adv * D_adv(p, q_θ; ω_t)`，其中 `D_static` 是多个冻结编码器的 Fréchet 距离加权和，`D_adv` 是当前对抗性表示下的 Fréchet 距离。
    2.  **D-step（更新对抗性表示）**：冻结生成器并截断其梯度，通过梯度上升更新对抗性表示网络参数 ω，以最大化 Fréchet 差异。为了保持优化稳定，对梯度进行了范数裁剪：`ω_{t+1} = ω_t + η_D * clip_τ(g_t)`，这可以解释为一个局部有界响应，防止表示发生剧烈跳变。
- **关键技术：真实特征白化 (Real-Feature Whitening)**：
    - **动机**：直接最大化原始 Fréchet 距离存在一个平凡解：对抗性网络可以通过**全局放大特征范数**来任意增大距离（因为 `D(cψ) = c²D(ψ)`），而不学习任何有意义的差异。这导致优化不稳定和模式崩溃。
    - **方法**：为了解决这个问题，引入了基于真实数据统计的白化操作。具体为 `ψ̄_ω(x) = (ψ_ω(x) - μ_p^ψ) (Σ_p^ψ + εI)^(-1/2)`，其中 `μ_p^ψ` 和 `Σ_p^ψ` 是真实样本特征的均值和协方差。
    - **效果**：该操作将真实特征归一化为零均值和单位协方差，使得对抗性表示在仿射变换下（如缩放）不会改变最终计算的距离。这消除了特征缩放的退化方向，迫使网络必须寻找真实的分布差异来增加距离，从而显著稳定了 min-max 优化过程。论文在附录中证明了该操作的仿射不变性。
- **与 GAN 的关系**：论文在理论层面将 AdvFD 与 WGAN 进行了区分。WGAN 是在**固定的传输几何（即样本空间）**中学习一个标量判别器（传输势能），而 AdvFD 则是学习一个**可变的特征几何**（即样本在新空间中的位置），并使用一个**固定的高斯传输函数（W₂ 距离）**来比较这些特征分布。

### 6. 主要结论与发现

- AdvFD 能够有效缓解静态 Fréchet 优化中的 **Fréchet hacking** 问题，在保持单步采样成本不变的情况下，显著提升生成质量。

- 真实特征白化是实现稳定对抗训练的关键组件，它能有效防止对抗表示通过简单的特征缩放来欺骗目标。
