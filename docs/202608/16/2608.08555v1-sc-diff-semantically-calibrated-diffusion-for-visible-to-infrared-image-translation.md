## 摘要
可见光到红外图像翻译为利用丰富的可见光图像扩展红外训练数据提供了一种实用途径。扩散模型因其强大的生成性能而在此任务中具有前景。然而，现有的基于扩散的方法通常仅将语义先验用作外部条件，未明确调控去噪网络内的token交互。因此，它们难以保留可靠标注复用所需的目标位置、形状和语义布局。我们提出SC-Diff，一种语义校准的潜在扩散框架，将语义先验同时用于条件引导和内部自注意力校准。预训练的SAM3模型结合预定义文本提示首先从可见光图像中提取类别特定的语义掩码。这些掩码被合并为语义图，并与可见光图像融合作为输入条件。同一张语义图被转换为token级语义标签，用于校准去噪网络中的自注意力。基于这些标签，我们引入语义引导的自注意力校准（SGSC），它对同类别查询-键对自适应地施加正偏置。查询级校准强度取决于注意力在语义类别间的分散程度以及分配给查询自身类别的注意力。原始注意力分数进一步调节偏置，为响应更强的同类别键提供更大的校准。这种软校准在保留全局上下文交互的同时减少跨类别干扰，从而提升生成红外图像的语义一致性。大量实验表明，SC-Diff提高了感知质量，并为下游红外目标检测生成更有效的合成训练数据。

## Abstract
Visible-to-infrared image translation provides a practical way to expand infrared training data using abundant visible images. Diffusion models are promising for this task because of their strong generative performance. However, existing diffusion-based methods typically use semantic priors only as external conditions, without explicitly regulating token interactions within the denoising network. Consequently, they struggle to preserve object locations, shapes, and semantic layouts required for reliable annotation reuse. We propose SC-Diff, a semantically calibrated latent diffusion framework that uses semantic priors for both conditional guidance and internal self-attention calibration. A pretrained SAM3 model with predefined text prompts first extracts category-specific semantic masks from visible images. These masks are merged into a semantic map and fused with the visible image as the input condition. The same map is converted into token-level semantic labels to calibrate self-attention in the denoising network. Based on these labels, we introduce Semantic-Guided Self-Attention Calibration (SGSC), which adaptively applies positive biases to query-key pairs of the same category. The query-wise calibration strength depends on the dispersion of attention across semantic categories and the attention assigned to the query's own category. The original attention scores further modulate the bias, giving greater calibration to same-category keys with stronger responses. This soft calibration reduces cross-category interference while retaining global contextual interactions, thereby improving semantic consistency in generated infrared images. Extensive experiments show that SC-Diff improves perceptual quality and produces more effective synthetic training data for downstream infrared object detection.

## 2. 论文提出的方法论

**核心思想：**
将语义先验从“仅外部条件”提升为“内外兼修”——既作为条件编码的输入，又作为去噪过程中自注意力交互的内部校准信号，减少跨类别干扰，保留全局上下文。

**框架结构（SC-Diff）：**

1. **语义掩码生成**
   - 使用预训练的 SAM3 模型，配合预定义文本提示（如 person、car、tree、road 等 17 类城市场景常见类别），从可见光图像中提取类别特定的语义掩码。
   - 多掩码重叠时依据预测置信度消解冲突，得到非重叠语义标签图 Y，其中每个像素至多属于一个类别，0 表示未标注区域。

2. **条件编码（Clean Condition Encoding, CCE）**
   - 将可见光图像和语义图分别编码到潜在空间：z_vis = E(x_vis)，z_seg = E(x_seg)。
   - 通过 1×1 卷积投影后相加融合：f_con = Conv1×1(z_vis) + Conv1×1(z_seg)。
   - 条件编码器从融合条件中提取多尺度引导特征 y_con，注入 U-Net 各层。
   - 关键设计：条件从干净的输入提取，不与被噪声污染的目标潜在变量混合，避免噪声泄漏。

3. **Semantic-Guided Self-Attention Calibration（SGSC）**
   - 将语义标签图缩放到当前注意力层分辨率，转换为 token 级语义标签。
   - **两阶段软校准策略：**
     - **第一阶段——自适应正偏置计算：** 对每个查询 token，聚合其分配到各语义类别的注意力权重（排除未标注 token）；计算语义类别注意力熵 H；结合查询自身类别注意力占比，得到校准强度 β = H × (1 − P_own)。注意力分散且自身类别注意力不足时，校准更强；注意力集中时抑制校准，避免破坏有价值的上下文依赖。
     - **第二阶段——原始注意力调制：** 构建同类别指示矩阵 M（仅同类别且非零标签的 query-key 对为 1）；用原始注意力权重对偏置进行归一化调制 G，使得原本响应更强的同类别 key 获得更大的偏置增量；最终校准后的注意力为：
       - Ã_ij = exp(S_ij + λβ_i G_ij) / Σ_r exp(S_ir + λβ_i G_ir)，其中 λ 设为 10。

4. **模型推断**
   - 采用 DDIM 采样器加速（30 步），σ_t = 0 时为确定性采样。
   - 使用渐进式 classifier-free guidance（CFG）：噪声估计 = ϵ_∅ + c_v(ϵ_v − ϵ_∅) + c_s(ϵ_{v,m} − ϵ_v)，其中 c_v 和 c_s 分别为可见光条件与语义条件的引导尺度。

## 6. 论文的主要结论与发现

1. **语义先验双通道注入有效：** 将语义先验同时用作外部条件和内部自注意力校准（SC-Diff），比仅作为外部条件的方法（如 F-ViTA、DiffV2IR、PID）生成更高质量的可见光-红外翻译图像。

2. **感知质量全面领先：** 在三个数据集上，SC-Diff 在 LPIPS 和 FID 上均为最优，说明生成的图像在感知相似度和分布匹配方面更接近真实红外图像。虽然 PID 在 KAIST 上 PSNR/SSIM 略高，但其 LPIPS/FID 较差，说明像素级指标不完全反映感知质量。

3. **分布外泛化能力更强：** 在 Cityscapes 的三种风格翻译中，SC-Diff 均取得最低 FID，表明其在未见场景下能更好地传递目标红外风格并保持场景结构。

4. **为下游检测提供更有效的数据增强：** 在 M3FD 上整体 mAP 从 Vanilla 的 22.1 提升至 26.0（+3.9）；在 FLIR 上从 36.0 提升至 37.6（+1.6），均优于 PID 和 F-ViTA。定性检测结果也显示 SC-Diff 增强后的检测器漏检更少、定位更完整。

5. **SGSC 机制的作用机制得到验证：** 通过自注意力可视化，SGSC 减少了跨类别注意力泄漏，使注意力更集中于同类别区域，同时保留全局上下文交互；推断过程中 SC-Diff 在早期就能明确物体边界，而非完全依赖后期精修。

## 7. 优点

1. **思路新颖且定位精准：** 精准识别了现有扩散方法在可见光-红外翻译中的关键缺陷（语义先验仅作外部条件、内部 token 交互无语义约束），并提出了针对性的解决方案。

2. **“一图两用”的高效设计：** 同一张语义图既作为外部条件融合输入，又转换为 token 级标签校准内部注意力，无需额外的标注成本，设计简洁而有效。

3. **软校准保留全局上下文：** SGSC 不是硬性屏蔽跨类别注意力，而是通过熵感知的自适应偏置和原始注意力权重调制，在减少跨类别干扰的同时保留有用的全局上下文依赖，避免了过度约束。

4. **条件编码干净利落：** 条件从干净的外部输入提取，不与噪声目标潜在变量混合，避免了噪声泄漏，通过消融实验验证了这一设计的必要性。

5. **实验体系完善：** 域内生成、分布外生成、下游检测三联实验覆盖了生成质量和实用价值两个层面；多检测器验证增加了结论的普适性。

6. **定性分析深入：** 不仅展示生成图像对比，还提供了自注意力图可视化和推断中间过程可视化，从机制层面解释了方法为何有效。

## 8. 不足与局限

1. **依赖 SAM3 的语义提取能力：** 方法的质量上限受限于 SAM3 在可见光图像上的分割精度。若 SAM3 在特殊场景（极端光照、遮挡严重）下分割失败，语义标签的可靠性下降，校准效果将受影响。论文未讨论 SAM3 分割失败时的鲁棒性。

2. **类别集合固定且有限：** 使用预定义的 17 个城市场景类别提示词，对非城市场景（如野外、空中、水下）或类别超出提示集的目标（如动物、船只）无法进行有效校准，限制了方法的适用场景。

3. **计算资源需求较高：** 训练需要 3 块 A6000 GPU、400 epochs，未报告训练时间，难以评估训练成本。推理虽用 30 步 DDIM，但仍需多次 U-Net 前向传播，相比 GAN 类方法推理开销更大。

4. **像素级保真度未全面领先：** 在 KAIST 上 PSNR/SSIM 低于 PID，说明 SC-Diff 更侧重感知质量而非像素对齐。对于需要严格像素对齐的应用（如逐像素标注复用），可能存在局限。

5. **检测提升幅度有限且未报告统计显著性：** 在 FLIR 上，SC-Diff 相对于 Vanilla 仅提升 1.6 个 mAP 点，且未报告多次试验的方差或显著性检验，无法判断提升是否稳定可靠。

6. **消融实验覆盖不完整：** 主要消融仅在 FLIR 上报告，M3FD 和 KAIST 上的消融结果未展示；CFG 参数搜索也仅在 FLIR 上进行，不同数据集间最优超参数可能不同。

7. **标注继承的可靠性未直接验证：** 论文声称 SC-Diff 使可见光图像继承的标注更可靠，但未直接比较生成图像与其对应的真实红外图像在标注一致性上的差异（如检测标注的 mAP 与真实红外上检测的差距）。

8. **比较公平性存在潜在偏差：** 部分对比方法的指标引用自其他论文（标注 †），而非在完全一致的评估流程下复现，存在评估管线差异的风险。
