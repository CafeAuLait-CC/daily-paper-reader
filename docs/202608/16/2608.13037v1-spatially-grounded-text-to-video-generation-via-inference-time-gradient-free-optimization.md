## 摘要
扩散变压器文本到视频模型在合成质量上取得了显著成果，但细粒度的空间可控性仍然是一个重大挑战。尽管现有的免训练方法在空间接地生成（即在指定位置放置特定物体）中能够产生稳健的整体结果，但它们依赖基于梯度的优化技术，导致计算开销过大，这一瓶颈在现代化大规模架构中被进一步放大。为解决这一局限性，我们提出了无梯度解析轨迹优化视频生成（GATO-Vid），一种新颖的免训练且免梯度的精确空间引导方法。我们不再依赖昂贵的反向传播，而是引入了一种替代的交叉注意力分数，并通过解析求解获得精确的闭式解。为利用我们的解析解，我们提出了一种针对变压器潜在空间拓扑流形量身定制的即时注入机制。实验表明，GATO-Vid在定位精度上显著优于现有基线，同时引入的计算开销极小。

## Abstract
Diffusion Transformer Text-to-Video models have achieved remarkable synthesis quality, yet fine-grained spatial controllability remains a significant challenge. While existing training-free methods produce solid overall results in spatially grounded generation, \ie, placing a specific object in a designated location, they rely on gradient-based optimization techniques that incur prohibitive computational overhead, a bottleneck amplified in modern large-scale architectures. To address this limitation, we present Gradient-free Analytical Trajectory Optimization Video Generation (GATO-Vid), a novel training-free and gradient-free approach for precise spatial guidance. Rather than relying on costly backward passes, we introduce an alternative cross-attention score and solve it analytically to obtain an exact, closed-form solution. To use our analytical solution, we propose an on-the-fly injection mechanism tailored to the topological manifold of the transformer's latent space. Our experiments demonstrate that GATO-Vid significantly outperforms existing baselines in localization accuracy while introducing minimal computational overhead.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：扩散Transformer（DiT）架构的文本到视频（T2V）生成模型（如CogVideoX、Wan2.2等）已能生成高质量、逼真的视频，但**纯文本提示无法精确控制物体的空间位置**。
- **核心问题**：如何在推理阶段实现“空间接地”（spatially grounded）的视频生成，即根据文本提示和空间约束（如边界框）在指定位置生成指定物体，同时**避免梯度优化带来的巨大计算开销**。
- **现有方法的局限**：
  - **训练类方法**：需要大量标注数据和GPU资源，成本高昂。
  - **基于梯度的免训练方法**：通过反向传播优化交叉注意力图，虽效果好，但在现代DiT架构上计算开销惊人——单次反向传播在Wan2.2上需要额外26GB VRAM，使推理时间增加约300%，普通消费级GPU（<32GB显存）无法运行。
  - **现有的免梯度方法**（如Peekaboo、VideoTetris、SwitchCraft）：虽避免了反向传播，但在DiT架构上空间控制效果较弱或不可靠，且多数仅适用于旧的3D-UNet架构。
- **研究意义**：该工作填补了“免训练+免梯度”在DiT架构上精确空间控制的空白，为计算资源有限的用户提供了一种可行的空间可控视频生成方案。

## 2. 方法论：GATO-Vid

### 2.1 核心思想
将交叉注意力定位问题重新构造为**一个可解析求解的替代目标函数**，在完全不计算注意力图、不进行反向传播的前提下，推导出**闭式最优解（closed-form solution）**，并通过查询（query）注入机制在推理时引导生成过程。

### 2.2 关键技术细节

1. **替代分数函数的设计**（式9）：
   - 使用pre-softmax logits（即QK⊤）作为softmax注意力的代理，因为softmax是严格单调增函数，最大化logits等价于最大化注意力分数。
   - 构建三项分数s：
     - **(i)** 最大化目标区域内查询与目标文本键的内积；
     - **(ii)** 最小化目标区域内查询与非目标文本键的内积；
     - **(iii)** 最小化目标区域外查询与目标文本键的内积。
   - 通过向量分解将双求和化简为三个向量点积（式10），将复杂度从O(|Q|·|K|)降至O(d)级别。

2. **闭式解推导**（式12-13）：
   - 将Q(M)和Q(M^c)设为单位向量b+和b−，分数s成为关于b+和b−的线性函数。
   - **解析最优解**：
     - b+ = normalize(K(T) − K(T^c))：正偏置方向为目标词键与补集词键均值之差；
     - b− = normalize(−K(T))：负偏置方向为目标词键的反方向。

3. **几何感知的查询注入机制**（式14、16）：
   - **考虑RMSNorm流形**：DiT的query经过RMS归一化投影到超椭球面，直接加偏置会破坏数据分布。因此注入后需重新投影回椭球面（除以γ再归一化）。
   - **背景正交投影**（式15）：对背景区域的query，将负偏置的平行分量投影掉，只保留与原始query正交的方向，避免破坏背景特征。
   - **高斯空间调制**：在目标区域内对正偏置施加归一化2D高斯加权，模拟交叉注意力图从物体中心到边缘的衰减分布。

4. **注入时机**：此前15%的去噪迭代步数中使用注入，前20个Transformer块中实施。

### 2.3 算法流程（Algorithm 1）
1. 对视频特征进行tokenize；
2. 对每个Transformer块依次执行：自注意力 → 计算q/k/v → 在指定块中注入偏置（对M内query加正偏置并重投影，对M外的query加正交负偏置并重投影）→ 交叉注意力 → 前馈网络；
3. 最终detokenize输出。

1. **GATO-Vid显著提升定位精度**：
   - Set 1：IoU 0.363 vs 最佳基线Peekaboo的0.249；CD从0.103降至0.059。
   - Set 2：IoU 0.324 vs 最佳基线Peekaboo的0.171；CD从0.193降至0.121。
2. **计算开销极小**：仅增加0.4%推理时间，是现有方法中最具效率的。
3. **现有免梯度基线在DiT上效果普遍不佳**：VideoTetris和SwitchCraft几乎与无约束的Wan2.2持平，说明简单的注意力操作不足以应对DiT架构的空间控制；Peekaboo虽有效但引入了严重视觉伪影。
4. **定位与质量存在权衡**：更强的空间控制会导致视频动态度（DD）和美学质量（AQ）下降，部分原因是背景退化。
5. **组件分析**：正/负偏置（尤其负偏置）对定位精度影响最大；投影重归一化和高斯调制主要影响视觉质量和成功率；前20个块是注入的最优位置。
