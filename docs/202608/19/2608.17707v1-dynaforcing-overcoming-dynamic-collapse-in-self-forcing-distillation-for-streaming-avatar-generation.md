## 摘要
音频驱动的虚拟人生成需要逼真的唇形同步、富有表现力的动作以及实时流式传输。近期工作通过自强制与分布匹配蒸馏（DMD）实现了后者，但这种范式存在一个尚未被系统表征的关键失败：动态崩溃，即学生模型收敛到具有高感知质量但时间动态被严重抑制的近静态最优解。我们将此归因于两个原因：DMD中的反向KL目标偏向于低运动模态，以及无锚定的自条件化形成了放大崩溃的反馈回路。这对虚拟人尤其有害，因为即使微小的运动损失也会破坏唇形同步和表情。为解决此问题，我们提出了DynaForcing，一个在不同层面应用三种互补策略的训练框架。具体而言，混合强制在数据层面将展开锚定到真实动态以打破反馈回路。动态感知奖励正则化通过DMD的强化学习解释引入显式运动奖励，以在损失层面抵消反向KL偏差。参考扰动在条件层面扰动参考图像，将身份与静态细节解耦，迫使模型依赖音频来产生运动。我们进一步引入了计算图剪枝和梯度重放，将自强制的GPU占用降低一个数量级以上。实验表明，DynaForcing将动态恢复到与教师相当的水平（Dyn-Deg: 0.31 -> 0.73, Sync-C: 7.03 -> 7.68），同时提升视觉质量，在整个训练过程中解决了质量-动态权衡，无需提前停止。

## Abstract
Audio-driven avatar generation requires realistic lip-sync, expressive motion, and real-time streaming. Recent work achieves the latter via self-forcing with Distribution Matching Distillation (DMD), but this paradigm suffers from a critical failure that has not been systematically characterized: dynamic collapse, where the student model converges to a near-static optimum with high perceptual quality but severely suppressed temporal dynamics. We trace this to two causes: the reverse KL objective in DMD, which biases toward low-motion modes, and unanchored self-conditioning, which creates a feedback loop that amplifies collapse. This is especially harmful for avatars, where even subtle motion loss breaks lip-sync and expression.   To address this, we propose DynaForcing, a training framework with three complementary strategies applied at different levels. Specifically, Hybrid Forcing anchors rollouts to ground-truth dynamics at the data level to break the feedback loop. Dynamics-Aware Reward Regularization introduces explicit motion rewards via the RL interpretation of DMD to counteract the reverse KL bias at the loss level. Reference Perturbation perturbs reference images to decouple identity from static details, forcing the model to rely on audio for motion at the conditioning level. We further introduce computation graph pruning and gradient replay, reducing the GPU footprint of self-forcing by over an order of magnitude. Experiments show that DynaForcing recovers dynamics to teacher-comparable levels (Dyn-Deg: 0.31 -> 0.73, Sync-C: 7.03 -> 7.68) while improving visual quality, resolving the quality-dynamics trade-off throughout training without early stopping.

## 一、论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：音频驱动的虚拟人生成需要同时满足三个核心需求——精确的口型同步（lip-sync）、富有表现力的运动（expression/motion）、以及实时流式传输（real-time streaming）。近期工作通过 **自强制（Self-Forcing）与分布匹配蒸馏（DMD）** 成功将大规模视频扩散模型转化为因果式、少步流式生成器，实现了 14B 参数规模下的实时无限长度虚拟人视频生成。
- **核心问题**：自强制蒸馏范式存在一个此前未被系统表征的严重失效模式——**动态崩溃（Dynamic Collapse）**：学生模型收敛到一个"感知质量高但时间动态几乎为零"的次优解——嘴巴几乎不动、表情冻结、头部运动消失，但视觉质量评分反而很高。
  - **产生原因一**：DMD 使用的逆向 KL 散度 \(D_{KL}(p_\theta \| p_{data})\) 是 **mode-seeking（模式寻求）** 的，它只惩罚学生分布落在教师支持集之外的区域，但不惩罚"忽略某些模式"——静态内容恰恰是一个容易聚合的高似然模式。
  - **产生原因二**：自强制采用 **无锚定的自条件化（Unanchored Self-Conditioning）**——KV cache 完全由学生自身输出构成，没有任何真实标注（GT）锚定，一旦学生开始生成低动态内容，后续所有 block 都基于该静态历史进行条件化，形成正反馈回路，系统性放大动态坍缩（对比：CausVid 的 GT 锚定方法不会坍缩）。
  - **虚拟人任务为何尤其严重**：虚拟人场景背景固定、身份稳定，近零运动输出已能满足大部分视觉质量判据，梯度压力很小；而任务的核心恰恰是对时间动态敏感的唇形与微表情。
- **整体含义**：动态崩溃并非任务特异的偶发现象，而是自强制蒸馏的一般性病理。该工作首次系统性形式化这一现象，并提出完整解决方案，使流式虚拟人生成在保持实时性的同时恢复到与教师模型相当的动态水平。

## 二、论文提出的方法论

### 核心思想

DynaForcing 是一个训练框架，在**数据层、损失层、条件层**三个层面分别干预，共同对抗动态崩溃；同时引入两项效率优化，将自强制训练的 GPU 开销降低一个数量级以上。

### 关键技术细节

1. **混合强制（Hybrid Forcing, §4.2）——数据层策略**
   - 在自强制展开过程中，以概率 \(p_{data}\) 将各 block 的起点从纯高斯噪声替换为**加噪的 ground-truth 潜在表示**：\(B^i_{start} = \Psi(B^i_{GT}, t_{start})\)。
   - 加噪 GT 保留了运动结构信息（唇动、表情变化等），为学生提供逃离"零动态盆地"的梯度方向。
   - KV cache 仍然使用学生自身表示，保持训练/测试分布一致。
   - 对起始噪声步 \(t_{start}\) 的采样概率进行重分配（集中于中间步 \(t_1\)，权重 0.70），兼顾动态信息保持和有效去噪训练。

2. **动态感知奖励正则化（Dynamics-Aware Reward Regularization, §4.3）——损失层策略**
   - 利用 DMD 的强化学习解释，将显式动态奖励 \(R_{dyn}\) 以指数加权形式（\(\exp(\alpha \cdot \text{sg}(R_{dyn}))\)）乘入 DMD 梯度，从而放大高动态样本的梯度、抑制静态样本的梯度。
   - 奖励定义：\(R_{dyn}(\hat{V}, a) = \lambda_{sync}\cdot\text{Sync-C}(\hat{V}, a) + \lambda_{exp}\cdot\text{ExpVar}(\hat{V})\)，使用预训练 SyncNet 的口型同步置信度和 3DMM 表情系数标准差。
   - 奖励通过 stop-gradient 处理，与标准 DMD 训练完全兼容。

3. **参考扰动（Reference Perturbation, §4.4）——条件层策略**
   - 在标准训练中，参考帧与目标帧来自同一视频片段，模型学会"复制参考帧"的捷径而非真正生成音频驱动的运动。
   - 使用 Qwen-Image-Edit 对参考帧进行保持身份但改变视角、背景、光照等的语义编辑，并通过 **ArcFace 身份过滤**（\(\tau_{arc}=0.9\)）+ **SSIM 相似度分桶**（5 个桶均匀采样）实现平衡训练。
   - 迫使模型只能从参考帧提取身份信息，运动完全依赖音频驱动。

4. **高效自强制训练（Efficient Self-Forcing Training, §4.5）**
   - **计算图剪枝**：将 KV cache 从计算图中分离（detach），消除跨 block 梯度依赖。
   - **分块梯度重放**：rollout 阶段关闭梯度并存储中间结果，replay 阶段逐 block 重新启用梯度计算 DMD 梯度，将峰值激活显存降低约 \(K\) 倍。

## 六、论文的主要结论与发现

- **动态崩溃被系统性表征**：自强制蒸馏中，逆向 KL 的 mode-seeking 倾向与无锚定自条件的反馈回路共同导致时间动态被系统性压制；GT 锚定训练（CausVid 式）不会崩溃，证明无锚定自条件是主因。
- **DynaForcing 有效恢复动态**：在 GenBench-ShortVideo 上，Dyn-Deg 从 0.31 提升到 0.73（教师 WanS2V 为 0.72），Sync-C 从 7.03 提升到 7.68，ExpVar 从 0.69 提升到 2.02；视觉质量 ASE / IQA 也同步改善（3.55/4.58 vs. LiveAvatar 的 3.44/4.51）。
- **长视频优势保持**：在 >5 分钟的 GenBench-LongVideo 上，动态优势不衰减（ExpVar 1.93 vs. LiveAvatar 的 0.57）。
- **全程训练稳定**：与基线需要早停来避免质量-动态权衡不同，DynaForcing 在整个训练过程中动态指标和视觉质量同步提升并稳定，无需早停。
- **效率可行性**：训练 GPU 需求从 128 卡降至 8 卡，GPU·小时从 7,111 降至 667，且质量几乎无损。

## 七、优点

- **系统性归因分析**：不局限于提出方法，而是通过对照实验（自强制 vs. GT 锚定）清晰分离了两个崩溃驱动力（reverse-KL 和无锚定自条件化），归因有据。
- **多层次干预设计优雅**：数据层（Hybrid Forcing）、损失层（Reward Regularization）、条件层（Reference Perturbation）三个策略互补，组件消融显示各自贡献明确、叠加最优。
- **对奖励黑客的防范意识较强**：突出 Dyn-Deg（非训练目标）的恢复作为独立证据，并补充 landmark-based 的无奖励指标（Lip-Vel/Lip-Jit），论证动态恢复是真实的而非高频抖动式的奖励欺骗。
- **训练效率优化切实可用**：计算图剪枝 + 梯度重放实现了约 10 倍 GPU 开销缩减，对 14B 规模模型的实际训练可行性有重要价值。
- **训练稳定性视角新颖**：将"训练全程无崩溃、无需早停"作为核心卖点，区别于依赖 checkpoint 选择的现有做法。

## 八、不足与局限（论文自述 + 客观分析）

- **对预训练模型的依赖**：动态奖励依赖预训练 SyncNet 和 3DMM 模型，这些模型自身的偏差（如对特定人脸/语言的偏好）可能渗透到训练中。
- **任务覆盖有限**：分析聚焦于音频驱动的虚拟人任务；虽然作者预期数据层组件（Hybrid Forcing）可迁移，但跨任务（如通用 T2V）的系统验证仍留作未来工作。
- **奖励指标与评估指标重叠**：Sync-C 和 ExpVar 同时作为训练奖励与评估指标，存在奖励黑客的理论风险——尽管论文用 Dyn-Deg、Lip-Vel/Lip-Jit 和用户研究做了多角度佐证，但这不是完全消除。
- **梯度重放有额外开销**：训练 wall-clock 增加约 1.5 倍，虽有 GPU 显存优势，但训练总时间并未缩短。
- **参考扰动依赖外部编辑模型**：Qwen-Image-Edit 的编辑质量会影响训练分布，虽然消融显示传统增强也能恢复动态，但传统增强会略降视觉质量（ASE 3.55→3.48）。
- **用户研究规模有限**：25 名参与者的样本量较小，且未报告参与者人群多样性细节。
